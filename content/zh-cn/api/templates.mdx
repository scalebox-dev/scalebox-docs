# ScaleBox 模板 API

模板管理 API 参考。创建、更新和管理容器模板，为沙盒环境提供基础配置。

**需要身份验证：** 所有 API 请求都需要使用您的 API 密钥通过 `X-API-Key` 标头进行身份验证。
</Callout>

## API 端点

以下是所有可用的模板 API 端点：

| 端点 | 方法 | 路径 | 描述 |
|------|------|------|------|
| create-template | POST | `/v1/templates` | 创建新模板 |
| list-templates | GET | `/v1/templates` | 列出所有可访问的模板 |
| get-template | GET | `/v1/templates/{template_id}` | 获取特定模板的详细信息 |
| get-template-document | GET | `/v1/templates/{template_id}/document` | 获取模板 Markdown 说明文档（JSON） |
| download-template-document | GET | `/v1/templates/{template_id}/document?download=1` | 下载说明文档为 `.md` 附件（空文档返回 400） |
| put-template-document | PUT | `/v1/templates/{template_id}/document` | 设置或清空说明文档 |
| delete-template-document | DELETE | `/v1/templates/{template_id}/document` | 删除说明文档 |
| update-template | PUT | `/v1/templates/{template_id}` | 更新模板配置 |
| delete-template | DELETE | `/v1/templates/{template_id}` | 删除模板 |
| direct-import-template | POST | `/v1/templates/import` | 从外部镜像创建模板并启动导入 Harbor |
| start-import-existing-template | POST | `/v1/templates/{template_id}/import` | 为已存在的外部模板启动导入 |
| get-template-import-status | GET | `/v1/templates/{template_id}/import` | 按模板查询导入任务状态 |
| cancel-template-import | DELETE | `/v1/templates/{template_id}/import` | 取消该模板当前进行中的导入 |
| build-template | POST | `/v1/templates/{template_id}/build` | 构建模板镜像 |
| list-import-jobs | GET | `/v1/import-jobs` | 列出当前用户的模板导入任务 |
| get-import-job | GET | `/v1/import-jobs/{job_id}` | 按任务 ID 获取单个导入任务详情 |
| cancel-import-job | DELETE | `/v1/import-jobs/{job_id}` | 按任务 ID 取消导入任务 |
| share-template | POST | `/v1/templates/{template_id}/share` | 将私有模板与账户共享 |
| unshare-template | POST | `/v1/templates/{template_id}/unshare` | 将账户共享模板恢复为私有 |

## create-template

**POST** `/v1/templates`

创建新模板

### 请求参数

| 参数 | 类型 | 必需 | 默认值 | 描述 |
|------|------|------|--------|------|
| name | string | 是 | - | 模板名称（4-32个字符，支持小写字母、数字、连字符和下划线） |
| description | string | 否 | - | 模板描述 |
| image | string | 是 | - | 容器镜像名称 |
| base_template_id | string | 否 | - | 基础模板ID |
| public | boolean | 否 | false | 是否为公共模板 |
| cpu_count | integer | 否 | 2 | 默认CPU数量 |
| memory_mb | integer | 否 | 512 | 默认内存（MB） |
| storage_gb | integer | 否 | 1 | 默认存储（GB） |
| timeout | integer | 否 | 300 | 默认超时时间（秒） |
| ports | array | 否 | [] | 端口配置 |

### 请求示例

```bash
curl -X POST https://api.scalebox.dev/v1/templates \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "python-dev-template",
    "description": "Template for Python development",
    "image": "python:3.9",
    "public": false,
    "cpu_count": 2,
    "memory_mb": 1024,
    "storage_gb": 10,
    "timeout": 3600,
    "ports": [8000, 8080]
  }'
```

## list-templates

**GET** `/v1/templates`

列出所有可访问的模板

### 请求示例

```bash
curl -X GET https://api.scalebox.dev/v1/templates \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

每个模板对象包含 **`has_template_document`**（布尔）：是否存有非空 Markdown 说明。列表接口**不返回**完整 **`template_document`** 正文；请用 **get-template** 或下方 **template-document** 接口获取全文。

## get-template

**GET** `/v1/templates/{template_id}`

获取特定模板的详细信息

### 请求示例

```bash
curl -X GET https://api.scalebox.dev/v1/templates/tpl-abc123def456789 \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

完整响应中可包含 **`template_document`**（字符串或 `null`）：长文 Markdown 用户文档，与简短 **`description`** 不同。列表接口为减轻体积**不返回**该字段；请使用本接口或下方专用文档接口。

## template-document

模板可存可选的 Markdown 说明（最大约 **65,535 字节**）。能**访问**模板的用户可读文档；**写入/删除**与编辑该模板权限一致（所有者、同账户 root、或管理员编辑公共模板）。

### GET `/v1/templates/{template_id}/document`

返回标准成功包装内的 JSON，字段含 `template_id`、`template_document`（无内容时为 `null` 或省略）。

```bash
curl -X GET https://api.scalebox.dev/v1/templates/tpl-abc123def456789/document \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### GET `/v1/templates/{template_id}/document?download=1`

返回 `text/markdown` 附件。文档为空或仅空白时返回 **400**。查询参数可为 `download=true`、`1` 或 `yes`。

```bash
curl -L -o guide.md "https://api.scalebox.dev/v1/templates/tpl-abc123def456789/document?download=1" \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### PUT `/v1/templates/{template_id}/document`

请求体 JSON：`{"template_document": "..."}`。空字符串或仅空白会清空文档。

```bash
curl -X PUT https://api.scalebox.dev/v1/templates/tpl-abc123def456789/document \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{"template_document": "# 指南\n\n你好。"}'
```

### DELETE `/v1/templates/{template_id}/document`

清除已存储的 Markdown，权限同 PUT。

```bash
curl -X DELETE https://api.scalebox.dev/v1/templates/tpl-abc123def456789/document \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

更新模板配置

### 请求参数

| 参数 | 类型 | 必需 | 默认值 | 描述 |
|------|------|------|--------|------|
| name | string | 否 | - | 新模板名称（4-32个字符，支持小写字母、数字、连字符和下划线） |
| description | string | 否 | - | 新模板描述 |
| image | string | 否 | - | 新容器镜像名称 |
| public | boolean | 否 | - | 是否为公共模板 |
| cpu_count | integer | 否 | - | 新默认CPU数量 |
| memory_mb | integer | 否 | - | 新默认内存（MB） |
| storage_gb | integer | 否 | - | 新默认存储（GB） |
| timeout | integer | 否 | - | 新默认超时时间（秒） |
| ports | array | 否 | - | 新端口配置 |
| custom_command | string | 否 | - | 自定义启动命令 |
| ready_command | string | 否 | - | 就绪探针：JSON，type 为 exec\|httpGet\|tcpSocket；不传或空则保持不变 |

### 请求示例

```bash

  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "更新的Python环境",
    "description": "更新的描述",
    "image": "python:3.10",
    "cpu_count": 4,
    "memory_mb": 2048
  }'
```

## direct-import-template

**POST** `/v1/templates/import`

从 **`external_image_url`** 创建自定义模板，并排队将镜像复制到 ScaleBox Harbor（Skopeo）。成功时通常返回 **202 Accepted**，`data` 中含 `template_id`、`job_id`、`status` 等。

Harbor 的 project / repository / tag 由**服务端推导**（仓库名与模板 `name` 对齐，标签为 **`latest`**），客户端勿传 Harbor 目标路径字段。

### 请求体（JSON）

| 参数 | 类型 | 必需 | 描述 |
|------|------|------|------|
| name | string | 是 | 模板名称（与创建模板相同校验） |
| external_image_url | string | 是 | 上游镜像完整引用 |
| description | string | 否 | 描述 |
| external_registry_username | string | 否 | 私有仓库用户名 |
| external_registry_password | string | 否 | 私有仓库密码或令牌 |
| default_cpu_count | integer | 否 | 默认 CPU |
| default_memory_mb | integer | 否 | 默认内存 |
| visibility | string | 否 | `private`、账户 **root** 可用 `account_shared`、**管理员** 可用 `public` |
| ports | string | 否 | 端口 JSON（与创建模板相同结构） |
| custom_command | string | 否 | 自定义启动命令 |
| ready_command | string | 否 | 就绪探针 JSON |

### 请求示例

```bash
curl -X POST https://api.scalebox.dev/v1/templates/import \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-upstream-tool",
    "description": "从上游同步",
    "external_image_url": "docker.io/library/alpine:latest",
    "default_cpu_count": 2,
    "default_memory_mb": 1024,
    "visibility": "private"
  }'
```

## start-import-existing-template

**POST** `/v1/templates/{template_id}/import`

为已存在且 **`custom_image_source` 为 `external`** 的模板启动导入。返回 **202**。常见错误：非外部模板、已导入、已有任务运行（**409**）、无可用集群或 Harbor（**503**）等。无需请求体。

```bash
curl -X POST https://api.scalebox.dev/v1/templates/tpl-abc123def456789/import \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

## get-template-import-status

**GET** `/v1/templates/{template_id}/import`

返回该模板的**进行中**导入任务，或**最近一条**已完成/失败/已取消的任务。仅**模板所有者**（`owner_user_id`）可调用。

响应字段包括：`job_id`、`template_id`、`status`、`progress_percentage`、`external_image_url`、`harbor_image_url`、时间戳、`last_log_message`、`error_message`、`skopeo_logs` 等。

## cancel-template-import

**DELETE** `/v1/templates/{template_id}/import`

取消该模板当前**进行中**的导入任务。仅所有者。无活跃任务时 **404**。

```bash
curl -X DELETE https://api.scalebox.dev/v1/templates/tpl-abc123def456789/import \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

## list-import-jobs

**GET** `/v1/import-jobs`

列出当前用户的模板导入任务。默认仅返回进行中（pending/running）任务。

### 请求参数

| 参数 | 类型 | 必需 | 默认值 | 描述 |
|------|------|------|--------|------|
| status | string | 否 | ongoing | 筛选：ongoing（省略时默认）、pending、running、completed、failed、cancelled，或与 --all 同用返回全部 |
| template_id | string | 否 | - | 仅返回该模板 ID 的任务 |
| limit | integer | 否 | 20 | 返回数量上限（1-100） |
| offset | integer | 否 | 0 | 分页偏移 |

### 请求示例

```bash
curl -X GET "https://api.scalebox.dev/v1/import-jobs?status=ongoing&limit=20" \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

## cancel-import-job

**DELETE** `/v1/import-jobs/{job_id}`

按**任务 ID** 取消导入（与列表任务的权限规则一致）。

```bash
curl -X DELETE https://api.scalebox.dev/v1/import-jobs/job-xyz789 \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

若只知道模板 ID，也可使用 **`DELETE /v1/templates/{template_id}/import`**（见上文）。

## share-template

**POST** `/v1/templates/{template_id}/share`

将私有模板与账户共享（可见性 → account_shared）。仅模板所有者或管理员。

### 请求参数

| 参数 | 类型 | 必需 | 默认值 | 描述 |
|------|------|------|--------|------|
| new_name | string | 否 | - | 共享时使用的新名称（与现有账户共享模板重名时必填） |

### 请求示例

```bash
curl -X POST https://api.scalebox.dev/v1/templates/tpl-abc123def456789/share \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{"new_name": "my-shared-env"}'
```

## unshare-template

**POST** `/v1/templates/{template_id}/unshare`

将账户共享模板恢复为私有。仅模板所有者或管理员。

### 请求示例

```bash
curl -X POST https://api.scalebox.dev/v1/templates/tpl-abc123def456789/unshare \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

<Callout type="info">
**模板管理最佳实践**

使用描述性的模板名称，设置合理的默认资源限制。
公共模板可以被其他用户使用，请确保不包含敏感信息。
查看 [沙盒 API](./sandboxes) 来了解如何从模板创建沙盒。
</Callout>

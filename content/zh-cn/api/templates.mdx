# ScaleBox 模板 API

<Callout type="warn">
**需要身份验证：** 本页所有接口都要求使用 `X-API-Key`。
</Callout>

## 模板名称校验

- 长度 `4-32` 个字符
- 仅允许小写字母、数字、`-`、`_`
- 必须以字母或数字开头和结尾
- 不能以数字开头
- 不能包含连续分隔符：`--`、`__`、`-_`、`_-`
- 不能以 `tpl-` 开头

## 模板状态

| 状态 | 含义 |
|------|------|
| `pending` | 已创建，尚未开始构建或导入 |
| `building` | 正在构建 |
| `pushing` | 正在推送到 Harbor |
| `available` | 可用于创建沙盒 |
| `failed` | 构建或推送失败 |

## 响应约定

大多数 JSON 接口都返回标准包装：

```json
{
  "success": true,
  "data": {},
  "timestamp": "2026-04-17T12:34:56Z"
}
```

特殊情况：

- `GET /v1/templates/{template_id}/document?download=...` 返回原始 Markdown 文件，不走 JSON 包装。
- `POST /v1/templates/import` 与 `POST /v1/templates/{template_id}/import` 返回 `202 Accepted`，导入在后台继续执行。
- 少数旧路径会把 `message` 放在 `data` 内；这仍属于当前后端契约。

## 模板对象

### 列表对象

`GET /v1/templates` 中每个元素包含：

- `template_id`、`name`、`description`
- `default_cpu_count`、`default_memory_mb`
- `visibility`
- `template_source`、`custom_image_source`
- `external_image_url`、`external_registry_username`
- `status`
- `owner_user_id`、`owner_account_id`
- `harbor_image_url`、`harbor_project`、`harbor_repository`、`harbor_tag`
- `image_size_bytes`
- `metadata`、`ports`
- `custom_command`、`ready_command`
- `build_started_at`、`push_started_at`、`push_completed_at`
- `build_error_message`、`last_storage_sync_at`
- `created_at`、`updated_at`
- `has_template_document`
- 可选 `owner`：`user_id`、`username`、`display_name`

### 详情对象

`GET /v1/templates/{template_id}` 返回与列表对象相同的字段，另加：

- `parent_template_id`
- `root_template_id`
- `template_document`

## 接口

### List Templates

`GET /v1/templates`

列出当前用户可访问的模板。

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `page` | integer | 否 | 分页页码，默认 `1` |
| `limit` | integer | 否 | 返回模板数量，默认 `20`（别名：`page_size`） |
| `offset` | integer | 否 | 分页偏移量，默认 `0`（别名：`skip`） |
| `status` | string | 否 | 按状态筛选：`pending`、`building`、`pushing`、`available`、`failed` |
| `visibility` | string | 否 | 按可见性筛选：`private`、`account_shared`、`public` |
| `name` | string | 否 | 按模板名精确匹配 |
| `usable` | string | 否 | 传 `true` 时仅返回可用于创建沙盒的模板 |

成功响应：

- `data.templates`：模板列表对象数组
- `data.pagination`：分页对象，包含 `page`、`limit`、`offset`、`total`、`total_pages`

注意：列表响应只返回 `has_template_document`，**不返回**完整 `template_document`。

### Get Template

`GET /v1/templates/{template_id}`

成功响应：

- `data`：单个模板详情对象

### Template Document

模板可存储可选 Markdown 文档，最大约 `65,535` 字节。

#### Get template document

`GET /v1/templates/{template_id}/document`

成功响应：

- `data.template_id`
- `data.template_document`，未设置时为 `null` 或省略

#### Download template document

`GET /v1/templates/{template_id}/document?download=1`

特殊情况：

- 成功时返回 `200 OK`，`Content-Type: text/markdown; charset=utf-8`
- 同时带 `Content-Disposition: attachment`
- 允许 `download=true`、`download=1`、`download=yes`
- 若无文档或内容仅为空白，返回 `400`

#### Set template document

`PUT /v1/templates/{template_id}/document`

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `template_document` | string | 是 | Markdown 内容；空字符串或全空白会清空文档 |

成功响应：

- `data.template_id`
- `data.template_document`

#### Delete template document

`DELETE /v1/templates/{template_id}/document`

成功响应：

- 顶层 `message: "Template document removed"`
- `data.template_id`
- `data.template_document`，始终为 `null`

### Create Template

`POST /v1/templates`

创建模板或基于现有模板派生模板。

请求参数：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `name` | string | 是 | - | 模板名称 |
| `description` | string | 否 | - | 模板描述 |
| `default_cpu_count` | integer | 否 | `2` | 默认 CPU |
| `default_memory_mb` | integer | 否 | `512` | 默认内存 |
| `visibility` | string | 否 | `private` | `private`、`account_shared`、`public` |
| `template_source` | string | 否 | `scalebox_family` | `scalebox_family` 或 `custom` |
| `custom_image_source` | string | 否 | - | 自定义模板时必填：`external` 或 `imported` |
| `external_image_url` | string | 否 | - | 外部镜像完整引用 |
| `external_registry_username` | string | 否 | - | 私有外部仓库用户名 |
| `external_registry_password` | string | 否 | - | 私有外部仓库密码或令牌 |
| `harbor_image_url` | string | 否 | - | 完整 Harbor 镜像地址 |
| `harbor_project` | string | 否 | 自动推导 | Harbor project |
| `harbor_repository` | string | 否 | - | Harbor repository |
| `harbor_tag` | string | 否 | `latest` | Harbor tag |
| `metadata` | string | 否 | `{}` | JSON 字符串 |
| `base_template_id` | string | 否 | - | 派生时的基础模板 ID |
| `ports` | string | 否 | `[]` | 端口 JSON 数组 |
| `reset_ports` | boolean | 否 | `false` | 为 `true` 时移除从基础模板继承的非保护端口 |
| `custom_command` | string | 否 | - | 启动命令 |
| `ready_command` | string | 否 | - | 就绪探针 JSON |

成功响应：

- `201 Created`
- `data.template_id`、`name`、`description`
- `data.default_cpu_count`、`default_memory_mb`
- `data.visibility`
- `data.template_source`、`custom_image_source`
- `data.external_image_url`、`external_registry_username`
- `data.status`
- `data.harbor_image_url`、`harbor_project`、`harbor_repository`、`harbor_tag`
- `data.image_size_bytes`
- `data.metadata`、`ports`
- `data.build_started_at`、`push_started_at`、`push_completed_at`
- `data.build_error_message`、`last_storage_sync_at`
- `data.owner_id`
- `data.created_at`、`updated_at`

### Update Template

`PUT /v1/templates/{template_id}`

仅允许更新普通配置字段；`visibility`、`status`、`harbor_*` 等不通过此路径修改。

可更新字段：

- `name`
- `description`
- `template_document`
- `default_cpu_count`
- `default_memory_mb`
- `metadata`
- `ports`
- `custom_command`
- `ready_command`

成功响应：

- 顶层 `message: "Template updated successfully"`
- `data.template` 包含：
  - `template_id`、`name`、`description`、`template_document`
  - `default_cpu_count`、`default_memory_mb`
  - `visibility`、`status`
  - `harbor_image_url`、`harbor_project`、`harbor_repository`、`harbor_tag`
  - `image_size_bytes`
  - `metadata`、`ports`
  - `build_started_at`、`push_started_at`、`push_completed_at`
  - `build_error_message`、`last_storage_sync_at`
  - `owner_id`
  - `created_at`、`updated_at`

### Delete Template

`DELETE /v1/templates/{template_id}`

成功响应：

- 顶层 `message: "Template deleted successfully"`
- 成功时不返回 `data`

### Update Template Status

`PUT /v1/templates/{template_id}/status`

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `status` | string | 是 | `pending`、`building`、`pushing`、`available`、`failed` |
| `error_message` | string | 否 | 失败时的错误信息 |
| `push_logs` | string | 否 | 构建/推送日志 |
| `harbor_image_url` | string | 否 | 更新后的 Harbor 镜像地址 |

成功响应：

- `data.message`
- `data.template_id`
- `data.build_status`

### Validate Template

`POST /v1/templates/{template_id}/validate`

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `harbor_image_url` | string | 是 | 要标记为可用的 Harbor 镜像地址 |

成功响应：

- `data.message`
- `data.template_id`
- `data.build_status`
- `data.harbor_image_url`

### Get Storage Usage

`GET /v1/templates/storage-usage`

返回当前用户私有模板镜像占用。

成功响应：

- `data.used_gb`
- `data.limit_gb`
- `data.percentage`

<Callout type="warn">
`POST /v1/templates/register` 已移除。镜像已在 Harbor 时请用 `POST /v1/templates`；需要从外部仓库拉入 Harbor 时请用下方导入接口。
</Callout>

### Direct Import Template

`POST /v1/templates/import`

一步完成两件事：创建一个 `custom` + `external` 模板，并发起外部镜像到 Harbor 的异步导入。

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 模板名称 |
| `external_image_url` | string | 是 | 上游镜像完整引用 |
| `description` | string | 否 | 模板描述 |
| `external_registry_username` | string | 否 | 私有仓库用户名 |
| `external_registry_password` | string | 否 | 私有仓库密码或令牌 |
| `default_cpu_count` | integer | 否 | 默认 CPU |
| `default_memory_mb` | integer | 否 | 默认内存 |
| `visibility` | string | 否 | `private`、`account_shared`、`public` |
| `ports` | string | 否 | 端口 JSON |
| `custom_command` | string | 否 | 启动命令 |
| `ready_command` | string | 否 | 就绪探针 JSON |

特殊情况：

- 返回 `202 Accepted`
- Harbor 目标 `project` / `repository` / `tag` 由服务端推导，客户端**不要**传目的地字段

成功响应：

- `data.template_id`
- `data.name`
- `data.visibility`
- 任务创建成功时还会有 `data.job_id`、`status`、`external_image_url`、`harbor_image_url`、`created_at`
- `data.message` 可能是：
  - `Template created and import started`
  - `Template created but import failed to start. Retry via POST /v1/templates/:template_id/import`

### Start Import for Existing Template

`POST /v1/templates/{template_id}/import`

为已存在且 `custom_image_source = external` 的模板启动导入。

特殊情况：

- 返回 `202 Accepted`
- 无需请求体

成功响应：

- `data.job_id`
- `data.template_id`
- `data.status`
- `data.external_image_url`
- `data.harbor_image_url`
- `data.created_at`
- `data.message`

### Get Template Import Status

`GET /v1/templates/{template_id}/import`

返回进行中的导入任务；若没有进行中任务，则返回最近一条完成、失败或取消的任务。仅模板所有者可调用。

成功响应：

- `data.job_id`
- `data.template_id`
- `data.status`
- `data.progress_percentage`
- `data.external_image_url`
- `data.harbor_image_url`
- `data.created_at`、`started_at`、`completed_at`
- `data.last_log_message`
- `data.error_message`
- `data.skopeo_logs`

### Cancel Template Import

`DELETE /v1/templates/{template_id}/import`

取消该模板当前正在运行的导入任务。

成功响应：

- `data.job_id`
- `data.status`，始终为 `cancelled`
- `data.message`，值为 `Import job cancelled`

### List Import Jobs

`GET /v1/import-jobs`

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `status` | string | 否 | `ongoing`（默认）、`pending`、`running`、`completed`、`failed`、`cancelled` |
| `template_id` | string | 否 | 按模板过滤 |
| `page` | integer | 否 | 分页页码，默认 `1` |
| `limit` | integer | 否 | 返回条数，`1-100`（别名：`page_size`） |
| `offset` | integer | 否 | 分页偏移量（别名：`skip`） |

成功响应：

- `data.jobs`：数组元素含 `job_id`、`template_id`、`status`、`progress_percentage`、`external_image_url`、`harbor_image_url`、`created_at`、`started_at`、`completed_at`、`error_message`
- `data.pagination`：分页对象，包含 `page`、`limit`、`offset`、`total`、`total_pages`

### Get Import Job

`GET /v1/import-jobs/{job_id}`

成功响应：

- `data.job_id`
- `data.template_id`
- `data.status`
- `data.progress_percentage`
- `data.external_image_url`
- `data.harbor_image_url`
- `data.created_at`、`started_at`、`completed_at`、`updated_at`
- `data.last_log_message`
- `data.error_message`
- `data.skopeo_logs`
- `data.retry_count`
- `data.max_retries`

### Cancel Import Job

`DELETE /v1/import-jobs/{job_id}`

成功响应：

- `data.job_id`
- `data.status`，始终为 `cancelled`
- `data.message`，值为 `Import job cancelled`

### Share Template

`POST /v1/templates/{template_id}/share`

把私有模板共享到当前账户，`visibility` 会变为 `account_shared`。

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `new_name` | string | 否 | 共享时改名；名称冲突时通常需要提供 |

成功响应：

- `data.template_id`
- `data.visibility`，值为 `account_shared`
- `data.harbor_project`
- `data.harbor_image_url`
- `data.message`

### Unshare Template

`POST /v1/templates/{template_id}/unshare`

把账户共享模板恢复为私有模板。

成功响应：

- `data.template_id`
- `data.visibility`，值为 `private`
- `data.harbor_project`
- `data.harbor_image_url`
- `data.message`

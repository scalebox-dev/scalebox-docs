<Callout type="warn">
**需要身份验证：** API 密钥管理接口需要已认证请求。可使用 `X-API-Key`、`Authorization: Api-Key ...` 或受支持的 bearer token。
</Callout>

<Callout type="info">
**密钥显示规则：** 完整 `api_key` **仅**在创建（`POST`）响应中返回一次，请立即复制或下载保存。列表、获取、更新和状态接口只返回显示前缀 `prefix`；完整密钥不会保存在服务端，也无法再次获取。
</Callout>

## 标准响应格式

API 密钥接口使用统一响应包裹：

```json
{
  "success": true,
  "data": {},
  "timestamp": "2026-04-17T12:34:56Z"
}
```

删除接口会返回顶层 `message`，不包含 `data`。

## API 端点

### 创建 API 密钥

`POST /v1/api-keys`

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | API 密钥名称 |
| description | string | 否 | 用途说明 |

**响应示例**

```json
{
  "success": true,
  "data": {
    "key_id": "key-abc123def456789",
    "name": "development-key",
    "description": "用于本地开发",
    "api_key": "sk-1234567890abcdef1234567890abcdef12345678",
    "prefix": "sk-1234",
    "is_active": true,
    "created_at": "2026-04-17T12:00:00Z",
    "owner": {
      "user_id": "usr-xyz789abc123456",
      "username": "developer",
      "display_name": "John Developer",
      "email": "john@example.com"
    }
  },
  "timestamp": "2026-04-17T12:00:00Z"
}
```

### 列出 API 密钥

`GET /v1/api-keys`

**查询参数**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| user_id | string | 否 | 仅 root 用户可用，按拥有者筛选 |
| status | string | 否 | `active` 或 `inactive` |
| search | string | 否 | 名称模糊搜索 |
| sort_by | string | 否 | 排序字段 |
| sort_order | string | 否 | `asc` 或 `desc` |
| page | integer | 否 | 分页页码，默认 `1` |
| limit | integer | 否 | 返回数量上限（别名：`page_size`） |
| offset | integer | 否 | 分页偏移量（别名：`skip`） |

**响应示例**

```json
{
  "success": true,
  "data": {
    "api_keys": [
      {
        "key_id": "key-abc123def456789",
        "name": "development-key",
        "description": "用于本地开发",
        "prefix": "sk-1234567",
        "is_active": true,
        "last_used_at": "2026-04-17T11:45:00Z",
        "created_at": "2026-04-10T10:00:00Z",
        "updated_at": "2026-04-17T11:45:00Z",
        "owner": {
          "user_id": "usr-xyz789abc123456",
          "username": "developer",
          "display_name": "John Developer",
          "email": "john@example.com"
        }
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 50,
      "offset": 0,
      "total": 1,
      "total_pages": 1
    }
  },
  "timestamp": "2026-04-17T12:00:00Z"
}
```

### 获取 API 密钥

`GET /v1/api-keys/{key_id}`

返回单个密钥的元数据，**不包含**完整密钥。

**响应示例**

```json
{
  "success": true,
  "data": {
    "key_id": "key-abc123def456789",
    "name": "development-key",
    "description": "用于本地开发",
    "prefix": "sk-1234567",
    "is_active": true,
    "last_used_at": "2026-04-17T11:45:00Z",
    "created_at": "2026-04-10T10:00:00Z",
    "updated_at": "2026-04-17T11:45:00Z",
    "owner": {
      "user_id": "usr-xyz789abc123456",
      "username": "developer",
      "display_name": "John Developer",
      "email": "john@example.com"
    }
  },
  "timestamp": "2026-04-17T12:00:00Z"

```

### 更新 API 密钥

`PUT /v1/api-keys/{key_id}`

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 否 | 新名称 |
| description | string | 否 | 新描述 |

**响应示例**

```json
{
  "success": true,
  "data": {
    "key_id": "key-abc123def456789",
    "name": "production-key",
    "description": "用于生产环境",
    "prefix": "sk-1234567",
    "is_active": true,
    "last_used_at": "2026-04-17T11:45:00Z",
    "created_at": "2026-04-10T10:00:00Z",
    "updated_at": "2026-04-17T12:05:00Z"
  },
  "timestamp": "2026-04-17T12:05:00Z"
}
```

### 更新 API 密钥状态

`PUT /v1/api-keys/{key_id}/status`

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| is_active | boolean | 是 | `true` 启用，`false` 禁用 |

**响应示例**

```json
{
  "success": true,
  "data": {
    "message": "API key disabled successfully",
    "is_active": false
  },
  "timestamp": "2026-04-17T12:06:00Z"
}
```

### 删除 API 密钥

`DELETE /v1/api-keys/{key_id}`

**响应示例**

```json
{
  "success": true,
  "message": "API key deleted successfully",
  "timestamp": "2026-04-17T12:07:00Z"
}
```

## 校验说明

- API 密钥名称会经过后端的严格校验。
- 重名会返回 `409 Conflict`。
- 管理员用户最多只能有 1 个 API 密钥。
- 非管理员用户最多可以有 5 个 API 密钥。
- 若遗失完整密钥，请删除旧密钥并创建新密钥；ScaleBox 无法再次显示完整密钥。
- 创建接口返回较短的 `prefix`；列表、获取和更新接口返回较长的显示前缀。

## 常见错误

```json
{
  "success": false,
  "error": "An API key with this name already exists for your account",
  "timestamp": "2026-04-17T12:10:00Z"
}
```

- `400`：请求体非法、名称非法或达到密钥数量上限
- `401`：缺少认证或认证无效
- `404`：在当前可见范围内找不到该密钥
- `409`：名称重复
- `500`：数据库或密钥生成失败

# ScaleBox 项目 API

项目管理 API 参考。创建、更新和管理项目，组织您的沙盒环境。

<Callout type="warn">
**需要身份验证：** 所有 API 请求都需要使用您的 API 密钥通过 `X-API-Key` 标头进行身份验证。
</Callout>

## API 端点

以下是所有可用的项目 API 端点：

| 端点 | 方法 | 路径 | 描述 |
|------|------|------|------|
| create-project | POST | `/v1/projects` | 创建新项目 |
| list-projects | GET | `/v1/projects` | 列出用户的所有项目 |
| get-project | GET | `/v1/projects/{project_id}` | 获取特定项目的详细信息 |
| update-project | PUT | `/v1/projects/{project_id}` | 更新项目信息 |
| delete-project | DELETE | `/v1/projects/{project_id}` | 删除项目 |
| get-project-sandboxes | GET | `/v1/projects/{project_id}/sandboxes` | 获取项目中的所有沙盒 |
| add-sandbox-to-project | POST | `/v1/projects/{project_id}/sandboxes/{sandbox_id}` | 将沙盒添加到项目 |
| remove-sandbox-from-project | DELETE | `/v1/projects/{project_id}/sandboxes/{sandbox_id}` | 从项目中移除沙盒 |

## create-project

**POST** `/v1/projects`

创建新项目

### 请求参数

| 参数 | 类型 | 必需 | 默认值 | 描述 |
|------|------|------|--------|------|
| name | string | 是 | - | 项目名称（2-100个字符） |
| description | string | 否 | - | 项目描述 |

### 请求示例

```bash
curl -X POST https://api.scalebox.dev/v1/projects \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-development-project",
    "description": "Project for developing new features"
  }'
```

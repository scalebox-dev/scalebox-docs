# ScaleBox 沙盒 API

完整的沙盒管理 API 参考。创建、启动、停止和管理您的沙盒环境。

<Callout type="warn">
**身份验证：** 大多数沙盒 API 需要 `X-API-Key`。

**例外：** `GET /v1/scalebox-regions` 为公开接口（密钥可选）。创建沙盒前可用其列出 `locality.region` 可用 id。
</Callout>

## Scalebox 区域（发现）

调用 `GET /v1/scalebox-regions` 获取当前具备可用容量的区域 `id` / `name`。创建沙盒时将这些 id 填入 `locality.region`。未知区域 id 将返回 **400**。

## API 端点

以下是所有可用的沙盒 API 端点：

| 端点 | 方法 | 路径 | 描述 |
|------|------|------|------|
| create-sandbox | POST | `/v1/sandboxes` | 创建新沙盒 |
| list-scalebox-regions | GET | `/v1/scalebox-regions` | 获取可用区域列表 |
| list-sandboxes | GET | `/v1/sandboxes` | 列出认证用户的所有沙盒 |
| get-sandbox | GET | `/v1/sandboxes/{sandbox_id}` | 获取特定沙盒的详细信息 |
| update-sandbox | PUT | `/v1/sandboxes/{sandbox_id}` | 更新沙盒配置（仅限延长超时时间） |
| delete-sandbox | DELETE | `/v1/sandboxes/{sandbox_id}` | 删除沙盒及其所有关联资源 |
| pause-sandbox | POST | `/v1/sandboxes/{sandbox_id}/pause` | 暂停正在运行的沙盒 |
| resume-sandbox | POST | `/v1/sandboxes/{sandbox_id}/resume` | 恢复已暂停的沙盒 |
| terminate-sandbox | POST | `/v1/sandboxes/{sandbox_id}/terminate` | 强制立即终止沙盒 |
| batch-delete | POST | `/v1/sandboxes/batch-delete` | 批量删除多个沙盒 |
| batch-terminate | POST | `/v1/sandboxes/batch-terminate` | 并发终止多个沙盒 |
| batch-pause | POST | `/v1/sandboxes/batch-pause` | 并发暂停多个正在运行的沙盒 |
| batch-resume | POST | `/v1/sandboxes/batch-resume` | 并发恢复多个已暂停的沙盒 |
| update-timeout | POST | `/v1/sandboxes/{sandbox_id}/timeout` | 独立更新沙盒超时时间 |
| create-template-from-sandbox | POST | `/v1/sandboxes/{sandbox_id}/create-template` | 从正在运行的沙盒创建模板 |
| get-sandbox-ports | GET | `/v1/sandboxes/{sandbox_id}/ports` | 获取沙盒的所有端口 |
| add-sandbox-port | POST | `/v1/sandboxes/{sandbox_id}/ports` | 向正在运行的沙盒添加自定义端口 |
| remove-sandbox-port | DELETE | `/v1/sandboxes/{sandbox_id}/ports/{port}` | 从正在运行的沙盒中删除自定义端口 |
| get-webrtc-turn-credential | GET | `/v1/sandboxes/{sandbox_id}/webrtc-turn-credential` | 获取沙盒的短期 TURN 凭证 |
| exec-start | POST | `/v1/sandboxes/{sandbox_id}/exec` | 运行单条命令（每个沙盒同时最多 1 个） |
| exec-stream | GET | `/v1/sandboxes/{sandbox_id}/exec/stream?token=...` | SSE 输出流（当前运行；需要 token 查询参数） |
| exec-active | GET | `/v1/sandboxes/{sandbox_id}/exec/active` | 查询当前是否有命令在运行（可用于自动 attach） |
| exec-cancel | DELETE | `/v1/sandboxes/{sandbox_id}/exec` | 取消当前运行的命令 |

## create-sandbox

**POST** `/v1/sandboxes`

创建新沙盒。默认（同步）：等待至 running 或 failed。设置 `is_async: true` 可立即返回并轮询状态。

### 请求参数

| 参数 | 类型 | 必需 | 默认值 | 描述 |
|------|------|------|--------|------|
| name | string | 否 | 自动生成 | 人类可读的沙盒名称（0-24个字符，空值将仅使用随机后缀） |
| description | string | 否 | 空 | 沙盒用途的详细描述 |
| template | string | 否 | "base" | 模板名称或ID（例如："python-dev" 或 "tpl-abc123"） |
| project_id | string | 否 | 用户默认 | 要关联沙盒的项目 |
| cpu_count | integer | 否 | 模板默认 | CPU核心数量 |
| memory_mb | integer | 否 | 模板默认 | 内存分配（MB） |
| storage_gb | integer | 否 | 计划最大值的50% | 持久存储（GB）（0 = 使用订阅计划最大值的50%，向上取整） |
| timeout | integer | 否 | 300 | 沙盒超时时间（秒） |
| env_vars | object | 否 | {} | 要在沙盒中设置的环境变量 |
| metadata | object | 否 | {} | 沙盒元数据的自定义键值对 |
| secure | boolean | 否 | true | 沙盒的安全设置 |
| allow_internet_access | boolean | 否 | true | 是否允许沙盒访问互联网 |
| object_storage | object \| array | 否 | null | 单个挂载对象或挂载对象 JSON 数组（多挂载） |
| object_storage_direct_mount | boolean | 否 | false | 仅自定义模板：在 worker 容器挂载对象存储 |
| s3fs_executable_path | string | 否 | 空 | 直接挂载时：worker 上 s3fs 二进制可选路径 |
| custom_ports | array | 否 | [] | 自定义端口配置数组（模板中不存在的端口） |
| locality | object | 否 | null | 可选调度：`{ auto_detect: true }` 或 `{ region: string, force?: boolean }` |
| auto_pause | boolean | 否 | false | 为true时，沙盒超时触发自动暂停而非终止 |
| is_async | boolean | 否 | false | 为true时立即返回（客户端轮询状态） |

## 代理命令执行（Run Command）

在运行中的沙盒里执行一条 shell 命令，并通过 **SSE** 实时流式返回输出。该功能是“通道”而不是“持久化/历史”：

- **每个沙盒同一时间只允许 1 个命令运行**（服务端强制限制）。
- 输出缓冲区仅服务于**当前运行**，runner 结束后会被**及时清理**（不会保存命令历史）。
- 客户端可将 `stdout`/`stderr` 合并渲染成只读终端效果。

### 启动执行

**POST** `/v1/sandboxes/{sandbox_id}/exec`

#### 请求参数

| 字段 | 类型 | 必需 | 描述 |
|------|------|------|------|
| command | string | 是 | 要执行的命令（以 `bash -c` 方式运行） |
| cwd | string | 否 | 工作目录（默认 `/`） |
| env | object | 否 | 额外环境变量（覆盖合并到沙盒环境变量上） |

#### 请求示例

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/exec \
  -H "X-API-Key: sk-..." \
  -H "Content-Type: application/json" \
  -d '{"command":"ls -la /tmp","cwd":"/","env":{}}'
```

### 输出流（SSE）

**GET** `/v1/sandboxes/{sandbox_id}/exec/stream?token=...`

由于 EventSource 不能携带自定义 header，SSE 使用 `token` 查询参数。`token` 等价于你平时在 `Authorization: Bearer <token>` 里使用的访问令牌。

```bash
curl -N "https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/exec/stream?token=$ACCESS_TOKEN"
```

常见事件类型：`ready`、`start`、`stdout`、`stderr`、`keepalive`、`end`、`error`。

### 查询当前是否在运行

**GET** `/v1/sandboxes/{sandbox_id}/exec/active`

若有命令正在运行，返回 `active: true` 以及 `stream_path`、`command`、`cwd`、`started_at`、`deadline`（同一用户）。

### 取消当前执行

**DELETE** `/v1/sandboxes/{sandbox_id}/exec`

### 输出流缓冲说明

命令输出流是面向**当前**运行的短生命周期通道（best-effort）。当达到内部限制时，输出事件可能会被截断，较早的缓冲事件也可能被丢弃。

## 沙盒控制

### pause-sandbox

**POST** `/v1/sandboxes/{sandbox_id}/pause`

暂停正在运行的沙盒。默认（同步）：等待至暂停或回退到运行后返回。设置 `is_async: true` 可立即返回并轮询状态。

#### 请求参数

| 参数 | 类型 | 必需 | 默认值 | 描述 |
|------|------|------|--------|------|
| is_async | boolean | 否 | false | 为true时立即返回（客户端轮询）；为false或省略时等待至 paused 或回退（同步） |

#### 请求示例

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/pause \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{"is_async": false}'
```

### resume-sandbox

**POST** `/v1/sandboxes/{sandbox_id}/resume`

恢复已暂停的沙盒。默认（同步）：等待至运行或回退到暂停后返回。设置 `is_async: true` 可立即返回并轮询状态。

#### 请求参数

| 参数 | 类型 | 必需 | 默认值 | 描述 |
|------|------|------|--------|------|
| is_async | boolean | 否 | false | 为true时立即返回（客户端轮询）；为false或省略时等待至 running 或回退（同步） |

#### 请求示例

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/resume \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{"is_async": false}'
```

## 对象存储

ScaleBox 支持使用 FUSE 将 S3 兼容的对象存储挂载到沙盒中。您可以在创建沙盒时配置对象存储，或在运行时手动挂载。所有沙盒默认都启用了 FUSE 功能。

### 对象存储配置

创建沙盒时，`object_storage` 可为**单个挂载对象**或**挂载对象 JSON 数组**（多挂载）。与沙盒**调度地域** `locality.region`（来自 `GET /v1/scalebox-regions` 的 Scalebox 区域 id）不同，勿与 S3 的 `region` 字段混淆。

可选：`object_storage_direct_mount`（仅自定义模板）、`s3fs_executable_path`（直接挂载时指定 s3fs 路径）。

| 参数 | 类型 | 必需 | 描述 |
|------|------|------|------|
| uri | string | 是 | S3 兼容存储 URI，格式：`s3://bucket-name/path` 或 `oss://bucket-name/path` |
| mount_point | string | 是 | 容器中存储将被挂载的绝对路径 |
| access_key | string | 是 | S3 访问密钥 ID。凭证永远不会存储在数据库中，也不会在 API 响应中返回 |
| secret_key | string | 是 | S3 秘密访问密钥。凭证永远不会存储在数据库中，也不会在 API 响应中返回 |
| region | string | 否 | AWS 区域名称（例如：`us-east-1`、`ap-east-1`）。必须提供 `region` 或 `endpoint` 中的至少一个 |
| endpoint | string | 否 | 自定义 S3 兼容端点 URL。必须提供 `region` 或 `endpoint` 中的至少一个 |

### 自动挂载

如果在创建时配置了对象存储，它将在沙盒启动时自动挂载。
挂载脚本在主应用程序之前运行，确保存储立即可用。

### 运行时手动挂载

所有沙盒都启用了 FUSE 功能（`SYS_ADMIN` 能力和 `/dev/fuse` 设备）。
您可以通过在运行中的容器中执行命令随时手动挂载对象存储：

```bash
# 创建凭证文件
echo "ACCESS_KEY:SECRET_KEY" > /root/.s3fs-credentials
chmod 600 /root/.s3fs-credentials

# 创建挂载点
mkdir -p /mnt/oss

# 挂载 S3 存储桶（对于非默认区域，需要同时指定 url 和 endpoint）
s3fs bucket-name:/path /mnt/oss \
  -o passwd_file=/root/.s3fs-credentials \
  -o url=https://s3.region.amazonaws.com \
  -o endpoint=region
```

<Callout type="info">
**安全提示：** 对象存储凭证永远不会持久化到数据库中。
只有 URI 和挂载点会被存储并在 API 响应中返回。凭证仅在挂载操作期间使用。
</Callout>

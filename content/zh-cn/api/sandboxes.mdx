# ScaleBox 沙盒 API

<Callout type="warn">
**身份验证：** 大多数沙盒接口都要求 `X-API-Key`。

**公开例外：** `GET /v1/scalebox-regions` 为公开接口，密钥可选。
</Callout>

## Scalebox Regions

`GET /v1/scalebox-regions` 返回当前至少有一个可用集群的区域 `id` / `name` 列表。创建沙盒前，先用它取得 `locality.region` 可用值；未知区域会返回 `400`。

## 沙盒状态

| 状态 | 含义 |
|------|------|
| `created` | 已创建，尚未启动 |
| `starting` | 正在启动，常见 `substatus`：`allocating`、`deploying`、`initializing`、`waiting_ready` |
| `running` | 正在运行，可访问 |
| `pausing` | 正在暂停 |
| `paused` | 已暂停，可恢复 |
| `resuming` | 正在恢复 |
| `terminating` | 正在终止 |
| `terminated` | 已终止，不可恢复 |
| `failed` | 创建或运行失败 |

## 响应约定

多数 JSON 接口都返回标准包装：

```json
{
  "success": true,
  "data": {},
  "timestamp": "2026-04-17T12:34:56Z"
}
```

特殊情况：

- `GET /v1/scalebox-regions` 虽然是公开接口，但仍走标准 JSON 包装。
- `POST /v1/sandboxes/{sandbox_id}/exec`、`GET /v1/sandboxes/{sandbox_id}/exec/active`、`DELETE /v1/sandboxes/{sandbox_id}/exec` 返回原始 JSON，不走标准包装。
- `GET /v1/sandboxes/{sandbox_id}/exec/stream` 返回 `text/event-stream`（SSE），不是 JSON。
- `DELETE /v1/sandboxes/{sandbox_id}`、`POST /v1/sandboxes/{sandbox_id}/terminate` 以及批量删除/终止/暂停/恢复接口通常返回 `202 Accepted`，表示操作已异步启动。

## Read Sandbox Object

`GET /v1/sandboxes/{sandbox_id}`，以及同步的暂停/恢复响应，会返回一个完整沙盒对象。当前后端会暴露：

- 身份与归属：`sandbox_id`、`name`、`description`、`status`、`substatus`、`reason`、`template_id`、`template_name`、`template_exists`、`project_id`、`project_name`、`owner`、`account_owner`，以及兼容字段 `user_account_id`、`userName`、`userEmail`、`region`、`visibility`
- 资源与访问：`cpu_count`、`memory_mb`、`storage_gb`、`resources`、`timeout`、`auto_pause`、`secure`、`allow_internet_access`、`sandbox_domain`、`sandbox_domain_internal`、`web_terminal_available`、`web_files_available`、`envd_access_token`
- 配置与挂载：`metadata`、`env_vars`、`object_storage`、`object_storage_single`、`object_storage_direct_mount`、`object_storage_s3fs_path`、`ports`、`template_ports`、`custom_ports`、`template_custom_command`、`template_ready_command`、`template_source`
- 生命周期与时间：`created_at`、`updated_at`、`started_at`、`stopped_at`、`ended_at`、`timeout_at`、`remaining_seconds`、`paused_at`、`pausing_at`、`resumed_at`、`uptime`、`total_paused_seconds`、`total_running_seconds`、`actual_total_paused_seconds`、`actual_total_running_seconds`、`lifecycle_outcome`、`last_accessed_at`
- 持久化与可选辅助字段：`persistence_days`、`persistence_expires_at`、`persistence_days_remaining`，以及可选 `network_proxy`、`webrtc_turn`

## 接口

### Create Sandbox

`POST /v1/sandboxes`

默认同步：等待到 `running` 或 `failed` 后返回。传 `is_async: true` 时会更早返回，由客户端自行轮询。

请求参数：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `name` | string | 否 | 自动生成 | 沙盒名称 |
| `description` | string | 否 | 空 | 沙盒描述 |
| `template` | string | 否 | `"base"` | 模板名或模板 ID |
| `project_id` | string | 否 | 用户默认项目 | 目标项目 |
| `cpu_count` | integer | 否 | 模板默认 | CPU |
| `memory_mb` | integer | 否 | 模板默认 | 内存 |
| `storage_gb` | integer | 否 | 计划上限的约一半 | 持久存储 |
| `timeout` | integer | 否 | `300` | 超时秒数 |
| `env_vars` | object | 否 | `{}` | 环境变量 |
| `metadata` | object | 否 | `{}` | 自定义元数据 |
| `secure` | boolean | 否 | `true` | 安全模式 |
| `allow_internet_access` | boolean | 否 | `true` | 是否允许联网 |
| `object_storage` | object \| array | 否 | `null` | 单挂载对象或挂载对象数组 |
| `object_storage_direct_mount` | boolean | 否 | `false` | 仅自定义模板：直接在 worker 容器挂载对象存储 |
| `s3fs_executable_path` | string | 否 | 空 | 直接挂载时可选的 `s3fs` 路径 |
| `custom_ports` | array | 否 | `[]` | 自定义端口数组 |
| `locality` | object | 否 | `null` | 例如 `{ auto_detect: true }` 或 `{ region: "...", force?: boolean }` |
| `auto_pause` | boolean | 否 | `false` | 超时时自动暂停，而不是终止 |
| `is_async` | boolean | 否 | `false` | 异步创建 |

成功响应：

- `201 Created`
- `data.sandbox_id`、`name`、`description`
- `data.template_id`、`owner_user_id`、`project_id`
- `data.cpu_count`、`memory_mb`、`storage_gb`
- `data.timeout`、`auto_pause`
- `data.secure`、`allow_internet_access`
- `data.metadata`、`env_vars`
- `data.object_storage`
- `data.ports`、`template_ports`、`custom_ports`
- `data.template_custom_command`、`template_ready_command`
- `data.status`、`substatus`、`reason`
- `data.created_at`
- `data.sandbox_domain`、`sandbox_domain_internal`
- `data.web_terminal_available`、`web_files_available`
- `data.envd_access_token`
- `data.persistence_days`、`persistence_expires_at`、`persistence_days_remaining`
- 可选 `data.network_proxy`

### List Scalebox Regions

`GET /v1/scalebox-regions`

成功响应：

- `data.scalebox_regions`：`{ id, name }` 数组；没有可用容量时也可能为空数组

### List Sandboxes

`GET /v1/sandboxes`

查询参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `page` | integer | 否 | 分页页码，默认 `1` |
| `limit` | integer | 否 | 返回数量上限，默认 `20`（别名：`page_size`） |
| `offset` | integer | 否 | 分页偏移量，默认 `0`（别名：`skip`） |

成功响应：

- `data.sandboxes`：沙盒摘要对象数组，字段基本与 **Read Sandbox Object** 一致
- `data.pagination`：分页对象，包含 `page`、`limit`、`offset`、`total`、`total_pages`

### Get Sandbox

`GET /v1/sandboxes/{sandbox_id}`

成功响应：

- `data`：单个 **Read Sandbox Object**

### Update Sandbox

`PUT /v1/sandboxes/{sandbox_id}`

此接口只允许延长当前运行阶段的超时时间。

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `timeout` | integer | 是 | 新超时值，必须大于当前超时值 |

成功响应：

- 顶层 `message: "Sandbox updated successfully"`
- 成功时不返回 `data`

### Delete Sandbox

`DELETE /v1/sandboxes/{sandbox_id}`

删除沙盒。默认 `force=true`，除非显式传 `?force=false`。

成功响应：

- `202 Accepted`
- 顶层 `message: "Sandbox deletion initiated"`
- `data.sandbox_id`
- `data.status`，值为 `deletion_in_progress`
- `data.note`

### Pause Sandbox

`POST /v1/sandboxes/{sandbox_id}/pause`

默认同步：等待到 `paused` 或回退到 `running` 后返回。

请求参数：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `is_async` | boolean | 否 | `false` | `true` 时立即返回，客户端自行轮询 |

成功响应：

- 同步模式：`data` 返回更新后的 **Read Sandbox Object**
- 异步模式：`data` 也返回当前沙盒对象，通常会看到 `status: "pausing"`

### Resume Sandbox

`POST /v1/sandboxes/{sandbox_id}/resume`

默认同步：等待到 `running` 或回退到 `paused` 后返回。

请求参数：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `is_async` | boolean | 否 | `false` | `true` 时立即返回，客户端自行轮询 |
| `object_storage` | object | 否 | `null` | 可选：暂停状态下恢复时的 OSS 增量（仅单沙盒 resume）。三选一：`remove_all`、`disable_all` 或非空 `mounts[]`。见 [恢复时的对象存储补丁](#恢复时的对象存储补丁)。不支持 batch-resume。 |

成功响应：

- 同步模式：`data` 返回更新后的 **Read Sandbox Object**
- 异步模式：`data` 为较小对象，只含 `sandbox_id`、`status: "resuming"`、`message: "Resume operation initiated"`

### Terminate Sandbox

`POST /v1/sandboxes/{sandbox_id}/terminate`

通常返回异步终止结果。

成功响应：

- 常见情况：`202 Accepted`
  - 顶层 `message: "Sandbox termination initiated"`
  - `data.sandbox_id`
  - `data.status`，值为 `termination_in_progress`
  - `data.note`
- 特殊情况：若沙盒已处于终止态，返回 `200 OK`
  - 顶层 `message: "Sandbox is already terminated"`
  - `data.sandbox_id`
  - `data.status: "terminated"`
  - `data.note`

## Proxied Command Exec

在运行中的沙盒里执行一条命令，并通过 **SSE** 流式输出结果。

特性：

- 每个沙盒同一时间只允许一条命令
- 输出通道只对应**当前这次运行**
- 运行结束后缓冲会被清理，不是历史记录接口

### Start Exec

`POST /v1/sandboxes/{sandbox_id}/exec`

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `command` | string | 是 | 用 `bash -c` 执行的命令 |
| `cwd` | string | 否 | 工作目录，默认 `/` |
| `env` | object | 否 | 额外环境变量，会覆盖合并到沙盒环境变量上 |

成功响应：

- 原始 `201 Created` JSON
- `stream_path`
- `started_at`
- `deadline`

### Stream Exec Output

`GET /v1/sandboxes/{sandbox_id}/exec/stream?token=...`

特殊情况：

- 返回 `text/event-stream`
- 浏览器 `EventSource` 不能带自定义 header，因此浏览器端应使用 `token` 查询参数
- 非浏览器客户端可直接用 `X-API-Key`

事件类型：

- `ready`
- `start`
- `stdout`（含 `data_b64`）
- `stderr`（含 `data_b64`）
- `keepalive`
- `end`（含 `exit_code`）
- `error`（含 `code`、`message`）

### Check Active Exec

`GET /v1/sandboxes/{sandbox_id}/exec/active`

成功响应：

- 空闲：原始 JSON `{ "active": false }`
- 运行中：原始 JSON，包含 `active`、`stream_path`、`command`、`cwd`、`started_at`、`deadline`

### Cancel Exec

`DELETE /v1/sandboxes/{sandbox_id}/exec`

成功响应：

- 原始 JSON `{ "cancelled": true }`

## Timeout / Project / Metrics

### Update Timeout

`POST /v1/sandboxes/{sandbox_id}/timeout`

运行中的沙盒：

- 如果新值大于当前已用时长，立即作用于当前阶段
- 否则仅写入数据库，等下一次运行阶段生效

暂停中的沙盒：

- 总是作用于下一次恢复后的运行阶段

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `timeout` | integer | 是 | 新超时秒数 |

成功响应：

- 顶层 `message` 会说明当前阶段还是下一阶段生效
- `data.timeout`
- `data.timeout_at`
- `data.remaining_time`
- `data.applies_to`，值为 `current_phase` 或 `next_phase`
- `data.note`

## Object Storage

创建沙盒时，`object_storage` 可传单个挂载对象或挂载对象数组。注意不要把对象存储的 `region` 与调度区域 `locality.region` 混淆。

对象字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `uri` | string | 是 | `s3://bucket/path` 或 `oss://bucket/path` |
| `mount_point` | string | 是 | 容器内挂载路径 |
| `access_key` | string | 是 | 访问密钥 ID；不会持久化到数据库，也不会在响应中回显 |
| `secret_key` | string | 是 | 访问密钥密文；不会持久化到数据库，也不会在响应中回显 |
| `region` | string | 否 | S3 区域名；与 `endpoint` 至少提供一个 |
| `endpoint` | string | 否 | 自定义 S3 兼容端点 |

### 恢复时的对象存储补丁

沙盒处于**已暂停**时，`POST /v1/sandboxes/{sandbox_id}/resume` 可附带可选的 `object_storage` 增量。无论沙盒当前是否已有挂载，upsert 条目都可在恢复时**添加首个挂载**。仅发送有变更的挂载；后端按 `mount_point` 合并到持久化 slot 记录。

必须**三选一**：`remove_all`、`disable_all` 或非空 `mounts` 数组。空的 `object_storage` 表示无操作。组合多种模式返回 HTTP 400。

**`mounts[]` 条目**（以 `mount_point` 为键）：

- **Upsert**（默认）：包含 `uri`、`access_key`、`secret_key`，以及 `region` 或 `endpoint` 至少一项（与创建时校验相同）。
- **Delete**：`{ "mount_point": "/mnt/x", "delete": true }` — 不要包含 uri/凭证。
- **Disable**：`{ "mount_point": "/mnt/x", "disable": true }` — 不要包含 uri/凭证。

<Callout type="info">
对象存储凭证不会持久化保存；API 响应中只会返回 URI、挂载点等非敏感信息。
</Callout>

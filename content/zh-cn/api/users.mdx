<Callout type="warn">
**需要身份验证：** 所有用户 API 都需要 `X-API-Key` 请求头。
</Callout>

<Callout type="info">
`/v1/users/me` 用于当前用户的自助资料访问；`/v1/user-management/*` 用于账户级用户管理，其中大多数接口需要账户 root 用户。
</Callout>

## 标准响应格式

用户接口使用统一响应包裹：

```json
{
  "success": true,
  "data": {},
  "timestamp": "2026-04-17T12:34:56Z"
}
```

部分变更接口会在顶层返回 `message`，不包含 `data`。

### 更新我的资料

`PUT /v1/users/me`

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| display_name | string | 否 | 新显示名称 |
| description | string | 否 | 新描述 |
| role | string | 否 | 仅 root 用户可更新自己的角色 |
| status | string | 否 | 仅 root 用户可更新自己的状态 |

**响应示例**

```json
{
  "success": true,
  "message": "Profile updated successfully",
  "timestamp": "2026-04-17T12:01:00Z"
}
```

### 列出用户

`GET /v1/user-management/users`

仅账户 root 用户可用。

**查询参数**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | integer | 否 | 分页页码，默认 `1` |
| limit | integer | 否 | 返回用户数量，默认 `50`（别名：`page_size`） |
| offset | integer | 否 | 分页偏移量，默认 `0`（别名：`skip`） |
| status | string | 否 | 可选按状态过滤，例如 `enabled` 或 `disabled` |

**响应示例**

```json
{
  "success": true,
  "data": {
    "users": [
      {
        "user_id": "usr-def456ghi789012",
        "email": "jane@example.com",
        "username": "jane.developer",
        "display_name": "Jane Developer",
        "role": "user",
        "status": "active",
        "is_root_user": false,
        "email_verified": false,
        "created_at": "2026-04-17T12:03:00Z",
        "last_login": null,
        "dedicated_signin_url": "https://app.scalebox.dev/signin/account/acc-123456789"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 50,
      "offset": 0,
      "total": 1,
      "total_pages": 1
    }
  },
  "timestamp": "2026-04-17T12:02:00Z"
}
```

### 创建用户

`POST /v1/user-management/users`

仅账户 root 用户可用。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| email | string | 是 | 用户邮箱 |
| username | string | 是 | 用户名 |
| display_name | string | 否 | 显示名称 |
| role | string | 是 | 用户角色 |
| status | string | 否 | 初始状态 |
| description | string | 否 | 描述 |

**响应示例**

```json
{
  "success": true,
  "data": {
    "message": "User created successfully",
    "user": {
      "user_id": "usr-def456ghi789012",
      "email": "jane@example.com",
      "username": "jane.developer",
      "display_name": "Jane Developer",
      "role": "user",
      "status": "active",
      "email_verified": false
    },
    "initial_password": "",
    "dedicated_signin_url": "https://app.scalebox.dev/signin/account/acc-123456789"
  },
  "timestamp": "2026-04-17T12:03:00Z"
}
```

非管理员新用户通常不会得到初始密码，而是通过邮件验证后设置自己的密码。

### 更新用户

`PUT /v1/user-management/users/{user_id}`

仅账户 root 用户可用。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| display_name | string | 否 | 新显示名称 |
| role | string | 否 | 新角色 |
| status | string | 否 | 新状态 |
| description | string | 否 | 新描述 |

**响应示例**

```json
{
  "success": true,
  "message": "User updated successfully",
  "timestamp": "2026-04-17T12:05:00Z"

```

### 删除用户

`DELETE /v1/user-management/users/{user_id}`

仅账户 root 用户可用。

**响应示例**

```json
{
  "success": true,
  "data": {
    "message": "User deleted successfully. All external resources have been cleaned up.",
    "deleted_empty_projects": 2,
    "deletion_status": "complete",
    "note": "User and all associated resources have been completely removed"
  },
  "timestamp": "2026-04-17T12:06:00Z"
}
```

### 重置用户密码

`POST /v1/user-management/users/{user_id}/reset-password`

仅账户 root 用户可用。

**响应示例**

```json
{
  "success": true,
  "data": {
    "message": "Password reset link has been sent to the user's email. The link will expire in 30 minutes."
  },
  "timestamp": "2026-04-17T12:07:00Z"
}
```

### 修改我的密码

`POST /v1/user-management/change-password`

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| current_password | string | 是 | 当前密码 |
| new_password | string | 是 | 新密码，至少 8 个字符 |

**响应示例**

```json
{
  "success": true,
  "message": "Password changed successfully",
  "timestamp": "2026-04-17T12:08:00Z"
}
```

### 请求我的密码重置邮件

`POST /v1/user-management/request-password-reset`

向当前已认证用户发送密码重置邮件。

**响应示例**

```json
{
  "success": true,
  "message": "Password reset link sent to your email",
  "timestamp": "2026-04-17T12:09:00Z"
}
```

请求过于频繁时可能返回 `429`，并在 `data.time_remaining_minutes` 中给出剩余等待时间。

## 常见错误

```json
{
  "success": false,
  "error": "Only root users can list users",
  "timestamp": "2026-04-17T12:10:00Z"
}
```

- `400`：请求体非法、密码过弱、当前密码错误，或状态变更不允许
- `403`：非 root 用户调用了账户级用户管理接口
- `404`：在当前账户下找不到目标用户
- `429`：密码重置请求过于频繁
- `500`：持久化、邮件发送或资源清理失败

<Callout type="warn">
**需要身份验证：** 所有用量接口都需要 `X-API-Key` 请求头。
</Callout>

<Callout type="info">
汇总、分析、会话和事件接口会按调用者角色自动限域。账户 root 用户审核团队成员的配额申请时，请使用账户管理页中的接口；非 root 用户则使用 `/v1/usage/quota-requests`。
</Callout>

## 响应约定

用量接口使用标准响应包裹：

```json
{
  "success": true,
  "data": {},
  "timestamp": "2026-04-20T12:34:56Z"
}
```

列表接口统一返回 `data.<items>` 与 `data.pagination`。真实分页参数为 `page` 与 `limit`，同时接受别名 `page_size`。

## 接口

### 获取用量汇总

`GET /v1/usage/summary`

查询参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| start | RFC3339 时间 | 否 | 开始时间，默认最近 30 天 |
| end | RFC3339 时间 | 否 | 结束时间，默认当前时间 |
| project_id | string | 否 | 可选项目过滤 |

返回 `data.summary` 与 `data.time_period`。

```json
{
  "success": true,
  "data": {
    "summary": {
      "total_sessions": 18,
      "active_sessions": 2,
      "completed_sessions": 15,
      "failed_sessions": 1,
      "total_cpu_hours": 34.5,
      "total_memory_gb_hours": 96,
      "total_storage_gb_hours": 140.25,
      "avg_session_duration": 4180,
      "total_cost": 12.84
    },
    "time_period": {
      "start": "2026-04-01T00:00:00Z",
      "end": "2026-04-20T00:00:00Z"
    }
  },
  "timestamp": "2026-04-20T12:34:56Z"
}
```

### 获取用量分析

`GET /v1/usage/analytics`

查询参数：`start`、`end`。

返回 `data.summary`，以及 `data.charts` 下的：

- `sessions_over_time`
- `resource_utilization`
- `cost_breakdown`

### 列出用量会话

`GET /v1/usage/sessions`

查询参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | integer | 否 | 页码，默认 `1` |
| limit | integer | 否 | 每页数量，默认 `50` |
| page_size | integer | 否 | `limit` 的别名 |
| start | RFC3339 时间 | 否 | `start_time` 下界 |
| end | RFC3339 时间 | 否 | `start_time` 上界 |

```json

  "data": {
```

| page_size | integer | 否 | `limit` 的别名 |
| start | RFC3339 时间 | 否 | `event_timestamp` 下界 |

| project_id | string | 否 | 项目过滤 |
| resource_type | string | 否 | 资源类型过滤 |

### 获取当前有效配额

`GET /v1/usage/quotas`

返回调用者当前激活的用户配额分配；若没有分配，则返回 `data.quotas: null`。

### 管理我的配额申请

非 root 用户可使用以下接口：

- `GET /v1/usage/quota-requests`
- `POST /v1/usage/quota-requests`
- `PUT /v1/usage/quota-requests/{request_id}`
- `DELETE /v1/usage/quota-requests/{request_id}`

创建与更新请求体字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| cpu_seconds_monthly | int64 | 是 | 每月 CPU 秒数 |
| ram_gb_seconds | number | 否 | RAM GB 秒 |
| sandbox_storage_gb_seconds | number | 否 | 沙箱存储 GB 秒 |
| traffic_gb_seconds | number | 否 | 流量 GB 秒 |
| template_storage_gb | number | 是 | 模板存储 GB |
| concurrent_sandboxes | integer | 否 | `0` 表示用户级不限 |
| reason | string | 是 | 申请原因 |

列表查询参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | string | 否 | 按状态过滤，如 `pending`、`approved`、`denied`、`withdrawn` |
| page | integer | 否 | 页码 |
| limit | integer | 否 | 每页数量 |
| page_size | integer | 否 | `limit` 的别名 |

```json
{
  "success": true,
```

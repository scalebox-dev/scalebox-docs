# ScaleBox 通知 API

通知管理 API 参考。管理用户通知、标记已读状态和删除通知。

<Callout type="warn">
**需要身份验证：** 所有 API 请求都需要使用您的 API 密钥通过 `X-API-Key` 标头进行身份验证。
</Callout>

## API 端点

以下是所有可用的通知管理端点：

| 端点 | 方法 | 路径 | 描述 |
|------|------|------|------|
| list-notifications | GET | `/v1/notifications` | 列出用户的所有通知 |
| get-notification | GET | `/v1/notifications/{notification_id}` | 获取特定通知的详细信息 |
| mark-notification-read | PATCH | `/v1/notifications/{notification_id}/read` | 将通知标记为已读 |
| mark-notification-unread | PATCH | `/v1/notifications/{notification_id}/unread` | 将通知标记为未读 |
| mark-all-notifications-read | PATCH | `/v1/notifications/read-all` | 将所有通知标记为已读 |
| delete-notification | DELETE | `/v1/notifications/{notification_id}` | 删除特定通知 |
| delete-all-notifications | DELETE | `/v1/notifications` | 删除所有通知 |

## list-notifications

**GET** `/v1/notifications`

列出用户的所有通知

### 请求示例

```bash
curl -X GET https://api.scalebox.dev/v1/notifications \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

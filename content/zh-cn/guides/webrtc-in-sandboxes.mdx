# 在沙盒中托管 WebRTC

ScaleBox 提供共享的 STUN/TURN 基础设施，方便你在沙盒内运行实时 WebRTC 应用。本文说明沙盒内应用会收到的**环境变量**，以及**外部客户端**如何获取 TURN 凭证。

## 概述

当沙盒在已启用 WebRTC TURN 的集群上运行时，ScaleBox 会向容器注入与 TURN 相关的环境变量。你的应用用它们获取短期凭证，并告诉浏览器客户端使用哪个 TURN 服务器。TURN 密钥不会离开集群；沙盒通过集群内凭证服务或公开 API/CLI 获取凭证。

## 沙盒内：环境变量

以下变量会注入到集群上**所有**沙盒（因此你可以稍后添加 WebRTC 端口而无需重新部署）。在应用中用它们配置 WebRTC。

| 变量 | 示例 / 含义 | 用途 |
|------|-------------|------|
| `TURN_CREDENTIAL_SERVICE_URL` | `http://turn-credential-service.scalebox.svc.cluster.local:8080` | 集群内凭证服务的基础 URL。应用 GET `/api/turn-credential` 获取浏览器端所需的 `ice_servers`。服务端（集群内）对等体凭证使用 `?internal=1`。 |
| `TURN_PUBLIC_HOST` | `turn.<集群别名>.<基础域名>` | 客户端使用的公网 TURN 主机名。与 `TURN_PUBLIC_PORT`（32543）一起用于构建浏览器的 `ice_servers`。 |
| `TURN_PUBLIC_PORT` | `32543` | 公网 TURN 端口。客户端连接 `TURN_PUBLIC_HOST:TURN_PUBLIC_PORT`。 |
| `COTURN_INTERNAL_HOST` | `coturn.scalebox.svc.cluster.local` | 集群内 coturn 主机。与 `COTURN_INTERNAL_PORT` 一起用于服务端对等体（如沙盒内媒体服务器与 coturn 通信）。 |
| `COTURN_INTERNAL_PORT` | `32543` | 集群内 coturn 端口。 |

### 在应用中的用法

- **浏览器客户端：** 在沙盒内后端 GET `${TURN_CREDENTIAL_SERVICE_URL}/api/turn-credential`。响应包含 `iceServers`（及可选的 `username`/`credential`）。将 `iceServers` 传给客户端的 `RTCPeerConnection`。也可让客户端通过 ScaleBox API 获取凭证（见下方"对外"部分）。
- **服务端对等体**（如沙盒内连接 coturn 的进程）：GET `${TURN_CREDENTIAL_SERVICE_URL}/api/turn-credential?internal=1` 获取 `COTURN_INTERNAL_HOST:COTURN_INTERNAL_PORT` 的凭证。

```javascript
const url = process.env.TURN_CREDENTIAL_SERVICE_URL + '/api/turn-credential';
const res = await fetch(url);
const { iceServers } = await res.json();
// 将 iceServers 用于 RTCPeerConnection
```

## 对外：外部客户端获取凭证

若客户端在沙盒**外**运行（如浏览器或移动应用），需要 TURN 凭证及公网 TURN 主机/端口。有两种获取方式。

### API

使用 API 密钥 **GET** `/v1/sandboxes/{sandbox_id}/webrtc-turn-credential`。沙盒须为**运行中**且至少有一个 **WebRTC 端口**。响应包含 `ice_servers`、`username`、`credential`、`turn_public_host`、`turn_public_port`。将 `ice_servers` 用于 `RTCPeerConnection`。

```bash
curl -X GET https://api.scalebox.dev/v1/sandboxes/sbx-abc123/webrtc-turn-credential \
  -H "X-API-Key: YOUR_API_KEY"
```

### CLI

登录后执行 `scalebox-cli sandbox webrtc-credential <sandbox-id>`。输出为 JSON，含 `ice_servers`、`username`、`credential`、`turn_public_host`、`turn_public_port`。可用 `jq` 提取 `ice_servers`。

```bash
scalebox-cli sandbox webrtc-credential sbx-abc123
```

## 前置条件

- 模板或沙盒至少暴露一个协议为 **WEBRTC** 的端口（API/CLI 凭证接口才能成功）。可通过模板配置或之后使用 `sandbox port add --protocol WEBRTC` 添加。
- 沙盒须处于**运行中**状态才能获取凭证。

端口管理与凭证 API 详见 [沙盒命令](../cli/sandbox-commands) 与 [沙盒 API](../api/sandboxes)。

## 开始使用

按照以下步骤设置 ScaleBox CLI 并准备使用：

<Steps>

### 安装 ScaleBox CLI

为您的平台下载相应的二进制文件并添加到 PATH。

| 平台 | 架构 | 大小 | 下载 |
|------|------|------|------|
| Linux x86_64 | 适用于大多数 Linux 服务器与桌面 | 16MB | [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-linux-amd64-v1.4.6) |
| Linux ARM64 | 适用于 Raspberry Pi、AWS Graviton、Apple Silicon Linux | 15MB | [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-linux-arm64-v1.4.6) |
| macOS Intel | 适用于 Intel 架构 Mac 电脑 | 16MB | [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-darwin-amd64-v1.4.6) |
| macOS Apple Silicon | 适用于 M1/M2/M3 Mac 电脑 | 15MB | [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-darwin-arm64-v1.4.6) |
| Windows x86_64 | 适用于 Windows 10/11 系统 | 16MB | [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-windows-amd64-v1.4.6.exe) |

[了解更多](/zh-cn/cli/installation)

### 使用 API 密钥认证

使用您的 ScaleBox API 密钥登录：

```bash
scalebox-cli auth login --api-key sk-your-key --server-url https://api.scalebox.dev
```

### 浏览可用模板

列出公共模板和您的私人模板：

```bash
scalebox-cli template list
```

### 创建您的第一个沙盒

从模板启动沙盒：

```bash
scalebox-cli sandbox create --template tpl-abc123 --name my-workspace
```

</Steps>

## 常用工作流程

以下是您使用 ScaleBox CLI 最常执行的任务：

<Tabs items={['模板', '沙盒', '高级']}>
  <Tab value="模板">
    ### 模板管理
    
    创建、更新和管理环境模板
    
    ```bash
    # 列出所有模板
    scalebox-cli template list
    
    # 获取模板详情
    scalebox-cli template get tpl-abc123
    
    # 更新模板
    scalebox-cli template update tpl-abc123 --description "更新的模板"
    ```
  </Tab>
  
  <Tab value="沙盒">
    ### 沙盒操作
    
    创建和管理沙盒环境
    
    ```bash
    # 创建沙盒
    scalebox-cli sandbox create --template tpl-abc123
    
    # 列出沙盒
    scalebox-cli sandbox list
    
    # 获取沙盒详情
    scalebox-cli sandbox get sbx-def456
    ```
  </Tab>
  
  <Tab value="高级">
    ### 安全文件操作 (v1.2.2)
    
    通过 HTTPS 上传和下载文件，具有智能冲突检测功能
    
    ```bash
    # 上传文件
    scalebox-cli sandbox upload sbx-abc123 ./data.csv /workspace/data.csv
    
    # 下载文件
    scalebox-cli sandbox download sbx-abc123 /workspace/results.json ./results.json
    ```
  </Tab>
</Tabs>

## 基本命令

按类别组织的最有用命令的快速参考：

<Tabs items={['模板', '沙盒', '认证', '文件']}>
  <Tab value="模板">
    - `scalebox-cli template list` - 列出所有可用模板
    - `scalebox-cli template get tpl-abc123def456789` - 获取模板详情
  </Tab>
  
  <Tab value="沙盒">
    - `scalebox-cli sandbox create --template tpl-abc123 --name my-project` - 创建新沙盒
    - `scalebox-cli sandbox list` - 列出您的沙盒
    - `scalebox-cli sandbox get sbx-def456ghi789012` - 获取沙盒详情和连接信息
  </Tab>
  
  <Tab value="认证">
    - `scalebox-cli auth whoami` - 检查认证状态
    - `scalebox-cli auth whoami` - 查看当前用户信息
  </Tab>
  
  <Tab value="文件">
    - `scalebox-cli sandbox upload sbx-def456 ./data.json /workspace/data.json` - 上传文件到沙盒 (v1.2.2)
    - `scalebox-cli sandbox download sbx-def456 /workspace/results /local/results --recursive` - 从沙盒下载文件 (v1.2.2)
    - `scalebox-cli sandbox ls sbx-def456 /workspace/project` - 列出沙盒目录内容 (v1.2.2)
  </Tab>
</Tabs>

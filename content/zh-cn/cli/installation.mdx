## 安装验证

安装完成后，验证 CLI 是否正常工作：

### 1. 检查版本

```bash
scalebox-cli --version
```

预期输出：`scalebox-cli version 1.4.4 (commit: dev, built: unknown)`

### 2. 查看帮助

```bash
scalebox-cli --help
```

## 命令补全

CLI 可以为 `bash`、`zsh`、`fish` 和 `powershell` 生成补全脚本。

### Bash（当前 shell）

```bash
source <(scalebox-cli completion bash)
```

### PowerShell（当前会话）

```powershell
scalebox-cli completion powershell | Out-String | Invoke-Expression
```

也可以通过 `scalebox-cli completion zsh` 和 `scalebox-cli completion fish` 输出 Zsh 与 Fish 的补全脚本。

## 快速设置

只需几个命令即可开始使用 ScaleBox CLI：

**1. 使用 API 密钥进行身份验证**

```bash
scalebox-cli auth login --api-key your-api-key --server-url https://api.scalebox.dev
```

将 `your-api-key` 替换为 [仪表板](https://www.scalebox.dev/dashboard) 中的实际 API 密钥。

**2. 列出可用模板**

```bash
scalebox-cli template list
```

**3. 创建您的第一个沙盒**

```bash
scalebox-cli sandbox create --template tpl-abc123
```

## 系统要求

### 最低要求

**操作系统**
- Linux (glibc 2.17+)
- macOS 10.12+
- Windows 10+

**依赖项**
- Docker（用于镜像操作）
- HTTPS 网络访问
- ~50MB 磁盘空间

## 安全验证

使用 SHA256 校验和验证下载的二进制文件的完整性：

### 下载校验和

[下载 checksums.txt](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/checksums.txt)

### 在 Linux/macOS 上验证

```bash
sha256sum -c checksums.txt
```

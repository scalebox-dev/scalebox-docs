`scalebox-cli webhook` 命令参考，`webhooks` 是别名。

本页所有命令也支持 `--compact`，用于输出单行 JSON。

## `webhook list`

列出 Webhook 端点。

```bash
scalebox-cli webhook list
```

列表输出使用标准嵌套分页 JSON：

```json
{
  "webhooks": [],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 0,
    "total_pages": 0,
    "offset": 0
  }
}
```

## `webhook create`

创建端点时需要 `--url` 和至少一个 `--event-type`。`--event-type` 可以重复传入，也可以在一次传参中使用逗号分隔。可选参数：`--description`、`--scope`。

```bash
scalebox-cli webhook create \
  --url https://example.com/hooks \
  --event-type sandbox.created,sandbox.terminated \
  --scope account
```

Root 用户默认创建账户级端点，除非显式传入 `--scope user`。

## `webhook get ENDPOINT_ID`

查看单个端点。

```bash
scalebox-cli webhook get wh_123
```

## `webhook update ENDPOINT_ID`

可更新参数：`--url`、`--event-type`、`--description`、`--active`、`--inactive`、`--timeout-seconds`、`--max-retries`、`--scope`。`--active` 与 `--inactive` 只能二选一。

```bash
scalebox-cli webhook update wh_123 --inactive --max-retries 5
```

## `webhook delete ENDPOINT_ID`

永久删除端点。

```bash
scalebox-cli webhook delete wh_123
```

## `webhook deliveries ENDPOINT_ID`

列出最近的投递尝试。支持参数：`--limit`。

```bash
scalebox-cli webhook deliveries wh_123 --limit 30
```

JSON 包装结构为：

```json
{
  "deliveries": [],
  "pagination": {
    "page": 1,
    "limit": 30,
    "total": 0,
    "total_pages": 0,
    "offset": 0
  }
}
```

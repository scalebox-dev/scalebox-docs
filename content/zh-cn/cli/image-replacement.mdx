</Callout>

## 基本用法

替换模板镜像的基本命令格式：

### 基本替换

```bash
# 替换现有模板的容器镜像
scalebox-cli template update tpl-xmmk6trfpg6mv3h9u --image-file ./new-image.tar
```

### 带身份验证的替换

```bash
# 首先进行身份验证（管理员操作需要）
scalebox-cli auth login --api-key sk-your-admin-key --server-url https://api.scalebox.dev

# 替换模板中的镜像
scalebox-cli template update tpl-xmmk6trfpg6mv3h9u --image-file /path/to/code-interpreter-v2.0.tar
```

## 完整工作流程

以下是替换模板镜像的完整步骤：

```bash
# 1. 导出您更新的 Docker 镜像
docker save my-updated-app:latest -o my-app-v2.0.tar

# 2. 替换模板中的镜像
scalebox-cli template update tpl-abc123 --image-file my-app-v2.0.tar

# 3. 验证更新
scalebox-cli template get tpl-abc123
```

## Docker 命令

在替换镜像之前，您需要先导出 Docker 镜像：

<Tabs items={['导出镜像', '导入验证']}>
  <Tab value="导出镜像">
    ```bash
    # 导出 Docker 镜像为 tar 文件
    docker save nginx:1.21 -o nginx-1.21.tar
    
    # 导出多个镜像
    docker save nginx:1.21 postgres:13 -o multi-images.tar
    
    # 压缩镜像文件（可选）
    gzip nginx-1.21.tar
    ```
  </Tab>
  
  <Tab value="导入验证">
    ```bash
    # 从 tar 文件导入镜像（用于验证）
    docker load -i nginx-1.21.tar
    
    # 验证镜像
    docker images | grep nginx
    ```
  </Tab>
</Tabs>

## 最佳实践

### 📦 镜像优化

使用多阶段构建来减小镜像大小，移除不必要的文件和依赖。考虑使用 Alpine Linux 基础镜像来减少镜像体积。

### 🏷️ 版本管理

为您的镜像使用语义化版本标签，例如 `v1.2.3`。避免使用 `latest` 标签，因为它可能导致不一致的行为。

### 🔒 安全考虑

定期更新基础镜像以获取安全补丁。扫描镜像中的漏洞，并确保只包含必要的组件和依赖。

### 📊 测试验证

在替换生产模板之前，先在测试环境中验证新镜像。确保应用程序在新镜像中正常运行，并检查所有功能。

## 故障排除

### ❌ "镜像文件过大"

检查镜像大小，考虑使用 `docker save | gzip` 压缩镜像文件。或者优化镜像，移除不必要的文件和依赖。

### ❌ "上传失败"

检查网络连接和文件权限。确保您有足够的磁盘空间，并且文件路径正确。尝试使用绝对路径。

### ❌ "镜像格式无效"

确保使用 `docker save` 命令导出的标准 tar 格式。不要使用 `docker export`，因为它会丢失镜像元数据。

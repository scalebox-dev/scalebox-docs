## 获取 API 密钥

在开始使用 CLI 之前，您需要从 ScaleBox 仪表板获取 API 密钥：

<Steps>

### 登录仪表板

访问您的 ScaleBox 仪表板并登录到您的账户。

[打开仪表板](https://www.scalebox.dev/dashboard)

### 导航到 API 密钥

在仪表板中，导航到 **设置** → **API 密钥** 部分。

### 创建新密钥

点击 **"创建新 API 密钥"** 按钮，为您的 CLI 使用创建一个描述性名称。

完整密钥**仅在创建成功时显示一次**。请立即复制或下载保存；之后控制台与 API 只能看到前缀，无法再次获取完整密钥。

示例 API 密钥：`sk-1234567890abcdef1234567890abcdef`

</Steps>

## 认证方式

ScaleBox CLI 支持三种认证方式，按优先级自动选择：

### 1. 环境变量（推荐）

```bash
SCALEBOX_API_KEY=sk-1234567890abcdef1234567890abcdef scalebox-cli auth login
```

服务器 URL 是可选的，默认为 `https://api.scalebox.dev`

### 2. 命令行参数

```bash
scalebox-cli auth login --api-key sk-1234567890abcdef1234567890abcdef --server-url https://api.scalebox.dev
```

当需要覆盖环境变量或用于自动化脚本时使用参数方式。

### 3. 交互式模式

```bash
scalebox-cli auth login -i
```

CLI 将安全地提示输入您的 API 密钥（隐藏输入）和服务器 URL，并提供智能默认值。

## 状态检查

验证您的认证状态：

```bash
scalebox-cli auth whoami
```

预期输出：`已认证 - 用户: your-email@example.com`

## 多 Profile 支持

CLI 支持在同一个 `~/.scalebox-cli/config.json` 中保存多个命名凭据 profile。未显式指定时，命令会使用 `current_profile`。

### 保存到命名 profile

```bash
scalebox-cli auth login --profile staging --api-key sk-your-key --server-url https://api.scalebox.dev
```

### 查看与切换 profile

```bash
scalebox-cli auth profile list
scalebox-cli auth profile use prod
scalebox-cli auth profile remove old-staging
```

### 检查配置并临时覆盖活动项

```bash
scalebox-cli auth config
scalebox-cli --profile prod sandbox list
```

Profile 解析顺序为根参数 `--profile`、环境变量 `SCALEBOX_PROFILE`，最后回退到 `current_profile`。

## 登出

从 CLI 中清除保存的认证信息：

```bash
scalebox-cli auth logout
```

这将清除本地保存的认证信息，下次使用时需要重新登录。

## 环境变量

为了安全起见，您可以使用环境变量来存储 API 密钥：

<Tabs items={['Linux/macOS', 'Windows']}>
  <Tab value="Linux/macOS">
    ```bash
    export SCALEBOX_API_KEY=sk-1234567890abcdef1234567890abcdef12345678
    ```
  </Tab>
  
  <Tab value="Windows">
    ```cmd
    set SCALEBOX_API_KEY=sk-1234567890abcdef1234567890abcdef12345678
    ```
  </Tab>
</Tabs>

设置环境变量后，CLI 将自动使用它进行认证，无需在每次使用时输入。

## 故障排除

### 常见问题

**❌ "无效的 API 密钥"**

检查您的 API 密钥是否正确，确保没有多余的空格或字符。在仪表板中验证密钥是否仍然有效。

**❌ "无法通过浏览器登录获取已有密钥"**

若账户已有活跃 API 密钥，CLI 浏览器登录无法从服务器取回完整密钥。请使用本地已保存的密钥（`~/.scalebox-cli/config.json`）、通过 `--api-key` 传入，或在控制台创建新密钥并立即复制保存。

**❌ "密钥遗失"**

完整密钥无法再次从 ScaleBox 获取。请在控制台删除旧密钥（如需要）并创建新密钥，创建后立即复制或下载。

**❌ "连接被拒绝"**

确认服务器 URL 是否正确。默认情况下使用 `https://api.scalebox.dev`。检查您的网络连接和防火墙设置。

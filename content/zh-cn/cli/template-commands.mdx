本页提供 ScaleBox CLI 模板命令的完整参考。模板定义了创建沙盒环境时使用的镜像、默认资源、端口以及运行时设置。

<Callout type="info">
模板创建主要有三条路径：使用 `template build` 从现有 ScaleBox 模板派生，使用 `template create-custom` 直接登记外部镜像，或使用 `template import` 将镜像导入 Harbor 后再注册模板。
</Callout>

## 模板命名规则

模板名称由 API 校验。

- 长度：`4` 到 `32` 个字符
- 允许字符：小写字母（`a-z`）、数字（`0-9`）、连字符（`-`）、下划线（`_`）
- 必须以字母或数字开头和结尾
- 不能以数字开头
- 不能以 `tpl-` 开头
- 不能包含连续分隔符，如 `--`、`__`、`-_`、`_-`

示例：

- 无效：`My Nginx`、`ng`、`1-python`、`tpl-demo`
- 有效：`my-nginx`、`python-data-science`

## 如何选择模板创建方式

| 命令 | 适用场景 | 说明 |
|---|---|---|
| `template build` | 从 ScaleBox 模板派生、本地 Docker 构建，或将外部镜像 / OCI tar 复制到 Harbor | 本机有 Docker 时使用；私有仓库支持 `--username` / `--password` |
| `template create-custom` | 直接登记外部镜像为自定义模板 | 不复制到 Harbor；镜像保留在原仓库（侧车部署） |
| `template import` | 由后端将外部镜像复制到 Harbor 并创建自定义模板 | 无需本机 Docker；用 `template import-jobs` 查看任务 |

## 模板文档命令

长篇 Markdown 文档与模板简短 `description` 字段分开存储。请使用 `scalebox-cli template document` 管理模板文档。

### template document get [template-id-or-name]

默认返回 JSON；使用 `--raw` 可仅输出 Markdown 正文。

| 参数 | 描述 |
|---|---|
| `--raw` | 仅输出 Markdown 正文 |
| `-o`, `--output` | 将输出写入文件，而不是标准输出 |

```bash
scalebox-cli template document get tpl-abc123
scalebox-cli template document get my-template --raw
scalebox-cli template document get tpl-abc123 --raw -o ./GUIDE.md
```

### template document download [template-id-or-name]

将模板 Markdown 文档下载为文件。若文档为空，服务端会拒绝请求。

| 参数 | 描述 |
|---|---|
| `-o`, `--output` | 输出路径（默认：`{template-id}-documentation.md`；使用 `-` 输出到标准输出） |

```bash
scalebox-cli template document download tpl-abc123
scalebox-cli template document download tpl-abc123 -o ./README.md
scalebox-cli template document download tpl-abc123 -o -
```

### template document set [template-id-or-name]

从文件或标准输入上传 Markdown 文档。

| 参数 | 描述 |
|---|---|
| `-f`, `--file` | Markdown 文件路径；省略或使用 `-` 表示标准输入 |

```bash
scalebox-cli template document set tpl-abc123 -f ./guide.md
cat guide.md | scalebox-cli template document set tpl-abc123
```

### template document clear [template-id-or-name]

清除已存储的 Markdown 文档。

```bash
scalebox-cli template document clear tpl-abc123
```

## 命令参考

### template build

构建或发布模板：从 ScaleBox 模板继承、使用本地构建上下文、用 Docker 拉取外部镜像，或加载本地 OCI tar。`--base` / `--base-template-id`、`--external-image-url`、`--image-file` 最多使用其一；若都不提供，则执行本地 Docker 构建并注册为自定义模板。

**外部镜像拉取：** CLI 先调用 `validate-custom-image`，再使用 `--username` / `--password` 拉取（公开镜像可省略）。推送到 Harbor 使用 API 返回的 ScaleBox 凭据。

**本机复制 vs 导入：** 本机有 Docker 时，请用 `template build --external-image-url` 或 `--image-file`，而不是 `template import`。

| 参数 | 类型 | 描述 |
|---|---|---|
| `--name` | string | 模板名称（必填） |
| `--base`, `-b` | string | 用于继承的基础模板名称或 ID；等同于 `--base-template-id` |
| `--base-template-id` | string | 用于继承的基础模板名称或 ID；等同于 `--base` |
| `--external-image-url` | string | 用于创建模板的外部 Docker 镜像 URL（非继承） |
| `--username` | string | 源仓库用户名（配合 `--external-image-url`，私有仓库） |
| `--password` | string | 源仓库密码（配合 `--external-image-url`） |
| `--image-file` | string | 用于创建模板的本地 Docker 镜像文件（`.tar`，非继承） |
| `--dockerfile`, `-d` | string | Dockerfile 路径（默认：`Dockerfile`） |
| `--path` | string | 构建上下文路径（默认：当前目录） |
| `--description` | string | 模板描述 |
| `--cpu` | integer | 默认 CPU 数量（`0` 表示继承基础模板；无基础时默认为 `2`） |
| `--memory` | integer | 默认内存 MB（`0` 表示继承基础模板；无基础时默认为 `2048`） |
| `--ports` | string | 端口配置 JSON 数组 |
| `--reset-ports` | boolean | 移除继承而来的非保护端口，仅保留保护端口 |
| `--override-custom-ports` | boolean | 已弃用的 `--reset-ports` 别名 |
| `--cmd`, `-c` | string | 模板启动命令 |
| `--ready-cmd` | string | 就绪探针 JSON 或普通命令字符串 |
| `--tag`, `-t` | string | 镜像标签（默认：`latest`） |
| `--visibility` | string | `private`（默认）或 `account_shared`；也可先 `private` 再 `template share` |

```bash
scalebox-cli template build --name "my-python-env" --base "python-base"
scalebox-cli template build --name "my-ubuntu-app" --external-image-url "docker.io/library/ubuntu:22.04" --cpu 2 --memory 2048
scalebox-cli template build --name "my-app" \
  --external-image-url "registry.example.com/myapp:v1" \
  --username myuser --password mypass --cpu 2 --memory 2048
scalebox-cli template build --name "custom-jupyter" --image-file "jupyter.tar" --cpu 4 --memory 8192
```

### template create-custom

直接将外部 Docker 镜像登记为自定义模板，不先导入 Harbor。

必须提供 `--external-image-url` 或 `--image` 之一。如果镜像本身没有定义 Entrypoint 或 Cmd，则必须显式传入 `--custom-command`。`--base` 只支持继承另一个自定义模板，不支持继承 ScaleBox family 模板。

| 参数 | 类型 | 描述 |
|---|---|---|
| `--name`, `-n` | string | 模板名称（必填） |
| `--description` | string | 模板描述 |
| `--external-image-url`, `-e` | string | 外部 Docker 镜像 URL（未使用 `--image` 时必填） |
| `--image` | string | `--external-image-url` 的别名 |
| `--username` | string | 私有镜像仓库用户名 |
| `--password` | string | 私有镜像仓库密码 |
| `--cpu` | integer | 默认 CPU 数量（默认：`2`） |
| `--memory` | integer | 默认内存 MB（默认：`2048`） |
| `--ports` | string | 端口配置 JSON 数组 |
| `--base` | string | 可选，自定义模板继承来源 |
| `--visibility` | string | `private`（默认）或 `account_shared` |
| `--custom-command` | string | 自定义模板启动命令 JSON，例如 `{"Entrypoint":["python"],"Cmd":["app.py"]}`；若省略且镜像已有 Entrypoint/Cmd，后端会直接使用镜像定义 |

```bash
scalebox-cli template create-custom \
  --name "official-nginx" \
  --external-image-url docker.io/library/nginx:latest \
  --cpu 1 --memory 512 \
  --ports '[{"port":8888,"name":"sandbox","is_protected":true},{"port":80,"name":"http"}]'

scalebox-cli template create-custom \
  --name "my-app" \
  --image registry.example.com/myapp:v1.0 \
  --username myuser \
  --password mypass \
  --cpu 2 --memory 2048

scalebox-cli template create-custom \
  --name "my-app-v2" \
  --base tpl-custom-v1 \
  --image registry.example.com/myapp:v2.0 \
  --cpu 4
```

### template import

通过**后端导入任务**（`POST /v1/templates/import`）将外部镜像复制到 ScaleBox Harbor。**无需本机 Docker**。结果始终为**自定义**模板（侧车部署）。

与 `template create-custom` 不同，源镜像须定义 Entrypoint 或 Cmd（或传入 `--custom-command`）。不支持 `--base`。用 `template import-jobs` 查看进度。

**本机有 Docker 时**，请改用 `template build --external-image-url` 或 `--image-file`。

| 参数 | 类型 | 描述 |
|---|---|---|
| `--name`, `-n` | string | 模板名称（必填） |
| `--image` | string | 外部 Docker 镜像 URL（必填） |
| `--description` | string | 模板描述 |
| `--custom-command` | string | 自定义模板启动命令 JSON |
| `--username` | string | 私有镜像仓库用户名 |
| `--password` | string | 私有镜像仓库密码 |
| `--cpu` | integer | 默认 CPU 数量（默认：`2`） |
| `--memory` | integer | 默认内存 MB（默认：`2048`） |
| `--ports` | string | 端口配置 JSON 数组 |
| `--visibility` | string | `private`（默认）。import 时 `account_shared` 需账户 root；否则先 `private` 再 `template share` |

```bash
scalebox-cli template import --name "redis-7-2" --image docker.io/library/redis:7.2 --cpu 1 --memory 1024

scalebox-cli template import \
  --name "private-app" \
  --image registry.example.com/myapp:latest \
  --username myuser \
  --password mypass \
  --cpu 2 --memory 4096
```

### template import-jobs

列出或查看模板导入任务。默认只显示进行中的任务。

| 参数 | 类型 | 描述 |
|---|---|---|
| `--all` | boolean | 显示全部任务，而不是仅显示进行中的任务 |
| `--template-id` | string | 仅查看某个模板的任务 |
| `--job-id` | string | 查看单个任务 |
| `--limit` | integer | 返回任务数量上限（默认：`20`） |
| `--offset` | integer | 分页偏移量 |

```bash
scalebox-cli template import-jobs
scalebox-cli template import-jobs --all
scalebox-cli template import-jobs --template-id tpl-abc123
scalebox-cli template import-jobs --job-id job-xyz789
```

使用 JSON 输出时，列表响应采用标准嵌套 `pagination` 对象。

### template list

列出所有可访问模板，并支持过滤、搜索和分页。

| 参数 | 类型 | 描述 |
|---|---|---|
| `--public` | boolean | 仅显示公共模板 |
| `--private` | boolean | 仅显示私有模板 |
| `--search` | string | 按名称或描述搜索 |
| `--lifecycle` | string | 按生命周期状态过滤：`draft`、`testing`、`active`、`deprecated`、`archived` |
| `--approval` | string | 按审批状态过滤：`pending`、`approved`、`rejected` |
| `--page` | integer | 页码（默认：`1`） |
| `--limit` | integer | 每页数量（默认：`20`） |
| `--all` | boolean | 持续抓取所有页，直到列表完整返回 |
| `--max-items` | integer | 配合 `--all` 使用时，抓取到指定数量后停止（`0` 表示不限制） |

```bash
scalebox-cli template list
scalebox-cli template list --public
scalebox-cli template list --private
scalebox-cli template list --search "python"
scalebox-cli template list --lifecycle active --page 2 --limit 10
scalebox-cli template list --all
scalebox-cli template list --all --max-items 200
```

不要将 `--all` 与非默认 `--page` 一起使用。

### template get [template-id]

按模板 ID 获取模板。文本模式下 CLI 只打印简要摘要；JSON 输出模式下会返回 API 返回的完整模板对象。

```bash
scalebox-cli template get tpl-abc123def456789
scalebox-cli template get tpl-xyz789
```

### template dockerfile [template-id-or-name]

从现有模板下载 Dockerfile 模板。

| 参数 | 类型 | 描述 |
|---|---|---|
| `--output`, `-o` | string | 输出文件路径（默认：`Dockerfile`；使用 `-` 输出到标准输出） |

```bash
scalebox-cli template dockerfile base
scalebox-cli template dockerfile tpl-abc123 --output Dockerfile.base
scalebox-cli template dockerfile base --output -
```

### template update [template-id]

更新模板元数据和配置。

| 参数 | 类型 | 描述 |
|---|---|---|
| `--name` | string | 新模板名称 |
| `--description` | string | 新模板描述 |
| `--cpu` | integer | 新 CPU 数量 |
| `--memory` | integer | 新内存 MB |
| `--ports` | string | 端口配置 JSON 数组 |
| `--metadata` | string | 模板元数据 JSON；传空字符串可清空 |
| `--custom-command` | string | 启动命令（`custom` 模板使用 JSON 对象，`scalebox_family` 模板使用纯文本）；传空字符串可清空 |
| `--ready-command` | string | 就绪探针 JSON 或普通 exec 命令；传空字符串可清空 |
| `--image-file` | string | 使用本地 `.tar` 文件替换镜像（受限；见 `scalebox-cli template update --help`） |
| `--image-url` | string | 当前 CLI `--help` 中仍会显示，但实际调用会立刻报“不再支持”错误 |
| `--tag` | string | 当前 CLI `--help` 中仍会显示，但实际调用会立刻报“不再支持”错误 |

当前 CLI 在 `--help` 中仍暴露 `--image-url` 和 `--tag`，但实际使用时命令会直接报错。若要变更模板对应的镜像，请改用 `template build` 或 `template import` 创建新版本。

```bash
scalebox-cli template update tpl-abc123 --name "new-name" --description "Updated description"
scalebox-cli template update tpl-abc123 --cpu 8 --memory 16384
scalebox-cli template update tpl-abc123 --ports '[{"port":8888,"name":"jupyter"}]'
scalebox-cli template update tpl-abc123 --metadata '{"team":"ml"}'
scalebox-cli template update tpl-abc123 --custom-command '{"Entrypoint":["python"],"Cmd":["app.py"]}'
scalebox-cli template update tpl-abc123 --ready-command '{"type":"httpGet","port":8000,"path":"/health"}'
```

### template delete [template-id]

永久删除模板。

当前实现会直接删除；没有可用的 `--force` 参数，也不会弹确认提示，尽管内置帮助文本里仍保留了过时的 `--force` 示例。

```bash
scalebox-cli template delete tpl-abc123
```

### template share [template-id]

将私有模板共享到当前账户，将可见性切换为 `account_shared`。

只有模板拥有者可以执行共享，且模板必须已经处于 active 状态。

| 参数 | 类型 | 描述 |
|---|---|---|
| `--new-name` | string | 如果账户内已有同名共享模板，可使用新名称 |

```bash
scalebox-cli template share tpl-abc123
scalebox-cli template share tpl-abc123 --new-name "my-shared-env"
```

### template unshare [template-id]

将 `account_shared` 模板恢复为私有模板。

只有模板拥有者可以取消共享，且模板必须已经处于 active 状态。

```bash
scalebox-cli template unshare tpl-abc123
```

## 命令配置说明

### build 命令使用的运行命令参数

`template build` 使用：

- `--cmd` 指定启动命令
- `--ready-cmd` 指定就绪探针

就绪探针支持两种形式：

- 普通命令字符串，会按 `exec` 处理
- JSON 对象，`type` 可为 `exec`、`httpGet` 或 `tcpSocket`

示例：

```bash
scalebox-cli template build --name "web-server" --base "python-base" --cmd "python app.py" --ready-cmd '{"type":"httpGet","port":8000,"path":"/health"}'
```

### update / custom template 相关命令的参数命名

`template update` 使用 `--custom-command` 和 `--ready-command`；`template create-custom` 与 `template import` 使用 `--custom-command` 传入自定义模板启动命令。

这些命令不使用 `--cmd` / `--ready-cmd` 这组短参数名。

`template create-custom` 中的自定义启动命令需要使用 `{"Entrypoint":[...],"Cmd":[...]}` 这种 JSON 结构。对于 `template update`，可接受的格式取决于模板来源：`custom` 模板使用 JSON，`scalebox_family` 模板使用纯文本。

## 权限与可见性

- 您可以列出可访问的模板、查看详情、用 `template build` 派生模板、用 `template create-custom` 登记外部镜像、用 `template import` 导入镜像，并更新自己拥有的模板。
- 公共 ScaleBox 模板可作为基础模板使用；您无法修改不属于自己的模板。
- `template build`、`template create-custom` 与 `template import` 的默认可见性均为 `private`。
- 使用 `template share` 可将私有模板在账户内共享为 `account_shared`。
- `template import` 直接设置 `account_shared` 需要账户 root；其他用户请先 `private` 导入，再执行 `template share`。

## 故障排查

### “Template not found”

- 检查模板 ID 或名称是否正确
- 确认您对该模板有访问权限
- 模板 ID 格式通常为 `tpl-...`

### 模板名称不合法

- 仅使用小写字母、数字、连字符和下划线
- 长度保持在 `4` 到 `32` 个字符之间
- 不要以数字或 `tpl-` 开头
- 不要使用连续分隔符，例如 `--`、`__`、`-_`、`_-`

### 构建或导入失败

- `template build` 需要本机安装并运行 Docker（拉取、构建或 `docker load`）
- 私有仓库请为 `template build` 或 `template import` 提供 `--username` 与 `--password`（会在拉取或导入任务开始前校验）
- `template import` 需要集群可用；任务长时间 pending 或失败时请查看 `template import-jobs`
- 传给 `--ports`、`--metadata`、`--custom-command` 或就绪探针参数的 JSON 必须合法

<Callout type="info">
可运行 `scalebox-cli template [command] --help` 查看您当前 CLI 版本对应的精确参数和示例。
</Callout>

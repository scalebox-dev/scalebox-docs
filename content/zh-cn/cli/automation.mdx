在非交互式脚本、定时任务和 CI 流水线中使用 ScaleBox CLI。本页聚焦真正适合自动化的关键点：API 密钥认证、机器可读输出、分页处理，以及异步生命周期轮询。

> 在脚本中优先使用 `auth login --api-key`、`-o json` 或 `-o json-compact`、显式分页参数，以及 `--async` 加轮询来处理较长的沙盒操作。

## 使用非交互方式认证

浏览器登录适合人工操作，但自动化应改用 API 密钥。请通过 CI 系统提供环境变量，不要把密钥硬编码进脚本。

```bash
export SCALEBOX_SERVER_URL="https://api.scalebox.dev"
export SCALEBOX_API_KEY="sk-your-api-key"

scalebox-cli auth login \
  --api-key "$SCALEBOX_API_KEY" \
  --server-url "$SCALEBOX_SERVER_URL"
```

## 选择机器可读输出

自动化场景中不要依赖人类可读表格输出。使用 `-o json` 获取较易读的日志，或使用 `-o json-compact` 进行管道处理。您也可以通过 `SCALEBOX_OUTPUT` 设置默认值。

```bash
export SCALEBOX_OUTPUT=json-compact

scalebox-cli template list --page 1 --limit 10
scalebox-cli sandbox list --page 1 --limit 20
```

## 显式处理分页

像 `template list` 和 `sandbox list` 这样的高频列表命令支持 `--page`、`--limit`、`--all` 和 `--max-items`。在自动化里请明确选择一种模式：

- 需要固定页面时，用 `--page` 搭配 `--limit`。
- 需要遍历完整结果集时，用 `--all`。
- 需要限制运行时间或输出规模时，加上 `--max-items`。

```bash
# 仪表盘或审计任务只取一页
scalebox-cli -o json template list --page 2 --limit 10

# 夜间同步任务遍历全部结果
scalebox-cli -o json-compact sandbox list --all --max-items 200
```

## 异步创建并主动轮询状态

对于运行时间较长的沙盒操作，建议使用异步模式并显式轮询。这样脚本逻辑更稳定，也不会假设创建、暂停或恢复会立刻完成。

```bash
SANDBOX_ID="$(scalebox-cli -o json-compact sandbox create \
  --template tpl-abc123 \
  --name ci-job \
  --async | jq -r '.data.sandbox.id')"

until [ "$(scalebox-cli -o json-compact sandbox get "$SANDBOX_ID" | jq -r '.data.sandbox.status')" = "running" ]; do
  sleep 5
done

scalebox-cli sandbox exec "$SANDBOX_ID" -- echo "ready"
```

## 实用脚本约定

- 在 shell 脚本里开启 `set -euo pipefail`。
- 需要管道处理时优先使用 `json-compact`，再配合 `jq` 等解析器。
- 如果脚本不应打开交互式终端，请在同步创建路径上使用 `--no-terminal`。
- 并非每个列表命令都使用同一套分页参数，编写自动化前请先查看该命令的 `--help`。

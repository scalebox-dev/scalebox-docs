## 快速命令参考

### 🔐 auth login

使用您的 API 密钥与 ScaleBox 进行身份验证

```bash
scalebox-cli auth login --api-key sk-your-key --server-url https://api.scalebox.dev
```

### 📊 auth whoami

检查当前身份验证状态

```bash
scalebox-cli auth whoami
```

### 👤 auth whoami

显示当前认证用户的信息

```bash
scalebox-cli auth whoami
```

### 🚪 auth logout

清除保存的认证信息

```bash
scalebox-cli auth logout
```

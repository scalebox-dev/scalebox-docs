## 基础命令

### `auth login`

使用浏览器登录或 API 密钥登录。可用 `--profile` 将凭据保存到命名 profile。

```bash
scalebox-cli auth login --profile staging --api-key sk-your-key --server-url https://api.scalebox.dev
```

### `auth whoami`

显示当前解析到的 profile 与已认证用户。

```bash
scalebox-cli auth whoami
```

### `auth config`

显示配置文件路径、活动 profile 与当前服务器信息。

```bash
scalebox-cli auth config
```

### `auth logout`

移除当前活动 profile 的已保存认证信息。其他 profile 会保留；要删除指定 profile 请使用 `auth profile remove`。

```bash
scalebox-cli auth logout
```

## Profile 管理

### `auth profile list`

列出所有已保存的凭据 profile，并标出当前活动项。

```bash
scalebox-cli auth profile list
```

### `auth profile use PROFILE_NAME`

切换活动 profile，而无需重新登录。

```bash
scalebox-cli auth profile use prod
```

### `auth profile remove PROFILE_NAME`

从 `~/.scalebox-cli/config.json` 中删除一个已保存 profile。

```bash
scalebox-cli auth profile remove old-staging
```

## Profile 选择顺序

如果没有显式指定 profile，CLI 会依次使用：

1. 根参数 `--profile`
2. 环境变量 `SCALEBOX_PROFILE`
3. `~/.scalebox-cli/config.json` 中的 `current_profile`

```bash
scalebox-cli --profile prod sandbox list
```

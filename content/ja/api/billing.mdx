## 応答規則

課金 API は標準の応答エンベロープを使用します。リスト エンドポイントは、`data.pagination` とともに `data.<items>` を返します。

## エンドポイント

### 請求書の一覧表示

`GET /v1/billing/invoices`

クエリパラメータ:

|名前 |タイプ |必須 |説明 |
|------|------|----------|-------------|
|ページ |整数 |いいえ |ページ番号、デフォルトは `1`。 |
|限界 |整数 |いいえ |ページサイズ。 |
|ページサイズ |整数 |いいえ | `limit` の別名。 |

### 請求書を 1 つ取得する

`GET /v1/billing/invoices/{invoice_id}`

`data.invoices[]` で使用されているのと同じ請求書の形状を返します。

### 現在の請求スナップショットを取得する

`GET /v1/billing/current`

### 統一された請求期間を取得する

`GET /v1/billing/periods`

`data.periods` を返します。最初の項目は現在の現在の期間であり、残りの項目は過去の請求書に裏付けされた期間です。

```json
{
  "success": true,
  "data": {
    "periods": [
      {
        "period_id": "current",
        "period_start": "2026-04-01",
        "period_end": "2026-04-30",
        "plan": "Pro",
        "is_current": true,
        "type": "current_period",
        "subscription_fee": {
          "standard": 20,
          "credit": 0,
          "final": 20

        "usage_cost": {

        "invoice_generated": false,

```

### 請求履歴を取得する

`GET /v1/billing/history`

クエリパラメータ:

|名前 |タイプ |必須 |説明 |
|------|------|----------|-------------|
|開始 | RFC3339 日時 |いいえ |範囲の開始。デフォルトは過去 30 日間です。 |
|終わり | RFC3339 日時 |いいえ |範囲の終わり。デフォルトは現在です。 |

戻り値:

- `data.period`
- `data.total_cost`
- `data.sessions`
- `data.breakdown`
- `data.daily_costs`

### 現在の請求書の生成

`POST /v1/billing/invoice/generate`

アクティブな期間の請求書を作成または更新し、生成された請求書オブジェクトを `data` に返します。

## よくあるエラー

- `400`: 無効な日付範囲または請求書 ID
- `403`: 請求書は別のアカウントに属しています
- `404`: 請求書が見つかりません
- `500`: 請求集計または請求書の生成に失敗しました

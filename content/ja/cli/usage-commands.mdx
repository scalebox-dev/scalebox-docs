`scalebox-cli usage` コマンドのリファレンス。

このページのすべてのコマンドは、1 行の JSON 出力の `--compact` も受け入れます。時間フィルターは、RFC3339 (例: `2026-04-01T00:00:00Z`) を使用します。

## 概要と分析

- `usage summary`: 時間範囲の使用状況の概要。フラグ: `--start`、`--end`、`--project-id`。
- `usage analytics`: チャートの分析ペイロード。フラグ: `--start`、`--end`。
- `usage quotas`: 効果的なクォータ割り当てを表示します。

```bash
scalebox-cli usage summary --start 2026-04-01T00:00:00Z --end 2026-04-30T23:59:59Z
scalebox-cli usage analytics --start 2026-04-01T00:00:00Z --end 2026-04-30T23:59:59Z
scalebox-cli usage quotas
```

## `usage sessions`

使用セッションをリストします。フラグ: `--start`、`--end`、`--page`、`--page-size`。

```bash
scalebox-cli usage sessions --page 1 --page-size 50
```

正規のページ分割された JSON:

```json
{
  "sessions": [],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 0,
    "total_pages": 0,
    "offset": 0
  }
}
```

## `usage events`

使用状況イベントをリストします。フラグ: `--start`、`--end`、`--page`、`--page-size`、`--project-id`、`--resource-type`、`--usage-type`。

```bash
scalebox-cli usage events --project-id prj_123 --usage-type cpu --page 1 --page-size 50
```

JSON エンベロープは、`events` に加えて、同じネストされた `pagination` オブジェクトを使用します。

## クォータのリクエスト

これらのコマンドは非 root ユーザー向けです。

- `usage quota-requests-list` とオプションの `--status`
- `usage quota-request-submit`
- `usage quota-request-update REQUEST_ID`
- `usage quota-request-withdraw REQUEST_ID`

送信して更新するには、次のクォータ フラグを受け入れます: `--cpu-seconds-monthly`、`--ram-gb-seconds`、`--sandbox-storage-gb-seconds`、`--traffic-gb-seconds`、`--template-storage-gb`、`--concurrent-sandboxes`、および必須の `--reason`。

```bash
scalebox-cli usage quota-requests-list --status pending
scalebox-cli usage quota-request-submit --cpu-seconds-monthly 500000 --template-storage-gb 50 --reason "Monthly growth"
scalebox-cli usage quota-request-update req_123 --cpu-seconds-monthly 750000 --template-storage-gb 80 --reason "Updated estimate"
scalebox-cli usage quota-request-withdraw req_123
```

`quota-requests-list` は次を返します:

```json
{
  "requests": [],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 0,
    "total_pages": 0,
    "offset": 0
  }
}
```

Download and install the ScaleBox CLI to manage templates and sandboxes from the command line. Available for Linux, macOS, and Windows with native binaries and no dependencies.

<Callout type="info">
**✨ Latest release: ScaleBox CLI v1.3.7**

- **v1.3.7** — `sandbox create --async` exits after the API accepts the create (no CLI polling); use `scalebox-cli sandbox get <id>` for status. `--no-terminal` skips the interactive terminal after a sync create reaches `running` (CI/scripts).
- **v1.3.6** — `template document` subcommands (`get`, `download`, `set`, `clear`) for long-form Markdown template docs.
- **v1.3.5** — `sandbox regions`, locality on create, inline JSON for `--object-storage` and `--ports`. Earlier: `template build --image-file`, WebRTC TURN, port management.
</Callout>

## Installation Verification

After installation, verify that the CLI is working correctly:

### 1. Check Version

```bash
scalebox-cli --version
```

Expected output: `scalebox-cli version 1.3.7 (commit: dev, built: unknown)`

### 2. View Help

```bash
scalebox-cli --help
```

## Quick Setup

Get started with the ScaleBox CLI in just a few commands:

**1. Authenticate with your API key**

```bash
scalebox-cli auth login --api-key your-api-key --server-url https://api.scalebox.dev
```

Replace `your-api-key` with your actual API key from the [dashboard](https://www.scalebox.dev/dashboard).

**2. List available templates**

```bash
scalebox-cli template list
```

**3. Create your first sandbox**

```bash
scalebox-cli sandbox create --template tpl-abc123
```

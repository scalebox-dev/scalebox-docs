## Platform Downloads

Choose the appropriate binary for your platform. All binaries are statically compiled and require no additional dependencies.

### Download Links

- **Linux x86_64**: [Download](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-linux-amd64-v1.2.9) (14MB) - For most Linux servers and desktops
- **Linux ARM64**: [Download](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-linux-arm64-v1.2.9) (14MB) - For Raspberry Pi, AWS Graviton, Apple Silicon Linux
- **macOS Intel**: [Download](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-darwin-amd64-v1.2.9) (15MB) - For Intel-based Mac computers

- **Windows x86_64**: [Download](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-windows-amd64-v1.2.9.exe) (15MB) - For Windows 10/11 systems

### Installation Steps

1. Download the binary for your platform
2. Make it executable (Linux/macOS): `chmod +x scalebox-cli`
3. Move to a directory in your PATH (e.g., `/usr/local/bin` or `~/bin`)
4. Verify installation: `scalebox-cli --version`

## Installation Verification

After installation, verify that the CLI is working correctly:

### 1. Check Version

```bash
scalebox-cli --version
```

**Expected output:**
```
scalebox-cli version 1.2.9 (commit: dev, built: unknown)
```

### 2. View Help

```bash
scalebox-cli --help
```

This should display the CLI help menu with all available commands.

## Quick Setup

Get started with the ScaleBox CLI in just a few commands:

### 1. Authenticate with your API key

```bash
scalebox-cli auth login --api-key your-api-key --server-url https://api.scalebox.dev
```

Replace `your-api-key` with your actual API key from the dashboard.

### 2. List available templates

```bash
scalebox-cli template list
```

### 3. Create your first sandbox

```bash
scalebox-cli sandbox create --template tpl-abc123
```

## Security Verification

Verify the integrity of downloaded binaries using SHA256 checksums:

### Download Checksums

Download the checksums file:
- [checksums.txt](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/checksums.txt)

### Verify on Linux/macOS

```bash
sha256sum -c checksums.txt
```

This will verify all downloaded binaries against their expected checksums.

### Verify on Windows

Use PowerShell to verify checksums:

```powershell
Get-FileHash scalebox-cli.exe -Algorithm SHA256
```

Compare the output with the checksum in the checksums.txt file.

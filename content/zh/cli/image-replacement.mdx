# ScaleBox CLI 镜像替换

替换任何模板中的容器镜像，同时保留所有元数据、配置和模板设置。这个强大的功能允许您更新底层容器内容，而不影响模板属性。

**新功能**

## 纯 Docker 操作

此功能执行纯 Docker 操作，作为 Harbor 注册表管理的包装器。CLI 处理镜像加载、标记和推送，同时保持模板配置不变。

## 快速示例

用一个命令替换模板的容器镜像：

```bash
# 替换现有模板的容器镜像
scalebox-cli template update tpl-xmmk6trfpg6mv3h9u --image-file ./new-image.tar
```

**此操作的作用：**
- 从 `./new-image.tar` 加载您的新镜像
- 使用模板现有的 Harbor 路径标记它
- 推送到 Harbor，替换现有镜像
- 保持所有模板元数据不变

## 要求

在使用镜像替换之前，请确保您具备以下条件：

### 需要管理员 API 密钥

镜像替换需要管理员级别的权限来修改 Harbor 注册表镜像。

### Docker 镜像文件 (.tar)

源镜像必须使用 `docker save` 命令导出为 tar 文件。

### Docker 服务运行中

本地 Docker 守护进程必须运行才能加载和标记替换镜像。

### 有效的模板 ID

目标模板必须存在，并且可以使用您的 API 密钥访问。

## 工作原理

镜像替换过程遵循以下步骤来安全地更新容器内容：

### 步骤 1：从文件加载镜像

CLI 将 Docker 镜像从您的 tar 文件加载到本地 Docker 守护进程中。

### 步骤 2：为 Harbor 标记

镜像使用现有的 Harbor 项目、存储库和标记名称进行标记。

### 步骤 3：推送到 Harbor

新镜像内容被推送到 Harbor，替换现有镜像。

### 步骤 4：模板保持不变

所有模板元数据保持不变 - 仅更新容器内容。

## 使用场景

镜像替换特别适用于以下场景：

### 安全更新

快速将安全补丁应用到基础镜像，而无需重新创建模板。

### 错误修复

部署应用程序修复，同时保持沙盒兼容性。

### 配置更改

更新环境变量、依赖项或运行时配置。

### 版本升级

更新语言运行时、框架或系统包。

## 分步指南

### 准备

#### 1. 准备您的 Docker 镜像

**构建或更新您的镜像：**
```bash
docker build -t my-app:v2.0 .
```

**导出为 tar 文件：**
```bash
docker save my-app:v2.0 -o my-app-v2.0.tar
```

### 替换

#### 2. 替换模板镜像

**使用管理员密钥进行身份验证：**
```bash
scalebox-cli auth login --api-key sk-your-admin-key --server-url https://api.scalebox.dev
```

**执行镜像替换：**
```bash
scalebox-cli template update tpl-your-template-id --image-file my-app-v2.0.tar
```

**预期输出：** 您将看到加载、标记和推送镜像的进度消息。

### 验证

#### 3. 验证更新

**检查模板详情：**
```bash
scalebox-cli template get tpl-your-template-id
```

**使用新沙盒进行测试：**
```bash
scalebox-cli sandbox create --template tpl-your-template-id --name test-updated-image
```

## 完整工作流程示例

以下是更新模板的完整端到端示例：

```bash
# 1. 导出您更新的 Docker 镜像
docker save my-updated-app:latest -o my-app-v2.0.tar

# 2. 替换模板中的镜像
scalebox-cli template update tpl-abc123def456789 --image-file my-app-v2.0.tar

# 3. 验证更新
scalebox-cli template get tpl-abc123def456789
```

## 故障排除

### "身份验证失败"

**解决方案：** 确保您使用的是管理员 API 密钥，而不是普通用户密钥。

**检查：** `scalebox-cli auth whoami` 以验证您的身份验证。

### "找不到镜像文件"

**解决方案：** 使用绝对路径或确保文件存在：`ls -la your-image.tar`

**检查：** 文件必须是使用 `docker save` 创建的有效 Docker tar 归档。

### "Docker 守护进程未运行"

**解决方案：** 启动 Docker：`sudo systemctl start docker`（Linux）或启动 Docker Desktop。

**检查：** `docker version` 应该显示客户端和服务器版本。

### "Harbor 推送失败"

**解决方案：** 检查与 Harbor 注册表的网络连接。

**检查：** 验证 Harbor 凭据与后端有效。

# ScaleBox CLI 身份验证

学习如何配置 ScaleBox CLI 以安全地连接到您的 ScaleBox 实例。支持多种身份验证方式：环境变量、命令行参数和交互式输入。

## 安全提醒

请妥善保管您的 API 密钥。不要在代码中硬编码或提交到版本控制系统。建议使用环境变量或配置文件来管理敏感信息。

## 获取 API 密钥

在开始使用 CLI 之前，您需要从 ScaleBox 仪表板获取 API 密钥：

### 1. 登录仪表板

访问您的 ScaleBox 仪表板并登录到您的账户。

### 2. 导航到 API 密钥

在仪表板中，导航到 **设置** → **API 密钥** 部分。

### 3. 创建新密钥

点击 **"创建新 API 密钥"** 按钮，为您的 CLI 使用创建一个描述性名称。

**示例 API 密钥：**
```
sk-1234567890abcdef1234567890abcdef
```

## 认证方式

ScaleBox CLI 支持三种认证方式，按优先级自动选择：

### 1. 环境变量（推荐）

```bash
SCALEBOX_API_KEY=sk-1234567890abcdef1234567890abcdef12345678 scalebox-cli auth login
```

服务器 URL 是可选的，默认为 `https://api.scalebox.dev`

### 2. 命令行参数

```bash
scalebox-cli auth login --api-key sk-1234567890abcdef1234567890abcdef12345678 --server-url https://api.scalebox.dev
```

当需要覆盖环境变量或用于自动化脚本时使用参数方式。

### 3. 交互式模式

```bash
scalebox-cli auth login -i
```

CLI 将安全地提示输入您的 API 密钥（隐藏输入）和服务器 URL，并提供智能默认值。

## 快速示例

以下是使用不同方式登录的快速示例：

### 交互式登录

运行登录命令，CLI 将提示您输入 API 密钥：

```bash
scalebox-cli auth login
```

CLI 将提示您输入 API 密钥和服务器 URL。输入时，密钥将被隐藏以确保安全。

### 命令行登录

直接在命令中指定 API 密钥和服务器 URL：

```bash
scalebox-cli auth login --api-key sk-1234567890abcdef1234567890abcdef12345678 --server-url https://api.scalebox.dev
```

## 状态检查

验证您的认证状态：

### 检查认证状态

```bash
scalebox-cli auth whoami
```

**预期输出：** `已认证 - 用户: your-email@example.com`

## 登出

从 CLI 中清除保存的认证信息：

### 登出命令

```bash
scalebox-cli auth logout
```

这将清除本地保存的认证信息，下次使用时需要重新登录。

## 环境变量

为了安全起见，您可以使用环境变量来存储 API 密钥：

### 设置环境变量

**Linux/macOS:**
```bash
export SCALEBOX_API_KEY=sk-1234567890abcdef1234567890abcdef12345678
```

**Windows:**
```powershell
set SCALEBOX_API_KEY=sk-1234567890abcdef1234567890abcdef12345678
```

设置环境变量后，CLI 将自动使用它进行认证，无需在每次使用时输入。

## 故障排除

### 常见问题

**❌ "无效的 API 密钥"**

检查您的 API 密钥是否正确，确保没有多余的空格或字符。在仪表板中验证密钥是否仍然有效。

**❌ "连接被拒绝"**

确认服务器 URL 是否正确。默认情况下使用 `https://api.scalebox.dev`。检查您的网络连接和防火墙设置。

**❌ "认证已过期"**

您的 API 密钥可能已过期或被撤销。在仪表板中检查密钥状态，必要时创建新的 API 密钥。

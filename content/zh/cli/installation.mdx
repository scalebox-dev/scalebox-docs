## 平台下载

选择适合您平台的二进制文件。所有二进制文件都是静态编译的，无需额外依赖。

### 下载链接

- **Linux x86_64**: [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-linux-amd64-v1.2.9) (14MB) - 适用于大多数 Linux 服务器和桌面
- **Linux ARM64**: [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-linux-arm64-v1.2.9) (14MB) - 适用于 Raspberry Pi、AWS Graviton、Apple Silicon Linux
- **macOS Intel**: [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-darwin-amd64-v1.2.9) (15MB) - 适用于 Intel 架构的 Mac 电脑
- **macOS Apple Silicon**: [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-darwin-arm64-v1.2.9) (14MB) - 适用于 M1/M2/M3 Mac 电脑
- **Windows x86_64**: [下载](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/scalebox-cli-windows-amd64-v1.2.9.exe) (15MB) - 适用于 Windows 10/11 系统

### 安装步骤

1. 下载适合您平台的二进制文件
2. 使其可执行（Linux/macOS）：`chmod +x scalebox-cli`
3. 移动到 PATH 中的目录（例如，`/usr/local/bin` 或 `~/bin`）
4. 验证安装：`scalebox-cli --version`

## 安装验证

安装完成后，验证 CLI 是否正常工作：

### 1. 检查版本

```bash
scalebox-cli --version
```

**预期输出：**
```
scalebox-cli version 1.2.9 (commit: dev, built: unknown)
```

### 2. 查看帮助

```bash
scalebox-cli --help
```

这应该显示包含所有可用命令的 CLI 帮助菜单。

## 快速设置

只需几个命令即可开始使用 ScaleBox CLI：

### 1. 使用 API 密钥进行身份验证

```bash
scalebox-cli auth login --api-key your-api-key --server-url https://api.scalebox.dev
```

将 `your-api-key` 替换为仪表板中的实际 API 密钥。

### 2. 列出可用模板

```bash
scalebox-cli template list
```

### 3. 创建您的第一个沙盒

```bash
scalebox-cli sandbox create --template tpl-abc123
```

## 安全验证

使用 SHA256 校验和验证下载的二进制文件的完整性：

### 下载校验和

下载校验和文件：
- [checksums.txt](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/checksums.txt)

### 在 Linux/macOS 上验证

```bash
sha256sum -c checksums.txt
```

这将验证所有下载的二进制文件与其预期的校验和。

### 在 Windows 上验证

使用 PowerShell 验证校验和：

```powershell
Get-FileHash scalebox-cli.exe -Algorithm SHA256
```

将输出与 checksums.txt 文件中的校验和进行比较。

# API 参考

ScaleBox 的完整 API 参考，这是一个用于创建和管理隔离开发环境的现代平台。本文档提供了所有可用端点、身份验证方法和使用示例的全面信息。

## 开始使用

要使用 ScaleBox API，您需要进行身份验证。所有 API 请求都需要以下之一：`X-API-Key` 标头、`Authorization: Api-Key` 或 `Authorization: Bearer`。

### 基础配置

- **基础 URL：** `https://api.scalebox.dev`
- **API 版本：** `v1`
- **身份验证：** `X-API-Key` 标头

## 核心概念

### RESTful API

所有端点都遵循 REST 约定，使用标准 HTTP 方法（GET、POST、PUT、DELETE）和 JSON 请求/响应格式。

### 基于资源

API 资源围绕沙盒、项目、模板和用户组织，具有清晰的层次关系。

### 安全身份验证

所有请求都需要 API 密钥身份验证，并为不同的用户角色提供适当的作用域和访问控制。

### 实时更新

支持 Webhook，用于资源状态更改时的实时通知和状态更新。

```

```

## 速率限制

API 请求受到速率限制，以确保公平使用。限制按 API 密钥应用并定期重置。

| 套餐 | 速率限制 |
|------|----------|
| 标准套餐 | 1,000 请求/小时 |
| 专业套餐 | 10,000 请求/小时 |
| 企业版 | 自定义限制 |

## 错误处理

API 使用标准 HTTP 状态代码，并在请求失败时以 JSON 格式返回详细的错误消息。

| 状态代码 | 描述 |
|----------|------|
| 400 | 错误请求（参数无效） |
| 401 | 未授权（API 密钥无效） |
| 403 | 禁止访问（权限不足） |
| 404 | 未找到（资源不存在） |
| 429 | 请求过多（超过速率限制） |
| 500 | 内部服务器错误 |

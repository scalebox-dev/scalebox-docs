## 需要身份验证

所有 API 请求都需要使用 `X-API-Key` 标头和您的 API 密钥进行身份验证。

## 通知概念

ScaleBox 中的通知让您及时了解重要事件、系统更改和资源状态更新。

### 通知功能

- **实时更新：** 重要事件发生时立即收到通知
- **优先级级别：** 低、中、高优先级分类
- **资源上下文：** 链接到特定沙盒、模板或系统资源的通知
- **批量管理：** 一次高效管理多个通知

## 通知类型

不同类型的通知，让您了解各种事件：

| 类型 | 描述 |
|------|------|
| `sandbox_timeout` | 沙盒接近其超时限制 |
| `sandbox_failed` | 沙盒启动失败或遇到错误 |
| `template_build_complete` | 模板构建过程已成功完成 |
| `template_build_failed` | 模板构建过程失败 |
| `account_quota_warning` | 账户接近资源配额限制 |
| `cluster_connectivity` | 检测到集群连接问题 |
| `system_maintenance` | 系统维护通知 |

## 优先级级别

通知按优先级分类，帮助您专注于最重要的项目：

| 优先级 | 描述 |
|--------|------|
| `low` | 不需要立即采取行动的信息性通知 |
| `medium` | 应该审查的重要通知 |
| `high` | 需要立即关注的关键通知 |

## API 端点

### 列出通知

**GET** `/v1/notifications`

列出已认证用户的所有通知。

**查询参数：**

| 参数 | 类型 | 必需 | 默认值 | 描述 |
|------|------|------|--------|------|
| `limit` | integer | 否 | 50 | 要返回的通知数量（1-100） |
| `offset` | integer | 否 | 0 | 要跳过的通知数量 |
| `status` | string | 否 | all | 按状态过滤：'read'、'unread' 或 'all' |
| `type` | string | 否 | all | 按通知类型过滤 |

**示例请求：**

```bash
curl -X GET "https://api.scalebox.dev/v1/notifications?limit=20&status=unread" \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### 获取通知

**GET** `/v1/notifications/{notification_id}`

获取特定通知的详细信息。

**示例请求：**

```bash
curl -X GET https://api.scalebox.dev/v1/notifications/ntf-abc123def456789 \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### 标记通知为已读

**PATCH** `/v1/notifications/{notification_id}/read`

将特定通知标记为已读。

**示例请求：**

```bash

  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### 全部标记为已读

**PATCH** `/v1/notifications/read-all`

将已认证用户的所有通知标记为已读。

**示例请求：**

```bash

  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### 删除所有通知

**DELETE** `/v1/notifications`

删除已认证用户的所有通知。

**示例请求：**

```bash
curl -X DELETE https://api.scalebox.dev/v1/notifications \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### 批量删除通知

**DELETE** `/v1/notifications/bulk-delete`

删除多个特定通知。

**请求参数：**

| 参数 | 类型 | 必需 | 描述 |
|------|------|------|------|
| `notification_ids` | array | 是 | 要删除的通知 ID 数组 |

**示例请求：**

```bash
curl -X DELETE https://api.scalebox.dev/v1/notifications/bulk-delete \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "notification_ids": ["ntf-abc123def456789", "ntf-def456ghi789012"]
  }'
```

## 批量操作

通知 API 支持高效的批量操作来管理多个通知：

- **批量标记为已读/未读：** 在单个请求中将多个通知标记为已读或未读
- **批量删除：** 一次删除多个特定通知或所有通知
- **批处理：** 所有批量操作为每个项目返回详细的成功/失败信息

## 错误处理

常见错误场景及处理方法：

- **无效的通知 ID：** 返回 404 未找到 - 验证通知是否存在且属于您的账户
- **无效的请求格式：** 对于格式错误的数组或无效的 JSON，返回 400 错误请求
- **访问控制：** 用户只能访问其账户内自己的通知
- **速率限制：** 批量操作有限制以防止滥用 - 通常每个请求 100 个项目

## HTTP 状态代码

API 返回的标准 HTTP 状态代码：

| 代码 | 描述 |
|------|------|
| 200 | 成功 |
| 204 | 无内容 |
| 400 | 错误请求 |
| 401 | 未授权 |
| 403 | 禁止访问 |
| 404 | 未找到 |
| 500 | 内部服务器错误 |

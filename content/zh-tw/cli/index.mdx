# CLI 概覽

ScaleBox CLI 是一個強大的命令列工具，讓您能夠直接從終端管理沙盒環境、模板和專案。

## 快速開始

開始使用 ScaleBox CLI：

1. [安裝 CLI](./installation) - 安裝和設定說明
2. [身份驗證](./authentication) - 設定您的 API 憑證
3. [快速開始](./quick-start) - 您的第一個 CLI 命令

## 可用命令

- [認證命令](./auth-commands) - 登入、登出和管理會話
- [沙盒命令](./sandbox-commands) - 建立和管理沙盒
- [模板命令](./template-commands) - 管理容器模板
- [映象替換](./image-replacement) - 替換容器映象
- [自動化](./automation) - 自動化工作流程

## 功能特點

- 🚀 **快速高效** - 毫秒級響應，流暢的使用體驗
- 🔐 **安全可靠** - 使用 API 金鑰進行安全認證
- 🎯 **直觀易用** - 清晰的命令結構和說明
- 🔄 **即時同步** - 與 Web 介面完全同步

## 系統要求

- Linux、macOS 或 Windows
- Python 3.8 或更高版本（用於 Python CLI）
- 或 Node.js 14+ （用於 npm 安裝）

## 取得幫助

在任何命令後新增 `--help` 標誌以獲取詳細說明：

```bash
scalebox --help
scalebox sandbox --help
scalebox sandbox create --help
```

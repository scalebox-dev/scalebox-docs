本頁提供 ScaleBox CLI 模板命令的完整參考。模板定義了建立沙盒環境時使用的映像、預設資源、連接埠以及執行時設定。

<Callout type="info">
模板建立主要有三條路徑：使用 `template build` 從現有 ScaleBox 模板衍生，使用 `template create-custom` 直接登記外部映像，或使用 `template import` 將映像匯入 Harbor 後再註冊模板。
</Callout>

## 模板命名規則

模板名稱由 API 驗證。

- 長度：`4` 到 `32` 個字元
- 允許字元：小寫字母（`a-z`）、數字（`0-9`）、連字號（`-`）、底線（`_`）
- 必須以英數字元開頭與結尾
- 不能以數字開頭
- 不能以 `tpl-` 開頭
- 不能包含連續分隔符號，例如 `--`、`__`、`-_`、`_-`

範例：

- 無效：`My Nginx`、`ng`、`1-python`、`tpl-demo`
- 有效：`my-nginx`、`python-data-science`

## 如何選擇模板建立方式

| 命令 | 適用情境 | 說明 |
|---|---|---|
| `template build` | 從 ScaleBox 模板衍生、本地 Docker 建置，或將外部映像 / OCI tar 複製到 Harbor | 本機有 Docker 時使用；私有倉庫支援 `--username` / `--password` |
| `template create-custom` | 直接將外部映像登記為自訂模板 | 不複製到 Harbor；映像保留在原倉庫（側車部署） |
| `template import` | 由後端將外部映像複製到 Harbor 並建立自訂模板 | 無需本機 Docker；用 `template import-jobs` 查看任務 |

## 模板文件命令

長篇 Markdown 文件與模板簡短 `description` 欄位分開儲存。請使用 `scalebox-cli template document` 管理模板文件。

### template document get [template-id-or-name]

預設回傳 JSON；使用 `--raw` 可僅輸出 Markdown 內容。

| 參數 | 描述 |
|---|---|
| `--raw` | 僅輸出 Markdown 內容 |
| `-o`, `--output` | 將輸出寫入檔案，而不是標準輸出 |

```bash
scalebox-cli template document get tpl-abc123
scalebox-cli template document get my-template --raw
scalebox-cli template document get tpl-abc123 --raw -o ./GUIDE.md
```

### template document download [template-id-or-name]

將模板 Markdown 文件下載為檔案。若文件為空，伺服器會拒絕請求。

| 參數 | 描述 |
|---|---|
| `-o`, `--output` | 輸出路徑（預設：`{template-id}-documentation.md`；使用 `-` 輸出到標準輸出） |

```bash
scalebox-cli template document download tpl-abc123
scalebox-cli template document download tpl-abc123 -o ./README.md
scalebox-cli template document download tpl-abc123 -o -
```

### template document set [template-id-or-name]

從檔案或標準輸入上傳 Markdown 文件。

| 參數 | 描述 |
|---|---|
| `-f`, `--file` | Markdown 檔案路徑；省略或使用 `-` 表示標準輸入 |

```bash
scalebox-cli template document set tpl-abc123 -f ./guide.md
cat guide.md | scalebox-cli template document set tpl-abc123
```

### template document clear [template-id-or-name]

清除已儲存的 Markdown 文件。

```bash
scalebox-cli template document clear tpl-abc123
```

## 命令參考

### template build

建置或發布模板：從 ScaleBox 模板衍生、使用本地建置內容、以 Docker 拉取外部映像，或載入本地 OCI tar。`--base` / `--base-template-id`、`--external-image-url`、`--image-file` 最多使用其一；若都未提供，則執行本地 Docker 建置並註冊為自訂模板。

**外部映像拉取：** CLI 先呼叫 `validate-custom-image`，再以 `--username` / `--password` 拉取（公開映像可省略）。推送到 Harbor 使用 API 回傳的 ScaleBox 憑證。

**本機複製 vs 匯入：** 本機有 Docker 時，請用 `template build --external-image-url` 或 `--image-file`，而不是 `template import`。

| 參數 | 類型 | 描述 |
|---|---|---|
| `--name` | string | 模板名稱（必填） |
| `--base`, `-b` | string | 用於繼承的基礎模板名稱或 ID；等同於 `--base-template-id` |
| `--base-template-id` | string | 用於繼承的基礎模板名稱或 ID；等同於 `--base` |
| `--external-image-url` | string | 用於建立模板的外部 Docker 映像 URL（非繼承） |
| `--username` | string | 源倉庫使用者名稱（配合 `--external-image-url`，私有倉庫） |
| `--password` | string | 源倉庫密碼（配合 `--external-image-url`） |
| `--image-file` | string | 用於建立模板的本地 Docker 映像檔（`.tar`，非繼承） |
| `--dockerfile`, `-d` | string | Dockerfile 路徑（預設：`Dockerfile`） |
| `--path` | string | 建置內容路徑（預設：目前目錄） |
| `--description` | string | 模板描述 |
| `--cpu` | integer | 預設 CPU 數量（`0` 表示繼承基礎模板；無基礎時預設 `2`） |
| `--memory` | integer | 預設記憶體 MB（`0` 表示繼承基礎模板；無基礎時預設 `2048`） |
| `--ports` | string | 連接埠設定 JSON 陣列 |
| `--reset-ports` | boolean | 移除繼承而來的非保護連接埠，只保留保護連接埠 |
| `--override-custom-ports` | boolean | 已棄用的 `--reset-ports` 別名 |
| `--cmd`, `-c` | string | 模板啟動命令 |
| `--ready-cmd` | string | 就緒探針 JSON 或一般命令字串 |
| `--tag`, `-t` | string | 映像標籤（預設：`latest`） |
| `--visibility` | string | `private`（預設）或 `account_shared`；亦可先 `private` 再 `template share` |

```bash
scalebox-cli template build --name "my-python-env" --base "python-base"
scalebox-cli template build --name "my-ubuntu-app" --external-image-url "docker.io/library/ubuntu:22.04" --cpu 2 --memory 2048
scalebox-cli template build --name "my-app" \
  --external-image-url "registry.example.com/myapp:v1" \
  --username myuser --password mypass --cpu 2 --memory 2048
scalebox-cli template build --name "custom-jupyter" --image-file "jupyter.tar" --cpu 4 --memory 8192
```

### template create-custom

直接將外部 Docker 映像登記為自訂模板，不先匯入 Harbor。

必須提供 `--external-image-url` 或 `--image` 其中之一。如果映像本身沒有定義 Entrypoint 或 Cmd，則必須明確提供 `--custom-command`。`--base` 只支援繼承另一個自訂模板，不支援繼承 ScaleBox family 模板。

| 參數 | 類型 | 描述 |
|---|---|---|
| `--name`, `-n` | string | 模板名稱（必填） |
| `--description` | string | 模板描述 |
| `--external-image-url`, `-e` | string | 外部 Docker 映像 URL（未使用 `--image` 時必填） |
| `--image` | string | `--external-image-url` 的別名 |
| `--username` | string | 私有映像倉庫使用者名稱 |
| `--password` | string | 私有映像倉庫密碼 |
| `--cpu` | integer | 預設 CPU 數量（預設：`2`） |
| `--memory` | integer | 預設記憶體 MB（預設：`2048`） |
| `--ports` | string | 連接埠設定 JSON 陣列 |
| `--base` | string | 可選，自訂模板的繼承來源 |
| `--visibility` | string | `private`（預設）或 `account_shared` |
| `--custom-command` | string | 自訂模板啟動命令 JSON，例如 `{"Entrypoint":["python"],"Cmd":["app.py"]}`；若省略且映像已有 Entrypoint/Cmd，後端會直接使用映像定義 |

```bash
scalebox-cli template create-custom \
  --name "official-nginx" \
  --external-image-url docker.io/library/nginx:latest \
  --cpu 1 --memory 512 \
  --ports '[{"port":8888,"name":"sandbox","is_protected":true},{"port":80,"name":"http"}]'

scalebox-cli template create-custom \
  --name "my-app" \
  --image registry.example.com/myapp:v1.0 \
  --username myuser \
  --password mypass \
  --cpu 2 --memory 2048

scalebox-cli template create-custom \
  --name "my-app-v2" \
  --base tpl-custom-v1 \
  --image registry.example.com/myapp:v2.0 \
  --cpu 4
```

### template import

透過**後端匯入任務**（`POST /v1/templates/import`）將外部映像複製到 ScaleBox Harbor。**無需本機 Docker**。結果始終為**自訂**模板（側車部署）。

與 `template create-custom` 不同，來源映像須定義 Entrypoint 或 Cmd（或傳入 `--custom-command`）。不支援 `--base`。用 `template import-jobs` 查看進度。

**本機有 Docker 時**，請改用 `template build --external-image-url` 或 `--image-file`。

| 參數 | 類型 | 描述 |
|---|---|---|
| `--name`, `-n` | string | 模板名稱（必填） |
| `--image` | string | 外部 Docker 映像 URL（必填） |
| `--description` | string | 模板描述 |
| `--custom-command` | string | 自訂模板啟動命令 JSON |
| `--username` | string | 私有映像倉庫使用者名稱 |
| `--password` | string | 私有映像倉庫密碼 |
| `--cpu` | integer | 預設 CPU 數量（預設：`2`） |
| `--memory` | integer | 預設記憶體 MB（預設：`2048`） |
| `--ports` | string | 連接埠設定 JSON 陣列 |
| `--visibility` | string | `private`（預設）。import 時 `account_shared` 需帳戶 root；否則先 `private` 再 `template share` |

```bash
scalebox-cli template import --name "redis-7-2" --image docker.io/library/redis:7.2 --cpu 1 --memory 1024

scalebox-cli template import \
  --name "private-app" \
  --image registry.example.com/myapp:latest \
  --username myuser \
  --password mypass \
  --cpu 2 --memory 4096
```

### template import-jobs

列出或檢視模板匯入任務。預設只顯示進行中的任務。

| 參數 | 類型 | 描述 |
|---|---|---|
| `--all` | boolean | 顯示全部任務，而不只是進行中的任務 |
| `--template-id` | string | 僅檢視某個模板的任務 |
| `--job-id` | string | 檢視單一任務 |
| `--limit` | integer | 回傳任務數量上限（預設：`20`） |
| `--offset` | integer | 分頁偏移量 |

```bash
scalebox-cli template import-jobs
scalebox-cli template import-jobs --all
scalebox-cli template import-jobs --template-id tpl-abc123
scalebox-cli template import-jobs --job-id job-xyz789
```

使用 JSON 輸出時，清單回應採用標準巢狀 `pagination` 物件。

### template list

列出所有可存取模板，並支援篩選、搜尋與分頁。

| 參數 | 類型 | 描述 |
|---|---|---|
| `--public` | boolean | 僅顯示公開模板 |
| `--private` | boolean | 僅顯示私有模板 |
| `--search` | string | 依名稱或描述搜尋 |
| `--lifecycle` | string | 依生命週期狀態篩選：`draft`、`testing`、`active`、`deprecated`、`archived` |
| `--approval` | string | 依審核狀態篩選：`pending`、`approved`、`rejected` |
| `--page` | integer | 頁碼（預設：`1`） |
| `--limit` | integer | 每頁數量（預設：`20`） |
| `--all` | boolean | 持續抓取所有頁，直到完整回傳 |
| `--max-items` | integer | 搭配 `--all` 使用時，抓取到指定數量後停止（`0` 表示不限制） |

```bash
scalebox-cli template list
scalebox-cli template list --public
scalebox-cli template list --private
scalebox-cli template list --search "python"
scalebox-cli template list --lifecycle active --page 2 --limit 10
scalebox-cli template list --all
scalebox-cli template list --all --max-items 200
```

不要將 `--all` 與非預設 `--page` 一起使用。

### template get [template-id]

依模板 ID 取得模板。文字模式下 CLI 只會列印精簡摘要；JSON 輸出模式下則會回傳 API 提供的完整模板物件。

```bash
scalebox-cli template get tpl-abc123def456789
scalebox-cli template get tpl-xyz789
```

### template dockerfile [template-id-or-name]

從現有模板下載 Dockerfile 範本。

| 參數 | 類型 | 描述 |
|---|---|---|
| `--output`, `-o` | string | 輸出檔案路徑（預設：`Dockerfile`；使用 `-` 輸出到標準輸出） |

```bash
scalebox-cli template dockerfile base
scalebox-cli template dockerfile tpl-abc123 --output Dockerfile.base
scalebox-cli template dockerfile base --output -
```

### template update [template-id]

更新模板中繼資料與設定。

| 參數 | 類型 | 描述 |
|---|---|---|
| `--name` | string | 新模板名稱 |
| `--description` | string | 新模板描述 |
| `--cpu` | integer | 新 CPU 數量 |
| `--memory` | integer | 新記憶體 MB |
| `--ports` | string | 連接埠設定 JSON 陣列 |
| `--metadata` | string | 模板中繼資料 JSON；傳入空字串可清空 |
| `--custom-command` | string | 啟動命令（`custom` 模板使用 JSON 物件，`scalebox_family` 模板使用純文字）；傳入空字串可清空 |
| `--ready-command` | string | 就緒探針 JSON 或一般 exec 命令；傳入空字串可清空 |
| `--image-file` | string | 使用本地 `.tar` 檔替換映像（受限；見 `scalebox-cli template update --help`） |
| `--image-url` | string | 目前 CLI `--help` 仍會顯示，但實際呼叫時會立刻報「不再支援」錯誤 |
| `--tag` | string | 目前 CLI `--help` 仍會顯示，但實際呼叫時會立刻報「不再支援」錯誤 |

目前 CLI 在 `--help` 中仍暴露 `--image-url` 和 `--tag`，但實際使用時命令會直接報錯。若要變更模板對應的映像，請改用 `template build` 或 `template import` 建立新版本。

```bash
scalebox-cli template update tpl-abc123 --name "new-name" --description "Updated description"
scalebox-cli template update tpl-abc123 --cpu 8 --memory 16384
scalebox-cli template update tpl-abc123 --ports '[{"port":8888,"name":"jupyter"}]'
scalebox-cli template update tpl-abc123 --metadata '{"team":"ml"}'
scalebox-cli template update tpl-abc123 --custom-command '{"Entrypoint":["python"],"Cmd":["app.py"]}'
scalebox-cli template update tpl-abc123 --ready-command '{"type":"httpGet","port":8000,"path":"/health"}'
```

### template delete [template-id]

永久刪除模板。

目前實作會直接刪除；沒有可用的 `--force` 旗標，也不會出現確認提示，即使內建說明文字仍保留了過時的 `--force` 範例。

```bash
scalebox-cli template delete tpl-abc123
```

### template share [template-id]

將私有模板共享到目前帳戶，將可見性切換為 `account_shared`。

只有模板擁有者可以執行共享，而且模板必須已經處於 active 狀態。

| 參數 | 類型 | 描述 |
|---|---|---|
| `--new-name` | string | 若帳戶內已有同名共享模板，可改用新名稱 |

```bash
scalebox-cli template share tpl-abc123
scalebox-cli template share tpl-abc123 --new-name "my-shared-env"
```

### template unshare [template-id]

將 `account_shared` 模板恢復為私有模板。

只有模板擁有者或管理員可以取消共享，而且模板必須已經處於 active 狀態。CLI 說明也特別指出，此操作會把映像複製到您的私有 Harbor 專案。

```bash
scalebox-cli template unshare tpl-abc123
```

## 命令設定說明

### build 命令使用的執行命令參數

`template build` 使用：

- `--cmd` 指定啟動命令
- `--ready-cmd` 指定就緒探針

就緒探針支援兩種形式：

- 一般命令字串，會依 `exec` 處理
- JSON 物件，`type` 可為 `exec`、`httpGet` 或 `tcpSocket`

範例：

```bash
scalebox-cli template build --name "web-server" --base "python-base" --cmd "python app.py" --ready-cmd '{"type":"httpGet","port":8000,"path":"/health"}'
```

### update / custom template 相關命令的參數命名

`template update` 使用 `--custom-command` 和 `--ready-command`；`template create-custom` 與 `template import` 使用 `--custom-command` 傳入自訂模板啟動命令。

這些命令不使用 `--cmd` / `--ready-cmd` 這組短參數名稱。

`template create-custom` 的自訂啟動命令需使用 `{"Entrypoint":[...],"Cmd":[...]}` 這種 JSON 結構。對於 `template update`，可接受的格式取決於模板來源：`custom` 模板使用 JSON，`scalebox_family` 模板使用純文字。

## 權限與可見性

- 您可以列出可存取的模板、檢視詳情、用 `template build` 衍生模板、用 `template create-custom` 登記外部映像、用 `template import` 匯入映像，並更新自己擁有的模板。
- 公共 ScaleBox 模板可作為基礎模板使用；您無法修改不屬於自己的模板。
- `template build`、`template create-custom` 與 `template import` 的預設可見性均為 `private`。
- 使用 `template share` 可將私有模板在帳戶內共享為 `account_shared`。
- `template import` 直接設定 `account_shared` 需要帳戶 root；其他使用者請先 `private` 匯入，再執行 `template share`。

## 疑難排解

### "Template not found"

- 檢查模板 ID 或名稱是否正確
- 確認您對該模板具有存取權限
- 模板 ID 通常採用 `tpl-...` 格式

### 模板名稱不合法

- 僅使用小寫字母、數字、連字號與底線
- 長度保持在 `4` 到 `32` 個字元之間
- 不要以數字或 `tpl-` 開頭
- 不要使用連續分隔符號，例如 `--`、`__`、`-_`、`_-`

### 建置或匯入失敗

- `template build` 需要本機安裝並執行 Docker（拉取、建置或 `docker load`）
- 私有倉庫請為 `template build` 或 `template import` 提供 `--username` 與 `--password`（會在拉取或匯入任務開始前驗證）
- `template import` 需要叢集可用；任務長時間 pending 或失敗時請查看 `template import-jobs`
- 傳給 `--ports`、`--metadata`、`--custom-command` 或就緒探針參數的 JSON 必須合法

<Callout type="info">
可執行 `scalebox-cli template [command] --help` 查看您目前 CLI 版本對應的精確參數與範例。
</Callout>

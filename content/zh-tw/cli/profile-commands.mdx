`scalebox-cli profile` 命令參考。

本頁所有命令也支援 `--compact`，用於輸出單行 JSON。

## `profile show`

查看目前使用者資料。

```bash
scalebox-cli profile show
```

## `profile update`

更新 `--display-name` 和/或 `--description`。如果兩個參數都不傳，CLI 會報錯。

```bash
scalebox-cli profile update --display-name "Jane Doe" --description "Platform engineer"
```

## `profile change-password`

使用已驗證的原地改密流程修改目前使用者密碼，必須同時傳入 `--current-password` 和 `--new-password`，且提交的兩個值不能相同。若帳戶尚未建立本地密碼，請改走郵件重設流程。

```bash
scalebox-cli profile change-password --current-password oldpass --new-password newpass123
```

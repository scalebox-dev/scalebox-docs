`scalebox-cli user` 命令參考。

本頁所有命令也支援 `--compact`，用於輸出單行 JSON。

## `user show`

查看目前已驗證使用者。

```bash
scalebox-cli user show
```

## `user update`

更新 `--display-name` 和/或 `--description`。如果兩個參數都不傳，CLI 會報錯。

```bash
scalebox-cli user update --display-name "Jane Doe" --description "Platform engineer"
```

## `user change-password`

使用已驗證的原地改密流程修改目前已驗證使用者密碼，必須同時傳入 `--current-password` 和 `--new-password`，且提交的兩個值不能相同。若帳戶尚未建立本地密碼，請改走郵件重設流程。

```bash
scalebox-cli user change-password --current-password oldpass --new-password newpass123
```

`scalebox-cli webhook` 命令參考，`webhooks` 是別名。

本頁所有命令也支援 `--compact`，用於輸出單行 JSON。

## `webhook list`

列出 Webhook 端點。

```bash
scalebox-cli webhook list
```

列表輸出使用標準巢狀分頁 JSON：

```json
{
  "webhooks": [],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 0,
    "total_pages": 0,
    "offset": 0
  }
}
```

## `webhook create`

建立端點時需要 `--url` 和至少一個 `--event-type`。`--event-type` 可以重複傳入，也可以在一次傳參中使用逗號分隔。可選參數：`--description`、`--scope`。

```bash
scalebox-cli webhook create \
  --url https://example.com/hooks \
  --event-type sandbox.created,sandbox.terminated \
  --scope account
```

Root 使用者預設建立帳戶層級端點，除非明確傳入 `--scope user`。

## `webhook get ENDPOINT_ID`

查看單一端點。

```bash
scalebox-cli webhook get wh_123
```

## `webhook update ENDPOINT_ID`

可更新參數：`--url`、`--event-type`、`--description`、`--active`、`--inactive`、`--timeout-seconds`、`--max-retries`、`--scope`。`--active` 與 `--inactive` 只能二選一。

```bash
scalebox-cli webhook update wh_123 --inactive --max-retries 5
```

## `webhook delete ENDPOINT_ID`

永久刪除端點。

```bash
scalebox-cli webhook delete wh_123
```

## `webhook deliveries ENDPOINT_ID`

列出最近的投遞嘗試。支援參數：`--limit`。

```bash
scalebox-cli webhook deliveries wh_123 --limit 30
```

JSON 包裝結構為：

```json
{
  "deliveries": [],
  "pagination": {
    "page": 1,
    "limit": 30,
    "total": 0,
    "total_pages": 0,
    "offset": 0
  }
}
```

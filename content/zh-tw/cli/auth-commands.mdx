## 基礎命令

### `auth login`

使用瀏覽器登入或 API 金鑰登入。可用 `--profile` 將憑證儲存到命名 profile。

```bash
scalebox-cli auth login --profile staging --api-key sk-your-key --server-url https://api.scalebox.dev
```

### `auth whoami`

顯示目前解析到的 profile 與已驗證使用者。

```bash
scalebox-cli auth whoami
```

### `auth config`

顯示設定檔路徑、活動 profile 與目前伺服器資訊。

```bash
scalebox-cli auth config
```

### `auth logout`

移除目前使用中 profile 的儲存憑證。其他 profile 會保留；若要刪除指定 profile 請使用 `auth profile remove`。

```bash
scalebox-cli auth logout
```

## Profile 管理

### `auth profile list`

列出所有已儲存的憑證 profile，並標出目前活動項。

```bash
scalebox-cli auth profile list
```

### `auth profile use PROFILE_NAME`

切換活動 profile，而不需要重新登入。

```bash
scalebox-cli auth profile use prod
```

### `auth profile remove PROFILE_NAME`

從 `~/.scalebox-cli/config.json` 中移除一個已儲存 profile。

```bash
scalebox-cli auth profile remove old-staging
```

## Profile 選擇順序

如果沒有顯式指定 profile，CLI 會依序使用：

1. 根旗標 `--profile`
2. 環境變數 `SCALEBOX_PROFILE`
3. `~/.scalebox-cli/config.json` 中的 `current_profile`

```bash
scalebox-cli --profile prod sandbox list
```

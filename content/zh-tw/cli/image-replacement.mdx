<Callout type="info" icon="✨">
**新功能：映象替換**

使用 `--image-file` 引數，您可以上傳自定義的 Docker 映象來替換模板中的預設映象。
</Callout>

## 基本用法

替換模板映象的基本命令格式：

### 基本替換

```bash
# 替換現有模板的容器映象
scalebox-cli template update tpl-xmmk6trfpg6mv3h9u --image-file ./new-image.tar
```

### 帶身份驗證的替換

```bash
# 首先進行身份驗證（管理員操作需要）
scalebox-cli auth login --api-key sk-your-admin-key --server-url https://api.scalebox.dev

# 替換模板中的映象
scalebox-cli template update tpl-xmmk6trfpg6mv3h9u --image-file /path/to/code-interpreter-v2.0.tar
```

## 完整工作流程

以下是替換模板映象的完整步驟：

```bash
# 1. 匯出您更新的 Docker 映象
docker save my-updated-app:latest -o my-app-v2.0.tar

# 2. 替換模板中的映象
scalebox-cli template update tpl-abc123 --image-file my-app-v2.0.tar

# 3. 驗證更新
scalebox-cli template get tpl-abc123
```

## Docker 命令

在替換映象之前，您需要先匯出 Docker 映象：

<Tabs items={['匯出映象', '匯入驗證']}>

<Tab value="匯出映象">
### 匯出 Docker 映象

```bash
# 匯出 Docker 映象為 tar 檔案
docker save nginx:1.21 -o nginx-1.21.tar

# 匯出多個映象
docker save nginx:1.21 postgres:13 -o multi-images.tar

# 壓縮映象檔案（可選）
gzip nginx-1.21.tar
```
</Tab>

<Tab value="匯入驗證">
### 匯入和驗證映象

```bash
# 從 tar 檔案匯入映象（用於驗證）
docker load -i nginx-1.21.tar

# 驗證映象
docker images | grep nginx
```
</Tab>

</Tabs>

## 最佳實踐

### 📦 映象最佳化

使用多階段構建來減小映象大小，移除不必要的檔案和依賴。
考慮使用 Alpine Linux 基礎映象來減少映象體積。

### 🏷️ 版本管理

為您的映象使用語義化版本標籤，例如 `v1.2.3`。
避免使用 `latest` 標籤，因為它可能導致不一致的行為。

### 🔒 安全考慮

定期更新基礎映象以獲取安全補丁。掃描映象中的漏洞，
並確保只包含必要的元件和依賴。

### 📊 測試驗證

在替換生產模板之前，先在測試環境中驗證新映象。
確保應用程式在新映象中正常執行，並檢查所有功能。

## 故障排除

### ❌ "映象檔案過大"

檢查映象大小，考慮使用 `docker save | gzip` 壓縮映象檔案。
或者最佳化映象，移除不必要的檔案和依賴。

### ❌ "上傳失敗"

檢查網路連線和檔案許可權。確保您有足夠的磁碟空間，
並且檔案路徑正確。嘗試使用絕對路徑。

### ❌ "映象格式無效"

確保使用 `docker save` 命令匯出的標準 tar 格式。
不要使用 `docker export`，因為它會丟失映象後設資料。

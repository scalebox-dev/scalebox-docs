下載並安裝 ScaleBox CLI 工具，從命令列管理範本和沙盒。
支援 Linux、macOS 和 Windows 平台，提供原生二進位檔案，無需額外相依性。

<Callout type="info">
**✨ 最新版本：ScaleBox CLI v1.4.1**

- **v1.4.1** — 已刷新本次發佈的二進位下載連結，並補上這一輪 CLI/API 密碼流程文件。`profile change-password` 現在與郵件重設流程分開說明，同時明確要求提交的 `new-password` 不能與 `current-password` 相同。
- **v1.3.8** — `sandbox run-code` 與 `sandbox run-code-context` 透過沙盒代理呼叫 Jupyter ExecutionService（進階能力；適用於 **code-interpreter** 或其**衍生**範本；詳見 `scalebox-cli sandbox run-code --help`）。其他範本請用 `sandbox exec` 執行 shell。
- **v1.3.7** — `sandbox create --async` 在 API 接受建立後即結束，CLI 不輪詢 `running`；請用 `scalebox-cli sandbox get <id>` 查看狀態。`--no-terminal` 在同步建立到達 `running` 後略過互動式終端機（CI/腳本）。
- **v1.3.6** — `template document` 子命令（`get`、`download`、`set`、`clear`）。
- **v1.3.5** — `sandbox regions`、地域與 `--object-storage` / `--ports` 行內 JSON。更早：`template build --image-file`、WebRTC TURN、連接埠管理。
</Callout>

## 安裝驗證

安裝完成後，驗證 CLI 是否正常運作：

### 1. 檢查版本

```bash
scalebox-cli --version
```

預期輸出：`scalebox-cli version 1.4.1 (commit: dev, built: unknown)`

### 2. 檢視說明

```bash
scalebox-cli --help
```

## 快速設定

只需幾個指令即可開始使用 ScaleBox CLI：

### 1. 使用 API 金鑰進行身份驗證

```bash
scalebox-cli auth login --api-key your-api-key --server-url https://api.scalebox.dev
```

將 `your-api-key` 替換為 [儀表板](https://www.scalebox.dev/dashboard) 中的實際 API 金鑰。

### 2. 列出可用範本

```bash
scalebox-cli template list
```

### 3. 建立您的第一個沙盒

```bash
scalebox-cli sandbox create --template tpl-abc123
```

## 系統需求

### 最低需求

**作業系統**
- Linux (glibc 2.17+)
- macOS 10.12+
- Windows 10+

**相依性**
- Docker（用於映像檔操作）
- HTTPS 網路存取
- ~50MB 磁碟空間

## 安全驗證

使用 SHA256 校驗和驗證下載的二進位檔案的完整性：

### 下載校驗和

[下載 checksums.txt](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/checksums.txt)

鎖定此版本：[checksums-v1.4.1.txt](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/checksums-v1.4.1.txt)

### 在 Linux/macOS 上驗證

```bash
sha256sum -c checksums.txt
```

## 安裝驗證

安裝完成後，驗證 CLI 是否正常運作：

### 1. 檢查版本

```bash
scalebox-cli --version
```

預期輸出：`scalebox-cli version 1.3.5 (commit: dev, built: unknown)`

### 2. 檢視說明

```bash
scalebox-cli --help
```

## 快速設定

只需幾個指令即可開始使用 ScaleBox CLI：

### 1. 使用 API 金鑰進行身份驗證

```bash
scalebox-cli auth login --api-key your-api-key --server-url https://api.scalebox.dev
```

將 `your-api-key` 替換為儀表板中的實際 API 金鑰。

### 2. 列出可用範本

```bash
scalebox-cli template list
```

### 3. 建立您的第一個沙盒

```bash
scalebox-cli sandbox create --template tpl-abc123
```

## 系統需求

### 最低需求

**作業系統**
- Linux (glibc 2.17+)
- macOS 10.12+
- Windows 10+

**相依性**
- Docker（用於映像檔操作）
- HTTPS 網路存取
- ~50MB 磁碟空間

## 安全驗證

使用 SHA256 校驗和驗證下載的二進位檔案的完整性：

### 下載校驗和

[下載 checksums.txt](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/checksums.txt)

鎖定此版本：[checksums-v1.3.5.txt](https://scalex-packages.s3.us-east-2.amazonaws.com/scalebox-cli-releases/checksums-v1.3.5.txt)

### 在 Linux/macOS 上驗證

```bash
sha256sum -c checksums.txt
```

## sandbox list

列出沙盒，可用分頁方式查詢，或抓取完整結果集。

**引數**

| 引數 | 型別 | 描述 |
|------|------|------|
| `--page` | integer | 分頁頁碼（預設：`1`） |
| `--limit` | integer | 每頁沙盒數量（預設：`20`） |
| `--all` | boolean | 持續抓取每一頁，直到清單完整為止 |
| `--max-items` | integer | 與 `--all` 搭配使用時，抓到指定數量後停止（`0` = 不限制） |
| `--status` | string | 依沙盒狀態篩選 |
| `--template` | string | 依模板 ID 篩選 |

**示例**

```bash
scalebox-cli sandbox list
scalebox-cli sandbox list --page 2 --limit 10
scalebox-cli sandbox list --all
scalebox-cli sandbox list --all --max-items 200
scalebox-cli -o json sandbox list --page 1 --limit 10
```

不要將 `--all` 與非預設的 `--page` 一起使用。JSON 輸出使用巢狀 `pagination` 物件。

## HTTPS 安全檔案操作 (v1.2.2)

所有檔案傳輸操作現在都使用安全的 HTTPS 協議，具有智慧衝突檢測和嚴格的路徑驗證。
支援公共和私有沙盒路由。遠端路徑為沙盒內的絕對路徑（如 `/workspace`、`/home/jovyan`），禁止使用目錄遍歷（`..`）。

### sandbox upload

上傳檔案或目錄到沙盒，具有智慧衝突檢測。

```bash
scalebox-cli sandbox upload sbx-abc123 ./myfile.txt /workspace/myfile.txt
```

### sandbox download

從沙盒下載檔案或目錄。

```bash
scalebox-cli sandbox download sbx-abc123 /workspace/results.json ./results.json
```

### sandbox ls

列出目錄內容和詳細資訊。

```bash
scalebox-cli sandbox ls sbx-abc123 /workspace
```

### sandbox create

**同步（預設）：** 等到 `running` 後連線互動式終端機，除非 `--no-terminal`（CI/腳本）。**`--async`：** API 立即返回，CLI 不輪詢，請用 `scalebox-cli sandbox get <id>` 查看狀態。

**基本用法：**

```bash
scalebox-cli sandbox create --template tpl-abc123 --name my-workspace
```

**使用自動暫停（逾時時暫停而非終止）：**

```bash
scalebox-cli sandbox create --template tpl-abc123 --name my-workspace --timeout 3600 --auto-pause
```

**非同步建立（CLI 不輪詢）：**

```bash
scalebox-cli sandbox create --template tpl-abc123 --name my-workspace --async
```

**同步建立但不進互動終端機：**

```bash
scalebox-cli sandbox create --template tpl-abc123 --name my-workspace --no-terminal
```

`--auto-pause` 標誌啟用自動暫停功能，當沙盒達到逾時時間時會暫停而非終止。這對於您想要保留但無需持續執行的開發環境非常有用。

**區域（排程）：** 執行 `scalebox-cli sandbox regions`（或 `--json`）列出 id，再使用 `--locality-region`、可選 `--locality-force`，或 `--locality-auto-detect`。若區域列表非空，CLI 會在建立前拒絕未知 id。

```bash
scalebox-cli sandbox regions
```

**物件儲存與自訂埠：** 僅支援行內 JSON（與 `create-template --ports` 相同風格）：`--object-storage` 接受單一物件或多掛載的 JSON 陣列；`--ports` 為 `custom_ports` 的 JSON 陣列。自訂範本可選 `--object-storage-direct-mount` 與 `--s3fs-executable-path`。

```bash
scalebox-cli sandbox create --template base --name demo --locality-region ap-southeast --object-storage '{"uri":"s3://b/p","mount_point":"/mnt/oss","access_key":"KEY","secret_key":"SECRET","region":"us-east-1"}'
```

## 沙盒生命週期管理 (v1.3.0)

使用暫停、恢復、終止和刪除操作管理沙盒狀態。**暫停與恢復**預設同步（CLI 等待完成）；`--async` 立即返回後需自行輪詢。**建立**行為見上文（`--async` / `--no-terminal`）。在適用情境支援單個與批次模式。

### sandbox pause

暫停一個或多個執行中的沙盒以節省資源，同時保留其狀態。預設會等待暫停完成；使用 `--async` 可立即返回。

**單個沙盒：**

```bash
scalebox-cli sandbox pause sbx-abc123
```

**批次暫停（多個沙盒）：**

```bash
scalebox-cli sandbox pause sbx-abc123 sbx-def456 sbx-ghi789
```

### sandbox resume

恢復一個或多個暫停的沙盒以將其恢復到執行狀態。預設會等待恢復完成；使用 `--async` 可立即返回。

**單個沙盒：**

```bash
scalebox-cli sandbox resume sbx-abc123
```

**批次恢復（多個沙盒）：**

```bash
scalebox-cli sandbox resume sbx-abc123 sbx-def456 sbx-ghi789
```

### sandbox terminate

立即終止一個或多個沙盒。

**單個沙盒：**

```bash
scalebox-cli sandbox terminate sbx-abc123
```

**批次終止（多個沙盒）：**

```bash
scalebox-cli sandbox terminate sbx-abc123 sbx-def456 sbx-ghi789 --force
```

### sandbox delete

刪除一個或多個沙盒並釋放所有相關資源。

**單個沙盒：**

```bash
scalebox-cli sandbox delete sbx-abc123
```

**批次刪除（多個沙盒）：**

```bash
scalebox-cli sandbox delete sbx-abc123 sbx-def456 sbx-ghi789 --force
```

<Callout type="warn">
**終止、刪除與 `--async`**

`sandbox terminate` 與 `sandbox delete` 在 API 接受請求後即返回，後台可能仍在釋放資源；這兩條命令沒有 `--async` 參數。僅 `create`、`pause`、`resume` 文件化 `--async`（建立語意見上文）。
</Callout>

## 從沙盒建立模板 (v1.2.8)

從執行中的沙盒建立可重用的模板。這將捕獲沙盒的當前狀態，並允許您使用相同配置建立新沙盒。

### sandbox create-template

從執行中的沙盒建立新模板。

**基本用法：**

```bash
scalebox-cli sandbox create-template sbx-abc123 --name my-template
```

**使用自定義配置：**

```bash
scalebox-cli sandbox create-template sbx-abc123 --name my-template --description "自定義模板" --cpu 4 --memory 8192
```

**可用標誌：**

- `--name`（必需）：模板名稱（4-32個字元，支援小寫字母、數字、連字元和下劃線）
- `--description`：模板描述
- `--public`：使模板公開（僅管理員）
- `--cpu`：CPU 數量（0 = 從基礎模板繼承）
- `--memory`：記憶體（MB）（0 = 從基礎模板繼承）
- `--ports`：附加埠（JSON 陣列格式）
- `--start-command`：自定義啟動命令
- `--ready-command`：就緒探針 JSON（type 為 exec\|httpGet\|tcpSocket）或普通命令（exec）

## WebRTC TURN 與埠管理 (v1.3.3)

對於帶有 WebRTC 埠的沙盒，可取得短期 TURN 憑證供 RTCPeerConnection 使用。使用 `sandbox port list`、`port add`、`port remove` 管理執行中沙盒的自訂埠。沙盒內環境變數（如 `TURN_CREDENTIAL_SERVICE_URL`、`TURN_PUBLIC_HOST`）及如何託管 WebRTC 應用，請參閱指南 [在沙盒中託管 WebRTC](../guides/webrtc-in-sandboxes)。

### sandbox webrtc-credential

取得沙盒的 TURN 憑證（ice_servers、username、credential）。沙盒須在執行且具有 WebRTC 埠。輸出為 JSON。

```bash
scalebox-cli sandbox webrtc-credential sbx-abc123
```

### sandbox port list

列出沙盒的所有埠（模板埠 + 自訂埠）。

```bash
scalebox-cli sandbox port list sbx-abc123
```

### sandbox port add

向執行中的沙盒新增自訂埠。需使用 `--port` 和 `--name`（必填）。可選：`--protocol`（TCP、UDP、WEBRTC）、`--service-port`。

```bash
scalebox-cli sandbox port add sbx-abc123 --port 8080 --name api
```

```bash
scalebox-cli sandbox port add sbx-abc123 --port 9000 --name webrtc --protocol WEBRTC
```

### sandbox port remove

從執行中的沙盒移除自訂埠。僅可移除自訂（非模板）埠。

```bash
scalebox-cli sandbox port remove sbx-abc123 8080
```

## 物件儲存掛載

ScaleBox 支援將 S3 相容的物件儲存掛載到沙盒中。您可以在建立沙盒時配置物件儲存，
或在執行時手動掛載。所有沙盒預設都啟用了 FUSE 功能。

### 建立帶物件儲存的沙盒

使用 API 建立沙盒時配置物件儲存。儲存將在沙盒啟動時自動掛載。

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "template": "tpl-abc123",
    "name": "my-workspace",
    "object_storage": {
      "uri": "s3://my-bucket/data",
      "mount_point": "/mnt/oss",
      "access_key": "YOUR_S3_ACCESS_KEY",
      "secret_key": "YOUR_S3_SECRET_KEY",
      "region": "us-east-1"
    }
  }'
```

### 執行時手動掛載

所有沙盒都啟用了 FUSE 功能。您可以透過在執行中的容器中執行命令手動掛載物件儲存：

```bash
# 建立憑證檔案
echo "YOUR_ACCESS_KEY:YOUR_SECRET_KEY" > /root/.s3fs-credentials
chmod 600 /root/.s3fs-credentials

# 建立掛載點
mkdir -p /mnt/oss

# 掛載 S3 儲存桶（對於非預設區域，需要同時指定 url 和 endpoint）
s3fs bucket-name:/path /mnt/oss \
  -o passwd_file=/root/.s3fs-credentials \
  -o url=https://s3.region.amazonaws.com \
  -o endpoint=region
```

<Callout type="info">
**注意：** 物件儲存憑證永遠不會儲存在資料庫中。
只有 URI 和掛載點會被持久化。憑證僅在掛載操作期間使用。
</Callout>

## HTTPS 安全與路徑要求

ScaleBox CLI v1.2.2 使用 HTTPS 安全通訊並強制執行嚴格的路徑驗證以確保安全性和清晰性：

### ✅ 有效路徑

- `/workspace/myfile.txt` - 工作區目錄
- `/home/user/document.pdf` - 使用者主目錄
- `/tmp/data.json` - 系統臨時目錄
- `/etc/config.conf` - 系統配置檔案
- `/` - 根目錄

### ❌ 無效路徑

- `../etc/passwd` - 目錄遍歷攻擊
- `/../../etc/shadow` - 路徑遍歷嘗試
- `myfile.txt` - 相對路徑（應使用絕對路徑）
- `workspace/file.txt` - 缺少前導斜槓

## 命令標誌

用於增強檔案操作控制的可用標誌：

### --force

強制覆蓋現有檔案而不確認。

與 upload/download 一起使用以覆蓋衝突的檔案。

### --recursive

遞迴傳輸目錄。

上傳/下載目錄時必需。

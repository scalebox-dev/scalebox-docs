`scalebox-cli account` 命令參考。

本頁所有命令也支援 `--compact`，用於輸出單行 JSON。許多命令僅限 root 使用者使用。

## 訂閱與帳戶資訊

- `account subscription-show`：查看目前帳戶訂閱。
- `account subscription-set --plan PLAN_NAME`：切換訂閱方案。
- `account subscription-history`：列出訂閱變更歷史。
- `account plans-list`：列出公開方案。
- `account update`：更新 `--display-name` 和/或 `--description`。
- `account benefits`：查看帳戶權益。
- `account voucher-usage VOUCHER_ID`：查看優惠券使用紀錄。
- `account discount-impact DISCOUNT_ID`：查看折扣影響分析。

```bash
scalebox-cli account subscription-show
scalebox-cli account subscription-set --plan pro
scalebox-cli account update --display-name "Platform Team"
scalebox-cli account benefits
```

像 `subscription-history` 和 `voucher-usage` 這類列表命令，回傳值使用標準巢狀分頁 JSON：

```json
{
  "history": [],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 0,
    "total_pages": 0,
    "offset": 0
  }
}
```

## 使用者管理

- `account users-list`
- `account users-create`
- `account users-get USER_ID`
- `account users-update USER_ID`
- `account users-delete USER_ID`
- `account users-reset-password USER_ID`

`users-create` 支援 `--email`、`--username`、`--role`、`--display-name`、`--status`、`--description`，其中 `--email`、`--username`、`--role` 為必填。

`users-update` 支援 `--display-name`、`--role`、`--status`、`--description`。

```bash
scalebox-cli account users-list
scalebox-cli account users-create --email dev@example.com --username dev1 --role member
scalebox-cli account users-update usr_123 --status disabled
scalebox-cli account users-reset-password usr_123
```

`users-list` 的分頁結構為：

```json
{
  "users": [],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 0,
    "total_pages": 0,
    "offset": 0
  }
}
```

## 配額管理

- `account quota-allocations-list`，可選 `--include-inactive`
- `account quota-allocation-create`
- `account quota-allocation-update ALLOCATION_ID`
- `account quota-allocation-delete ALLOCATION_ID`
- `account quota-allocation-revoke ALLOCATION_ID`
- `account quota-requests-list`，可選 `--status`
- `account quota-request-review REQUEST_ID --action approve|deny [--notes ...]`

配額建立和更新都支援：`--cpu-seconds-monthly`、`--ram-gb-seconds`、`--sandbox-storage-gb-seconds`、`--traffic-gb-seconds`、`--template-storage-gb`、`--concurrent-sandboxes`。建立時還必須傳入 `--target-user-id`。

`quota-allocation-update` 更嚴格，以上全部配額參數都必須同時傳入。

```bash
scalebox-cli account quota-allocations-list --include-inactive
scalebox-cli account quota-allocation-create --target-user-id usr_123 --template-storage-gb 100
scalebox-cli account quota-request-review req_123 --action approve --notes "Approved for Q2"
```

像 `quota-allocations-list` 與 `quota-requests-list` 這類列表命令，也使用相同的巢狀 `pagination` 結構，陣列欄位分別為 `allocations` 或 `requests`。

## 端點

### 列出發票

`GET /v1/billing/invoices`

查詢參數：

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| page | integer | 否 | 頁碼，預設 `1` |
| limit | integer | 否 | 每頁數量 |
| page_size | integer | 否 | `limit` 的別名 |

### 取得單張發票

`GET /v1/billing/invoices/{invoice_id}`

回傳與 `data.invoices[]` 相同的發票物件結構。

### 取得目前帳期快照

`GET /v1/billing/current`

回傳目前訂閱週期內的即時計費概覽，包括：

- `data.current_period`
- `data.current_cost`
- `data.projected_cost`
- `data.active_sessions`
- `data.completed_sessions`
- `data.subscription_fee`
- `data.cost_breakdown`
- `data.daily_trend`

### 取得統一帳期列表

`GET /v1/billing/periods`

回傳 `data.periods`。第一筆是目前即時帳期，後續則是歷史發票帳期。

### 取得計費歷史

`GET /v1/billing/history`

查詢參數：

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| start | RFC3339 時間 | 否 | 開始時間，預設最近 30 天 |
| end | RFC3339 時間 | 否 | 結束時間，預設目前時間 |

回傳欄位包括：

- `data.period`
- `data.total_cost`
- `data.sessions`
- `data.breakdown`
- `data.daily_costs`

### 產生目前帳期發票

`POST /v1/billing/invoice/generate`

為目前帳期建立或刷新發票，並在 `data` 中回傳生成後的發票物件。

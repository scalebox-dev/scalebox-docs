<Callout type="warn">
**需要身份驗證：** 所有 Webhook 管理 API 都需要 `X-API-Key` 標頭。
</Callout>

<Callout type="info">
Webhook 簽名密鑰不會透過這些 API 回傳。請在 UI 或建立流程提供密鑰時自行安全保存。
</Callout>

## 標準回應格式

Webhook 管理端點使用標準信封格式：

```json
{
  "success": true,
  "data": {},
  "timestamp": "2026-04-17T12:34:56Z"
}
```

刪除操作會回傳頂層 `message`，不含 `data`。

## API 端點

### 建立 Webhook

`POST /v1/webhooks`

**請求主體**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| url | string | 是 | `http://` 或 `https://` 端點 URL |
| event_types | array[string] | 是 | 訂閱的事件類型清單 |
| description | string | 否 | 端點描述 |
| scope | string | 否 | `user` 或 `account` |

**回應**

```json
{
  "success": true,
  "data": {
    "endpoint_id": "whk-abc123def456789",
    "url": "https://your-app.example/webhooks/scalebox",
    "event_types": [
      "sandbox.started",
      "sandbox.terminated"
    ],
    "is_active": true,
    "description": "Production lifecycle webhook",
    "timeout_seconds": 30,
    "max_retries": 3,
    "created_at": "2026-04-17T12:00:00Z",
    "updated_at": "2026-04-17T12:00:00Z",
    "user_id": "usr-xyz789abc123456"
  },
  "timestamp": "2026-04-17T12:00:00Z"
}
```

帳戶層級的 Webhook 會讓 `user_id` 為 `null`。

### 列出 Webhook

`GET /v1/webhooks`

**查詢參數**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| page | integer | 否 | 分頁頁碼，預設 `1` |
| limit | integer | 否 | 每頁回傳筆數，預設 `20`；別名：`page_size` |
| offset | integer | 否 | 要略過的筆數，預設 `0`；別名：`skip` |

**回應**

```json
{
  "success": true,
  "data": {
    "webhooks": [
      {
        "endpoint_id": "whk-abc123def456789",
        "url": "https://your-app.example/webhooks/scalebox",
        "event_types": [
          "sandbox.started",
          "sandbox.terminated"
        ],
        "is_active": true,
        "description": "Production lifecycle webhook",
        "timeout_seconds": 30,
        "max_retries": 3,
        "total_deliveries": 150,
        "successful_deliveries": 148,
        "failed_deliveries": 2,
        "last_delivery_at": "2026-04-17T11:55:00Z",
        "last_success_at": "2026-04-17T11:55:00Z",
        "last_failure_at": "2026-04-17T10:10:00Z",
        "created_at": "2026-04-10T08:00:00Z",
        "updated_at": "2026-04-17T11:55:00Z",
        "user_id": "usr-xyz789abc123456"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "offset": 0,
      "total": 1,
      "total_pages": 1
    }
  },
  "timestamp": "2026-04-17T12:01:00Z"
}
```

root 與 admin 檢視時也可能看見 `account_id`。

### 更新 Webhook

`PUT /v1/webhooks/{endpoint_id}`

**請求主體**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| url | string | 否 | 新 URL |
| event_types | array[string] | 否 | 新的事件訂閱清單 |
| is_active | boolean | 否 | 啟用或停用 |
| description | string | 否 | 新描述 |
| timeout_seconds | integer | 否 | 5 到 300 |
| max_retries | integer | 否 | 0 到 10 |
| scope | string | 否 | `user` 或 `account` |

**回應**

```json
{
  "success": true,
  "data": {
    "endpoint_id": "whk-abc123def456789",
    "url": "https://your-app.example/webhooks/scalebox",
    "event_types": [
      "sandbox.started",
      "sandbox.failed",
      "sandbox.terminated"
    ],
    "is_active": false,
    "description": "Paused temporarily",
    "timeout_seconds": 30,
    "max_retries": 3,
    "updated_at": "2026-04-17T12:03:00Z"
  },
  "timestamp": "2026-04-17T12:03:00Z"
}
```

### 刪除 Webhook

`DELETE /v1/webhooks/{endpoint_id}`

**回應**

```json
{
  "success": true,
  "message": "Webhook endpoint deleted successfully",
  "timestamp": "2026-04-17T12:04:00Z"
}
```

### 取得投遞歷史

`GET /v1/webhooks/{endpoint_id}/deliveries`

**查詢參數**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| limit | integer | 否 | 預設 `50`，有效範圍 `1-200` |

**回應**

```json
{
  "success": true,
  "data": {
    "deliveries": [
      {
        "delivery_id": "whd-xyz789abc123456",
        "event_type": "sandbox.started",
        "event_id": "evt-abc123def456789",
        "status": "delivered",
        "http_status_code": 200,
        "attempt_number": 1,
        "max_attempts": 3,
        "next_retry_at": null,
        "delivered_at": "2026-04-17T11:55:00Z",
        "failed_at": null,
        "error_message": null,
        "created_at": "2026-04-17T11:55:00Z"
      }
    ]
  },
  "timestamp": "2026-04-17T12:05:00Z"
}
```

## 事件類型

目前支援的面向客戶事件類型包括：

- `sandbox.created`
- `sandbox.started`
- `sandbox.stopped`
- `sandbox.paused`
- `sandbox.resumed`
- `sandbox.terminated`
- `sandbox.failed`
- `sandbox.project_switched`
- `template.uploaded`
- `template.deleted`

像 `payment.*`、`subscription.*`、`budget.*` 這類帳戶層級事件，需要帳戶層級 Webhook 與帳戶 root 使用者。

## 投遞負載

Webhook 投遞本身與上面的管理 API 不同。典型投遞內容如下：

```json
{
  "id": "evt-abc123def456789",
  "type": "sandbox.started",
  "timestamp": "2026-04-17T11:55:00Z",
  "data": {
    "sandbox_id": "sbx-abc123def456789",
    "status": "running"
  }
}
```

## 常見錯誤

```json
{
  "success": false,
  "error": "Invalid event type: sandbox.unknown",
  "timestamp": "2026-04-17T12:10:00Z"
}
```

- `400`：URL 無效、scope 無效、事件類型不支援，或 timeout/retry 值不合法
- `403`：非 root 使用者嘗試建立或更新帳戶層級 Webhook
- `404`：在目前範圍內找不到端點
- `500`：持久化或投遞歷史查詢失敗

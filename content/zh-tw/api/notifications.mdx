## API 端點

以下是所有可用的通知管理端點：

| 端點 | 方法 | 路徑 | 描述 |
|------|------|------|------|
| list-notifications | GET | `/v1/notifications` | 列出使用者的所有通知 |
| get-notification | GET | `/v1/notifications/{notification_id}` | 獲取特定通知的詳細資訊 |
| mark-notification-read | PATCH | `/v1/notifications/{notification_id}/read` | 將通知標記為已讀 |
| mark-notification-unread | PATCH | `/v1/notifications/{notification_id}/unread` | 將通知標記為未讀 |
| mark-all-notifications-read | PATCH | `/v1/notifications/read-all` | 將所有通知標記為已讀 |
| delete-notification | DELETE | `/v1/notifications/{notification_id}` | 刪除特定通知 |
| delete-all-notifications | DELETE | `/v1/notifications` | 刪除所有通知 |

## list-notifications

列出使用者的所有通知

**路徑：** `GET /v1/notifications`

### 請求示例

```bash
curl -X GET https://api.scalebox.dev/v1/notifications \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

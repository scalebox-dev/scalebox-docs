<Callout type="warn">
**需要身份驗證：** 所有用量端點都需要 `X-API-Key` 標頭。
</Callout>

<Callout type="info">
摘要、分析、工作階段與事件端點會依呼叫者角色自動限域。帳戶 root 使用者審核團隊配額申請時，請使用帳戶管理頁的端點；非 root 使用者則使用 `/v1/usage/quota-requests`。
</Callout>

## 回應慣例

用量 API 使用標準信封格式。列表端點統一回傳 `data.<items>` 與 `data.pagination`。真實分頁參數為 `page` 與 `limit`，同時接受別名 `page_size`。

## 端點

### 取得用量摘要

`GET /v1/usage/summary`

查詢參數：

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| start | RFC3339 時間 | 否 | 開始時間，預設最近 30 天 |
| end | RFC3339 時間 | 否 | 結束時間，預設目前時間 |
| project_id | string | 否 | 可選專案篩選 |

回傳 `data.summary` 與 `data.time_period`。

### 取得用量分析

`GET /v1/usage/analytics`

查詢參數：`start`、`end`。

回傳 `data.summary`，以及 `data.charts` 下的：

- `sessions_over_time`
- `resource_utilization`
- `cost_breakdown`

### 列出用量工作階段

`GET /v1/usage/sessions`

查詢參數：

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| page | integer | 否 | 頁碼，預設 `1` |
| limit | integer | 否 | 每頁數量，預設 `50` |
| page_size | integer | 否 | `limit` 的別名 |
| start | RFC3339 時間 | 否 | `start_time` 下界 |
| end | RFC3339 時間 | 否 | `start_time` 上界 |

### 列出用量事件

`GET /v1/usage/events`

查詢參數：

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| page | integer | 否 | 頁碼 |
| limit | integer | 否 | 每頁數量 |
| page_size | integer | 否 | `limit` 的別名 |
| start | RFC3339 時間 | 否 | `event_timestamp` 下界 |
| end | RFC3339 時間 | 否 | `event_timestamp` 上界 |
| project_id | string | 否 | 專案篩選 |
| resource_type | string | 否 | 資源類型篩選 |
| usage_type | string | 否 | 事件類型篩選 |
| account_id | string | 否 | 僅管理員可用的帳戶篩選 |

### 取得目前有效配額

`GET /v1/usage/quotas`

回傳呼叫者目前啟用中的使用者配額分配；若尚未分配，則回傳 `data.quotas: null`。

### 管理我的配額申請

非 root 使用者可使用：

- `GET /v1/usage/quota-requests`
- `POST /v1/usage/quota-requests`
- `PUT /v1/usage/quota-requests/{request_id}`
- `DELETE /v1/usage/quota-requests/{request_id}`

建立與更新請求主體欄位：

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| cpu_seconds_monthly | int64 | 是 | 每月 CPU 秒數 |
| ram_gb_seconds | number | 否 | RAM GB 秒 |
| sandbox_storage_gb_seconds | number | 否 | 沙箱儲存 GB 秒 |
| traffic_gb_seconds | number | 否 | 流量 GB 秒 |
| template_storage_gb | number | 是 | 模板儲存 GB |
| concurrent_sandboxes | integer | 否 | `0` 代表使用者層級不限 |
| reason | string | 是 | 申請原因 |

列表查詢參數：

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| status | string | 否 | 依 `pending`、`approved`、`denied`、`withdrawn` 篩選 |
| page | integer | 否 | 頁碼 |
| limit | integer | 否 | 每頁數量 |
| page_size | integer | 否 | `limit` 的別名 |

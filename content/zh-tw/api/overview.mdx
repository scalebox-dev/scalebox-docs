# API 參考

ScaleBox 的完整 API 參考，這是一個用於創建和管理隔離開發環境的現代平臺。本文檔提供了所有可用端點、身份驗證方法和使用示例的全面信息。

## 開始使用

要使用 ScaleBox API，您需要進行身份驗證。所有 API 請求都需要以下之一：`X-API-Key` 標頭、`Authorization: Api-Key` 或 `Authorization: Bearer`。

### 基礎配置

- **基礎 URL：** `https://api.scalebox.dev`
- **API 版本：** `v1`
- **身份驗證：** `X-API-Key` 標頭

## 核心概念

### RESTful API

所有端點都遵循 REST 約定，使用標準 HTTP 方法（GET、POST、PUT、DELETE）和 JSON 請求/響應格式。

### 基於資源

API 資源圍繞沙盒、項目、模板和用戶組織，具有清晰的層次關係。

### 安全身份驗證

所有請求都需要 API 密鑰身份驗證，併為不同的用戶角色提供適當的作用域和訪問控制。

### 實時更新

支持 Webhook，用於資源狀態更改時的實時通知和狀態更新。

## 速率限制

API 請求受到速率限制，以確保公平使用。限制按 API 密鑰應用並定期重置。

| 套餐 | 速率限制 |
|------|----------|
| 標準套餐 | 1,000 請求/小時 |
| 專業套餐 | 10,000 請求/小時 |
| 企業版 | 自定義限制 |

## 錯誤處理

API 使用標準 HTTP 狀態代碼，並在請求失敗時以 JSON 格式返回詳細的錯誤消息。

| 狀態代碼 | 描述 |
|----------|------|
| 400 | 錯誤請求（參數無效） |
| 401 | 未授權（API 密鑰無效） |
| 403 | 禁止訪問（權限不足） |
| 404 | 未找到（資源不存在） |
| 429 | 請求過多（超過速率限制） |
| 500 | 內部服務器錯誤 |

<Callout type="warn">
**需要身份驗證：** 所有使用者 API 都需要 `X-API-Key` 標頭。
</Callout>

<Callout type="info">
`/v1/users/me` 用於自助式個人資料存取；`/v1/user-management/*` 用於帳戶管理，多數端點需要帳戶 root 使用者。
</Callout>

## 標準回應格式

使用者 API 使用標準信封格式：

```json
{
  "success": true,
  "data": {},
  "timestamp": "2026-04-17T12:34:56Z"
}
```

部分修改型端點只會回傳頂層 `message`，不含 `data`。

### 更新我的個人資料

`PUT /v1/users/me`

**請求主體**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| display_name | string | 否 | 更新後的顯示名稱 |
| description | string | 否 | 更新後的描述 |
| role | string | 否 | 僅 root 使用者可更新自己的角色 |
| status | string | 否 | 僅 root 使用者可更新自己的狀態 |

**回應**

```json
{
  "success": true,
  "message": "Profile updated successfully",
  "timestamp": "2026-04-17T12:01:00Z"
}
```

### 列出使用者

`GET /v1/user-management/users`

僅限帳戶 root 使用者。

**查詢參數**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| page | integer | 否 | 分頁頁碼，預設 `1` |
| limit | integer | 否 | 每頁回傳筆數；別名：`page_size` |
| offset | integer | 否 | 要略過的筆數；別名：`skip` |

**回應**

```json
{
  "success": true,
  "data": {
    "users": [
      {
        "user_id": "usr-abc123def456789",
        "email": "john@example.com",
        "username": "john.developer",
        "display_name": "John Developer",
        "role": "user",
        "status": "active",
        "is_root_user": true,
        "email_verified": true,
        "created_at": "2026-04-10T09:30:00Z",
        "last_login": "2026-04-17T08:45:00Z"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "offset": 0,
      "total": 1,
      "total_pages": 1
    }
  },
  "timestamp": "2026-04-17T12:02:00Z"
}
```

### 建立使用者

`POST /v1/user-management/users`

僅限帳戶 root 使用者。

**請求主體**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| email | string | 是 | 使用者電子郵件 |
| username | string | 是 | 使用者名稱 |
| display_name | string | 否 | 顯示名稱 |
| role | string | 是 | 使用者角色 |
| status | string | 否 | 初始狀態 |
| description | string | 否 | 描述 |

**回應**

```json
{
  "success": true,
  "data": {
    "message": "User created successfully",
    "user": {
      "user_id": "usr-def456ghi789012",
      "email": "jane@example.com",
      "username": "jane.developer",
      "display_name": "Jane Developer",
      "role": "user",
      "status": "active",
      "is_root_user": false,
      "email_verified": false,
      "created_at": "2026-04-17T12:03:00Z"
    },
    "initial_password": "",
    "dedicated_signin_url": null
  },
  "timestamp": "2026-04-17T12:03:00Z"
}
```

### 重設使用者密碼

`POST /v1/user-management/users/{user_id}/reset-password`

僅限帳戶 root 使用者。

**回應**

```json
{
  "success": true,
  "data": {
    "message": "Password reset link has been sent to the user's email. The link will expire in 30 minutes."
  },
  "timestamp": "2026-04-17T12:07:00Z"
}
```

### 變更我的密碼

`POST /v1/user-management/change-password`

此原地變更流程適用於已經具備本地密碼的帳戶。若帳戶尚未建立本地密碼，或目前密碼不可用，請改走郵件重設流程。

**請求主體**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| current_password | string | 是 | 此已驗證原地改密流程中用於驗證的目前本地密碼 |
| new_password | string | 是 | 新密碼，至少 8 個字元，且必須與 `current_password` 不同 |

**回應**

```json
{
  "success": true,
  "message": "Password changed successfully",
  "timestamp": "2026-04-17T12:08:00Z"
}
```

### 寄送我的密碼重設郵件

`POST /v1/user-management/request-password-reset`

寄送密碼重設郵件給目前已驗證的使用者。若帳戶尚未建立本地密碼，或目前密碼不可用，請改走此恢復流程。

**回應**

```json
{
  "success": true,
  "message": "Password reset link sent to your email",
  "timestamp": "2026-04-17T12:09:00Z"
}
```

速率限制時可能回傳 `429`，並在 `data.time_remaining_minutes` 提供剩餘等待時間。

## 常見錯誤

```json
{
  "success": false,
  "error": "Only root users can list users",
  "timestamp": "2026-04-17T12:10:00Z"
}
```

- `400`：請求主體無效、密碼過弱、目前密碼錯誤，或狀態轉換不允許
- `403`：非 root 使用者呼叫帳戶管理端點
- `404`：在目前帳戶內找不到目標使用者
- `429`：密碼重設請求過於頻繁
- `500`：持久化、郵件或背景清理流程失敗

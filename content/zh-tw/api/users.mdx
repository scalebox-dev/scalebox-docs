## API 端點

以下是所有可用的使用者 API 端點：

| 端點 | 方法 | 路徑 | 描述 |
|------|------|------|------|
| get-profile | GET | `/v1/users/profile` | 獲取當前使用者的個人資料 |
| update-profile | PUT | `/v1/users/profile` | 更新使用者個人資料 |
| change-password | POST | `/v1/users/change-password` | 更改使用者密碼 |
| request-password-reset | POST | `/v1/users/request-password-reset` | 請求密碼重置 |
| verify-email | POST | `/v1/users/verify-email` | 驗證使用者郵箱 |

## get-profile

獲取當前使用者的個人資料

**路徑：** `GET /v1/users/profile`

### 請求示例

```bash
curl -X GET https://api.scalebox.dev/v1/users/profile \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

## update-profile

更新使用者個人資料

**路徑：** `PUT /v1/users/profile`

### 請求示例

```bash
curl -X PUT https://api.scalebox.dev/v1/users/profile \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "display_name": "新顯示名稱",
    "email": "new-email@example.com"
  }'
```

## change-password

更改使用者密碼

**路徑：** `POST /v1/users/change-password`

### 請求示例

```bash
curl -X POST https://api.scalebox.dev/v1/users/change-password \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "current_password": "當前密碼",
    "new_password": "新密碼"
  }'
```

## request-password-reset

請求密碼重置

**路徑：** `POST /v1/users/request-password-reset`

### 請求示例

```bash
curl -X POST https://api.scalebox.dev/v1/users/request-password-reset \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com"
  }'
```

## verify-email

驗證使用者郵箱

**路徑：** `POST /v1/users/verify-email`

### 請求示例

```bash
curl -X POST https://api.scalebox.dev/v1/users/verify-email \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "token": "驗證令牌"
  }'
```

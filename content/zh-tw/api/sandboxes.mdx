<Callout type="warn">
**身份驗證：** 大多數沙盒 API 都需要 `X-API-Key` 標頭。

**例外：** `GET /v1/scalebox-regions` 是公開端點（API key 可選）。在建立沙盒前，可先用它取得 `locality.region` 可用的 region id。
</Callout>

## Scalebox 區域（Discovery）

呼叫 `GET /v1/scalebox-regions` 可取得目前具備可用容量的區域 `id` / `name` 配對。建立沙盒時，`locality.region` 要填的就是這些 `id`。這些值同時會對照全域 locality catalog 驗證；未知區域會回傳 **400**。

## 沙盒狀態

| 狀態 | 說明 |
|------|------|
| `created` | 沙盒已建立但尚未啟動 |
| `starting` | 正在啟動並配置資源（substatus: allocating、deploying、initializing、waiting_ready） |
| `running` | 沙盒正在執行且可存取 |
| `terminating` | 正在終止並清理資源（substatus: cleaning_resources、cleaning_data） |
| `terminated` | 沙盒已終止，無法重新啟動 |
| `failed` | 沙盒在建立或執行期間發生錯誤 |

## 回應慣例

本頁大多數 JSON 端點都使用標準 envelope：

```json
{
  "success": true,
  "data": {},
  "timestamp": "2026-04-17T12:34:56Z"
}
```

特殊情況：

- `GET /v1/scalebox-regions` 雖然是公開端點，但仍使用 JSON envelope。
- `POST /v1/sandboxes/{sandbox_id}/exec`、`GET /v1/sandboxes/{sandbox_id}/exec/active`、`DELETE /v1/sandboxes/{sandbox_id}/exec` 會回傳**原始 JSON**，不是標準 envelope。
- `GET /v1/sandboxes/{sandbox_id}/exec/stream` 回傳的是 `text/event-stream`（SSE），不是 JSON。

### 沙盒讀取物件

`GET /v1/sandboxes/{sandbox_id}` 與成功的 pause / resume 回應，會回傳一個完整沙盒物件。後端目前暴露的欄位包含：

- 身分與擁有權：`sandbox_id`、`name`、`description`、`status`、`substatus`、`reason`、`template_id`、`template_name`、`template_exists`、`project_id`、`project_name`、`owner`、`account_owner`，以及相容性欄位 `user_account_id`、`userName`、`userEmail`、`region`、`visibility`
- 資源與存取：`cpu_count`、`memory_mb`、`storage_gb`、`resources`、`timeout`、`auto_pause`、`secure`、`allow_internet_access`、`sandbox_domain`、`sandbox_domain_internal`、`web_terminal_available`、`web_files_available`、`envd_access_token`
- 設定與掛載：`metadata`、`env_vars`、`object_storage`、`object_storage_single`、`object_storage_direct_mount`、`object_storage_s3fs_path`、`ports`、`template_ports`、`custom_ports`、`template_custom_command`、`template_ready_command`、`template_source`
- 生命週期與時間：`created_at`、`updated_at`、`started_at`、`stopped_at`、`ended_at`、`timeout_at`、`remaining_seconds`、`paused_at`、`pausing_at`、`resumed_at`、`uptime`、`total_paused_seconds`、`total_running_seconds`、`actual_total_paused_seconds`、`actual_total_running_seconds`、`lifecycle_outcome`、`last_accessed_at`
- 持久化與可選輔助：`persistence_days`、`persistence_expires_at`、`persistence_days_remaining`、可選的 `network_proxy`、可選的 `webrtc_turn`

## API 端點

### 建立沙盒

`POST /v1/sandboxes`

建立新沙盒。預設為同步模式：等待到 `running` 或 `failed` 才回應。設定 `is_async: true` 可立即返回，之後由客戶端自行輪詢狀態。

**請求參數**

| 名稱 | 型別 | 必填 | 預設值 | 說明 |
|------|------|------|--------|------|
| name | string | 否 | 自動產生 | 人類可讀的沙盒名稱（0-24 字元） |
| description | string | 否 | 空 | 沙盒用途描述 |
| template | string | 否 | `"base"` | 模板名稱或 ID（例如 `"python-dev"`、`"tpl-abc123"`） |
| project_id | string | 否 | 使用者預設專案 | 要關聯的專案 |
| cpu_count | integer | 否 | 模板預設 | CPU 核心數 |
| memory_mb | integer | 否 | 模板預設 | 記憶體（MB） |
| storage_gb | integer | 否 | 方案上限 50% | 持久儲存容量（GB） |
| timeout | integer | 否 | 300 | 沙盒逾時秒數 |
| env_vars | object | 否 | {} | 要注入沙盒的環境變數 |
| metadata | object | 否 | {} | 自訂 metadata |
| secure | boolean | 否 | true | 沙盒安全設定 |
| allow_internet_access | boolean | 否 | true | 是否允許存取網際網路 |
| object_storage | object/array | 否 | null | 單一掛載（JSON object）或多掛載（JSON array） |
| object_storage_direct_mount | boolean | 否 | false | 僅 custom 模板可用：在 worker 容器直接掛載 object storage |
| s3fs_executable_path | string | 否 | 空 | 直接掛載時可指定 s3fs 二進位路徑 |
| custom_ports | array | 否 | [] | 自訂埠配置陣列 |
| locality | object | 否 | null | 可選排程：`{ auto_detect: true }` 與 / 或 `{ region: string, force?: boolean }` |
| auto_pause | boolean | 否 | false | 為 `true` 時，逾時觸發自動暫停而非終止 |
| is_async | boolean | 否 | false | 為 `true` 時立即回傳，由客戶端輪詢 |

**成功回應**

`201 Created`，標準 envelope。`data` 包含：

- `sandbox_id`、`name`、`description`、`template_id`、`owner_user_id`、`project_id`
- `cpu_count`、`memory_mb`、`storage_gb`、`timeout`、`auto_pause`、`secure`、`allow_internet_access`
- `metadata`、`env_vars`
- `object_storage`、`object_storage_single`、`object_storage_direct_mount`、`object_storage_s3fs_path`
- `ports`、`template_ports`、`custom_ports`
- `template_custom_command`、`template_ready_command`
- `status`、`substatus`、`reason`、`created_at`
- `sandbox_domain`、`sandbox_domain_internal`、`web_terminal_available`、`web_files_available`、`envd_access_token`
- `persistence_days`、`persistence_expires_at`、`persistence_days_remaining`
- 可選 `network_proxy`

預設同步模式會等待沙盒進入 `running` 或 `failed`。非同步模式則會提早回傳相同結構，通常狀態為 `created` 或 `starting`。

**範例**

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-dev",
    "template": "python-dev",
    "cpu_count": 2,
    "memory_mb": 4096,
    "storage_gb": 10,
    "timeout": 3600,
    "auto_pause": true,
    "is_async": false,
    "env_vars": {
      "DEBUG": "true",
      "API_KEY": "your-secret-key"
    },
    "metadata": {
      "project": "web-app",
      "environment": "development"
    },
    "object_storage": {
      "uri": "s3://my-bucket/data",
      "mount_point": "/mnt/oss",
      "access_key": "YOUR_S3_ACCESS_KEY",
      "secret_key": "YOUR_S3_SECRET_KEY",
      "region": "us-east-1"
    },
    "custom_ports": [
      { "port": 8080, "name": "web-server", "protocol": "tcp" },
      { "port": 9000, "name": "api-server", "protocol": "tcp" }
    ],
    "locality": {
      "region": "ap-southeast",
      "force": false
    }
  }'
```

### 列出 Scalebox 區域

`GET /v1/scalebox-regions`

公開探索端點：列出目前至少有一個符合條件叢集的 Scalebox region id。

**成功回應**

`200 OK`，標準 envelope，`data.scalebox_regions` 為 `{ id, name }` 物件陣列。若目前沒有任何可用容量，陣列可能為空。

**範例**

```bash
curl -X GET https://api.scalebox.dev/v1/scalebox-regions
```

### 列出沙盒

`GET /v1/sandboxes`

列出目前使用者的所有沙盒。

**查詢參數**

| 名稱 | 型別 | 必填 | 預設值 | 說明 |
|------|------|------|--------|------|
| page | integer | 否 | 1 | 分頁頁碼 |
| limit | integer | 否 | 20 | 每頁回傳筆數；別名：`page_size` |
| offset | integer | 否 | 0 | 要略過的筆數；別名：`skip` |

**成功回應**

`200 OK`，標準 envelope，包含：

- `data.sandboxes`：沙盒摘要陣列。每筆包含 `sandbox_id`、`name`、`description`、`template_id`、`template_name`、`template_exists`、`owner_user_id`、`project_id`、`project_name`、`cpu_count`、`memory_mb`、`storage_gb`、`timeout`、`timeout_at`、`remaining_seconds`、`auto_pause`、`secure`、`allow_internet_access`、`metadata`、`env_vars`、`object_storage`、`object_storage_single`、`object_storage_direct_mount`、`object_storage_s3fs_path`、`ports`、`template_ports`、`custom_ports`、`template_custom_command`、`template_ready_command`、`template_source`、`status`、`substatus`、`reason`、`started_at`、`stopped_at`、`created_at`、`updated_at`、`sandbox_domain`、`sandbox_domain_internal`、`web_terminal_available`、`web_files_available`、`paused_at`、`pausing_at`、`resumed_at`、`total_paused_seconds`、`lifecycle_outcome`、`persistence_days`、`persistence_expires_at`、`persistence_days_remaining`、`uptime`，以及可選的 `network_proxy`
- `data.pagination.page`
- `data.pagination.limit`
- `data.pagination.offset`
- `data.pagination.total`
- `data.pagination.total_pages`

**範例**

```bash
curl -X GET "https://api.scalebox.dev/v1/sandboxes?page=1&limit=20&offset=0" \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### 取得沙盒

`GET /v1/sandboxes/{sandbox_id}`

取得單一沙盒詳細資訊。

**成功回應**

`200 OK`，標準 envelope，`data` 為一個 **沙盒讀取物件**。

**範例**

```bash
curl -X GET https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789 \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### 更新沙盒

`PUT /v1/sandboxes/{sandbox_id}`

更新沙盒設定（只能延長 timeout）。

**請求參數**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| timeout | integer | 是 | 新的逾時秒數（必須大於目前 timeout） |

**成功回應**

`200 OK`，頂層 `message: "Sandbox updated successfully"`。成功時**不會**回傳 `data` 物件。

**範例**

```bash
curl -X PUT https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789 \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{"timeout": 7200}'
```

### 刪除沙盒

`DELETE /v1/sandboxes/{sandbox_id}`

刪除沙盒與所有相關資源。

**成功回應**

`202 Accepted`，頂層 `message: "Sandbox deletion initiated"`，並包含：

- `data.sandbox_id`
- `data.status`：`deletion_in_progress`
- `data.note`

**範例**

```bash
curl -X DELETE https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789 \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

### 暫停沙盒

`POST /v1/sandboxes/{sandbox_id}/pause`

暫停執行中的沙盒。預設同步等待至 `paused` 或回退到 `running`。

**請求參數**

| 名稱 | 型別 | 必填 | 預設值 | 說明 |
|------|------|------|--------|------|
| is_async | boolean | 否 | false | 為 `true` 時立即回傳，由客戶端輪詢 |

**成功回應**

`200 OK`，標準 envelope。

- 同步模式會等待，並以更新後的 **沙盒讀取物件** 作為 `data`（通常 `status: "paused"`）
- 非同步模式會在狀態轉換剛開始後立即回傳目前的 **沙盒讀取物件**（通常 `status: "pausing"`）

**範例**

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/pause \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{"is_async": false}'
```

### 恢復沙盒

`POST /v1/sandboxes/{sandbox_id}/resume`

恢復已暫停的沙盒。預設同步等待到 `running` 或回退到 `paused`。

**請求參數**

| 名稱 | 型別 | 必填 | 預設值 | 說明 |
|------|------|------|--------|------|
| is_async | boolean | 否 | false | 為 `true` 時立即回傳，由客戶端輪詢 |
| best_effort_oss | boolean | 否 | false | 為 `true` 時即使 OSS 掛載失敗也繼續恢復。臨時 (STS) 掛載在 API 層面可不提供新憑證。僅單沙盒 resume。 |
| object_storage | object | 否 | null | 可選：暫停狀態下恢復時的 OSS 增量（僅單沙盒 resume）。三選一：`remove_all`、`disable_all` 或非空 `mounts[]`。見 [恢復時的物件儲存補丁](#恢復時的物件儲存補丁)。不支援 batch-resume。 |

**成功回應**

`200 OK`，標準 envelope。

- 同步模式會等待，並以更新後的 **沙盒讀取物件** 作為 `data`（通常 `status: "running"`）
- 非同步模式則回傳較小的 `data` 物件：`sandbox_id`、`status: "resuming"`、`message: "Resume operation initiated"`

**範例**

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/resume \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{"is_async": false}'
```

### 終止沙盒

`POST /v1/sandboxes/{sandbox_id}/terminate`

強制立即終止沙盒。

**成功回應**

通常是 `202 Accepted`，頂層 `message: "Sandbox termination initiated"`，並包含：

- `data.sandbox_id`
- `data.status`：`termination_in_progress`
- `data.note`

特殊情況：若沙盒已經終止，後端會回傳 `200 OK`，並帶有 `data.sandbox_id`、`data.status: "terminated"`、`data.note`，以及頂層 `message: "Sandbox is already terminated"`。

**範例**

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/terminate \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678"
```

## 代理命令執行（Run Command）

在執行中的沙盒裡執行單一 shell 命令，並透過 **SSE** 串流輸出。這是一種**通道型**能力：

- **每個沙盒同時間只允許一個命令**
- 緩衝區只保留**當前這次執行**，runner 停止後會清空
- 輸出以事件串流送出，客戶端可自行把 `stdout` / `stderr` 合併渲染成終端效果

### 啟動命令執行

`POST /v1/sandboxes/{sandbox_id}/exec`

**請求體**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| command | string | 是 | 要執行的 shell 命令（以 `bash -c` 執行） |
| cwd | string | 否 | 工作目錄（預設 `/`） |
| env | object | 否 | 額外環境變數（會覆蓋合併到沙盒 env） |

**成功回應**

原始 `201 Created` JSON（**不是**標準 envelope）：

- `stream_path`：可 attach 的相對 SSE 路徑
- `started_at`：RFC3339Nano UTC 時間
- `deadline`：硬性 wall-clock 截止時間，RFC3339Nano UTC

**範例**

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/exec \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{"command":"ls -la /tmp","cwd":"/","env":{}}'
```

### 串流命令輸出（SSE）

`GET /v1/sandboxes/{sandbox_id}/exec/stream?token=...`

瀏覽器的 `EventSource` 無法帶自訂 header，因此瀏覽器使用 `token` 查詢參數驗證。非瀏覽器用戶端（curl / CLI / server-to-server）可直接使用 `X-API-Key`。

**成功回應**

`200 OK`，內容型別是 `text/event-stream`。伺服器會先送出 `ready` 事件，接著送出零個或多個 `start`、`stdout`、`stderr`、`keepalive`，最後以 `end` 或 `error` 結束。

**範例（curl）**

```bash
curl -N "https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/exec/stream?token=$ACCESS_TOKEN"
```

**範例（使用 API key header）**

```bash
curl -N "https://api.scalebox.dev/v1/sandboxes/sbx-abc123def456789/exec/stream" \
  -H "X-API-Key: sk-..."
```

**事件類型**

- `ready`：串流已附加
- `start`：程序已啟動（含 `pid`）
- `stdout`：base64 資料塊（`data_b64`）
- `stderr`：base64 資料塊（`data_b64`）
- `keepalive`：保持連線存活
- `end`：程序結束（含 `exit_code`）
- `error`：終端錯誤（含 `code`、`message`）

### 查詢是否有執行中的命令

`GET /v1/sandboxes/{sandbox_id}/exec/active`

當前若有命令正在此沙盒執行，會回傳 `active: true`，以及 `stream_path`、`command`、`cwd`、`started_at`、`deadline`。

**成功回應**

原始 `200 OK` JSON（**不是**標準 envelope）：

- idle：`{ "active": false }`
- active：`{ "active": true, "stream_path": "...", "command": "...", "cwd": "/", "started_at": "...", "deadline": "..." }`

### 取消目前命令

`DELETE /v1/sandboxes/{sandbox_id}/exec`

取消此沙盒目前正在執行的命令。

**成功回應**

原始 `200 OK` JSON：`{ "cancelled": true }`

### 串流緩衝說明

exec 輸出串流是針對**當前這次執行**的短生命週期、best-effort 通道。若達到內部限制，事件可能被截斷，較早的緩衝事件也可能被丟棄。

### 批次刪除

`POST /v1/sandboxes/batch-delete`

批次刪除多個沙盒。

**請求參數**

| 名稱 | 型別 | 必填 | 預設值 | 說明 |
|------|------|------|--------|------|
| sandbox_ids | array | 是 | - | 要刪除的沙盒 ID 陣列（最多 100 個） |
| force | boolean | 否 | false | 即使沙盒正在執行也強制刪除 |

**成功回應**

`202 Accepted`，頂層 `message` 會摘要成功 / 失敗數，並包含：

- `data.total`
- `data.successful`
- `data.failed`
- `data.results`：`{ sandbox_id, status, error? }` 陣列

**範例**

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes/batch-delete \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "sandbox_ids": ["sbx-abc123def456789", "sbx-def456ghi789012"],
    "force": false
  }'
```

### 批次終止

`POST /v1/sandboxes/batch-terminate`

並行終止多個沙盒（最多同時處理 50 個）。

**請求參數**

| 名稱 | 型別 | 必填 | 預設值 | 說明 |
|------|------|------|--------|------|
| sandbox_ids | array | 是 | - | 要終止的沙盒 ID 陣列（最多 100 個） |
| force | boolean | 否 | false | 即使處於過渡狀態也強制終止 |

**成功回應**

`202 Accepted`，頂層 `message` 會摘要成功 / 失敗數，並包含：

- `data.total`
- `data.successful`
- `data.failed`
- `data.results`：`{ sandbox_id, status, error? }` 陣列

### 批次暫停

`POST /v1/sandboxes/batch-pause`

並行暫停多個執行中的沙盒。

**請求參數**

| 名稱 | 型別 | 必填 | 說明 |

## 物件儲存

ScaleBox 支援透過 FUSE 將 S3 相容物件儲存掛載到沙盒中。您可以在建立沙盒時設定，也可以在執行期間手動掛載。

### 物件儲存設定

| 欄位 | 型別 | 必填 | 說明 |
|------|------|------|------|
| uri | string | 是 | S3 相容 URI：`s3://bucket-name/path` 或 `oss://bucket-name/path` |
| mount_point | string | 是 | 容器內的絕對掛載路徑 |
| access_key | string | 是 | S3 access key ID。不會在 API 中儲存或回顯 |
| secret_key | string | 是 | S3 secret access key。不會在 API 中儲存或回顯 |
| session_token | string | 否 | AWS STS 臨時憑證的 session token。提供後回應中該掛載標記為 `short_lived: true`。不會在 API 中儲存或回顯 |
| region | string | 否 | S3 region，例如 `us-east-1`；`region` 與 `endpoint` 至少要提供一個 |
| endpoint | string | 否 | 自訂 S3 相容端點 URL |

**回應中的掛載元資料：** `GET` 沙盒回傳 `object_storage` 陣列，含 `slot`、`state`（`active`/`disabled`/`free`）、`uri`、`mount_point`、可選 `region`/`endpoint`，以及臨時憑證掛載的 `short_lived`。憑證欄位不會回傳。

### 臨時（STS）憑證

建立或恢復 upsert 時提供 `session_token`。此類掛載為 **short-lived**：session token 會過期，恢復已暫停沙盒時需透過單沙盒恢復的 `object_storage` upsert 再次提供憑證。恢復 upsert 省略 `session_token` 可將掛載轉回標準長期憑證。批次恢復不支援 OSS 補丁。

### 恢復時的物件儲存補丁

沙盒處於**已暫停**時，`POST /v1/sandboxes/{sandbox_id}/resume` 可附帶可選的 `object_storage` 增量。無論沙盒目前是否已有掛載，upsert 條目都可在恢復時**新增首個掛載**。僅傳送有變更的掛載；後端依 `mount_point` 合併至持久化 slot 記錄。

必須**三選一**：`remove_all`、`disable_all` 或非空 `mounts` 陣列。空的 `object_storage` 表示無操作。組合多種模式回傳 HTTP 400。

**`mounts[]` 條目**（以 `mount_point` 為鍵）：

- **Upsert**（預設）：包含 `uri`、`access_key`、`secret_key`，以及 `region` 或 `endpoint` 至少一項（與建立時校驗相同）。刷新臨時憑證時需包含 `session_token`。
- **Delete**：`{ "mount_point": "/mnt/x", "delete": true }` — 不要包含 uri/憑證。
- **Disable**：`{ "mount_point": "/mnt/x", "disable": true }` — 不要包含 uri/憑證。

不修改掛載恢復時，標準（非 short-lived）沙盒無需重新輸入憑證。臨時掛載需 upsert 提供新憑證，或設定 `best_effort_oss: true`。

### 執行期手動掛載

所有沙盒都啟用了 FUSE 能力。您可以在執行中的容器內手動掛載 object storage：

```bash
# 建立憑證檔
echo "ACCESS_KEY:SECRET_KEY" > /root/.s3fs-credentials
chmod 600 /root/.s3fs-credentials

# 建立掛載點
mkdir -p /mnt/oss

# 掛載 S3 bucket
s3fs bucket-name:/path /mnt/oss \
  -o passwd_file=/root/.s3fs-credentials \
  -o url=https://s3.region.amazonaws.com \
  -o endpoint=region
```

<Callout type="info">
**安全提示：** 存取金鑰、秘密金鑰和 session token 均不會在 API 中儲存或回顯。掛載設定（URI、掛載點、區域、端點、slot 狀態）可能出現在沙盒詳情中。
</Callout>

## 指標 API

沙盒指標 API 提供即時效能資料與歷史趨勢，可用於監控資源使用情況。

### 指標端點

**原始指標：** `/v1/sandboxes/{sandbox_id}/metrics`
- 回傳標準化時間序列資料，適合 API 消費者
- 資料格式：含 CPU、記憶體、磁碟使用量的時間點陣列
- 使用情境：監控、告警、資料分析、外部整合

**圖表指標：** `/v1/sandboxes/{sandbox_id}/metrics/chart`
- 回傳適合前端圖表的資料
- 特性：內建統計、趨勢分析、色彩與圖表設定
- 使用情境：儀表板元件、即時監控、效能分析

### 時間參數

| 參數 | 說明 |
|------|------|
| `start` | 查詢開始時間，支援 ISO 8601、RFC3339、Unix timestamp |
| `end` | 查詢結束時間，預設為目前時間 |
| `step` | 資料點間隔。原始指標用秒數；圖表指標用 duration 字串（如 `15m`、`5s`） |

### 資源指標

| 指標 | 說明 |
|------|------|
| CPU | 請求核心數（整數）與使用率百分比（0-100） |
| Memory | 請求與使用中的記憶體位元組數 |
| Storage | 請求與使用中的磁碟空間位元組數 |
| Uptime | 沙盒執行秒數 |

## 錯誤處理

| 情境 | 說明 |
|------|------|
| No Data Available | 沙盒未執行時，可能回傳空 metrics 陣列與狀態 |
| Invalid Time Range | 若 start / end 顛倒，系統會自動交換 |
| Resource Not Found | 若沙盒不存在或使用者無權限，回傳 404 |

## 最佳實踐

| 建議 | 說明 |
|------|------|
| Time Range Selection | 即時監控建議 5-30 秒步進；歷史資料建議 1-15 分鐘 |
| Data Polling | 即時儀表板可每 30-60 秒輪詢一次 |
| Error Handling | 請檢查回應狀態，並處理沒有可用 metrics 的情況 |

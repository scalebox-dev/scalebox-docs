## API 端點

以下是所有可用的沙盒 API 端點：

| 端點 | 方法 | 路徑 | 描述 |
|------|------|------|------|
| create-sandbox | POST | `/v1/sandboxes` | 建立新沙盒。預設（同步）：等待至 running 或 failed。設定 is_async: true 可立即返回並輪詢狀態。 |
| list-scalebox-regions | GET | `/v1/scalebox-regions` | 公開端點：目前至少有一個可用叢集的 Scalebox 區域 id（與地域目錄交集）。用於建立沙盒時 locality.region。API 金鑰可選。 |
| list-sandboxes | GET | `/v1/sandboxes` | 列出認證使用者的所有沙盒 |
| get-sandbox | GET | `/v1/sandboxes/{sandbox_id}` | 獲取特定沙盒的詳細資訊 |
| update-sandbox | PUT | `/v1/sandboxes/{sandbox_id}` | 更新沙盒配置（僅限延長超時時間） |
| delete-sandbox | DELETE | `/v1/sandboxes/{sandbox_id}` | 刪除沙盒及其所有關聯資源 |
| pause-sandbox | POST | `/v1/sandboxes/{sandbox_id}/pause` | 暫停正在執行的沙盒。預設（同步）：等待至暫停或回退到執行後返回。設定 is_async: true 可立即返回並輪詢狀態。 |
| resume-sandbox | POST | `/v1/sandboxes/{sandbox_id}/resume` | 恢復已暫停的沙盒。預設（同步）：等待至執行或回退到暫停後返回。設定 is_async: true 可立即返回並輪詢狀態。 |
| terminate-sandbox | POST | `/v1/sandboxes/{sandbox_id}/terminate` | 強制立即終止沙盒 |
| batch-delete | POST | `/v1/sandboxes/batch-delete` | 批次刪除多個沙盒 |
| batch-terminate | POST | `/v1/sandboxes/batch-terminate` | 並行終止多個沙盒（最多同時處理50個） |
| batch-pause | POST | `/v1/sandboxes/batch-pause` | 並行暫停多個正在執行的沙盒（僅暫停執行中的沙盒） |
| batch-resume | POST | `/v1/sandboxes/batch-resume` | 並行恢復多個已暫停的沙盒，包含預算和訂閱驗證 |
| update-timeout | POST | `/v1/sandboxes/{sandbox_id}/timeout` | 獨立更新沙盒超時時間。對於執行中的沙盒：如果新超時 > 已用時間則立即應用，否則延遲到下一個執行階段。對於暫停的沙盒：應用於下一個執行階段。超時在每次恢復時重置。 |
| create-template-from-sandbox | POST | `/v1/sandboxes/{sandbox_id}/create-template` | 從正在執行的沙盒建立模板。沙盒必須處於 'running' 狀態。模板建立是非同步啟動的，映象將被推送到 Harbor。 |
| get-sandbox-ports | GET | `/v1/sandboxes/{sandbox_id}/ports` | 獲取沙盒的所有埠（模板埠 + 自定義埠） |
| add-sandbox-port | POST | `/v1/sandboxes/{sandbox_id}/ports` | 向正在執行的沙盒新增自定義埠。沙盒必須處於 'running' 狀態。這將動態更新 Kubernetes Service 並建立 Ingress 資源。 |
| remove-sandbox-port | DELETE | `/v1/sandboxes/{sandbox_id}/ports/{port}` | 從正在執行的沙盒中刪除自定義埠。沙盒必須處於 'running' 狀態。只能刪除自定義埠（模板埠受保護）。這將刪除 Ingress 並更新 Kubernetes Service。 |
| get-webrtc-turn-credential | GET | `/v1/sandboxes/{sandbox_id}/webrtc-turn-credential` | 取得沙盒的短期 TURN 憑證（ice_servers、username、credential）。沙盒須在執行且至少有一個 WebRTC 埠。響應用於配置 RTCPeerConnection。 |

## create-sandbox

建立新沙盒。預設（同步）：等待至 running 或 failed。設定 is_async: true 可立即返回並輪詢狀態。

```
POST /v1/sandboxes
```

### 請求引數

| 引數 | 型別 | 必需 | 預設值 | 描述 |
|------|------|------|--------|------|
| `name` | string | 否 | 自動生成 | 人類可讀的沙盒名稱（0-24個字元，空值將僅使用隨機字尾） |
| `description` | string | 否 | 空 | 沙盒用途的詳細描述 |
| `template` | string | 否 | "base" | 模板名稱或ID（例如："python-dev" 或 "tpl-abc123"） |
| `project_id` | string | 否 | 使用者預設 | 要關聯沙盒的專案 |
| `cpu_count` | integer | 否 | 模板預設 | CPU核心數量 |
| `memory_mb` | integer | 否 | 模板預設 | 記憶體分配（MB） |
| `storage_gb` | integer | 否 | 計劃最大值的50% | 持久儲存（GB）（0 = 使用訂閱計劃最大值的50%，向上取整） |
| `timeout` | integer | 否 | 300 | 沙盒超時時間（秒） |
| `env_vars` | object | 否 | {} | 要在沙盒中設定的環境變數 |
| `metadata` | object | 否 | {} | 沙盒後設資料的自定義鍵值對 |
| `secure` | boolean | 否 | true | 沙盒的安全設定 |
| `allow_internet_access` | boolean | 否 | true | 是否允許沙盒訪問網際網路 |
| `object_storage` | object \| array | 否 | null | 單一掛載物件或掛載物件 JSON 陣列（多掛載）。憑證不會持久儲存。詳見物件儲存部分。 |
| `object_storage_direct_mount` | boolean | 否 | false | 僅自訂範本：在 worker 容器掛載物件儲存。scalebox_family 範本忽略。 |
| `s3fs_executable_path` | string | 否 | 空（使用 PATH 上的 s3fs） | 直接掛載時：worker 上 s3fs 二進位可選路徑。 |
| `custom_ports` | array | 否 | [] | 自定義埠配置陣列（模板中不存在的埠）。每個埠必須包含 'port'（數字）和 'name'（字串）。最多16個總埠（模板 + 自定義）。 |
| `locality` | object | 否 | null | 可選排程：`{ auto_detect: true }` 或 `{ region: string, force?: boolean }`。region 須符合系統設定；可用 GET /v1/scalebox-regions 探索目前容量。force: true 時若該區域無可用叢集則失敗（不回退）。 |
| `auto_pause` | boolean | 否 | false | 為true時，沙盒超時觸發自動暫停而非終止，並應用持久化。為false時，超時導致硬終止。此設定在建立後不可更改。 |
| `is_async` | boolean | 否 | false | 為true時立即返回（用戶端輪詢狀態）；為false或省略時等待沙盒變為 running 或 failed（同步）。 |

## batch-delete

批次刪除多個沙盒

```
POST /v1/sandboxes/batch-delete
```

### 請求引數

| 引數 | 型別 | 必需 | 預設值 | 描述 |
|------|------|------|--------|------|
| `sandbox_ids` | array | 是 | - | 要刪除的沙盒ID陣列（最多100個） |
| `force` | boolean | 否 | false | 即使正在執行也強制刪除 |

### 請求示例

```bash
curl -X POST https://api.scalebox.dev/v1/sandboxes/batch-delete \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "sandbox_ids": ["sbx-abc123def456789", "sbx-def456ghi789012"],
```

## 物件儲存

ScaleBox 支援使用 FUSE 將 S3 相容的物件儲存掛載到沙盒中。您可以在建立沙盒時配置物件儲存，或在執行時手動掛載。所有沙盒預設都啟用了 FUSE 功能。

### 物件儲存配置

建立沙盒時，`object_storage` 可為**單一掛載物件**或**掛載物件 JSON 陣列**（多掛載）。與沙盒**排程地域** `locality.region`（來自 `GET /v1/scalebox-regions` 的 Scalebox 區域 id）不同，勿與 S3 的 `region` 欄位混淆。

可選：`object_storage_direct_mount`（僅自訂範本）、`s3fs_executable_path`（直接掛載時指定 s3fs 路徑）。

#### 配置欄位

| 欄位 | 型別 | 必需 | 描述 |
|------|------|------|------|
| `uri` | string | 是 | S3 相容儲存 URI，格式：`s3://bucket-name/path` 或 `oss://bucket-name/path`。示例：`s3://my-bucket/data` |
| `mount_point` | string | 是 | 容器中儲存將被掛載的絕對路徑。示例：`/mnt/oss` |
| `access_key` | string | 是 | S3 訪問金鑰 ID。憑證永遠不會儲存在資料庫中，也不會在 API 響應中返回。 |
| `secret_key` | string | 是 | S3 秘密訪問金鑰。憑證永遠不會儲存在資料庫中，也不會在 API 響應中返回。 |
| `region` | string | 否* | AWS 區域名稱（例如：`us-east-1`、`ap-east-1`）。必須提供 `region` 或 `endpoint` 中的至少一個。 |
| `endpoint` | string | 否* | 自定義 S3 相容端點 URL。必須提供 `region` 或 `endpoint` 中的至少一個。示例：`https://s3.ap-east-1.amazonaws.com` |

### 自動掛載

如果在建立時配置了物件儲存，它將在沙盒啟動時自動掛載。掛載指令碼在主應用程式之前執行，確儲存儲立即可用。

### 執行時手動掛載

所有沙盒都啟用了 FUSE 功能（`SYS_ADMIN` 能力和 `/dev/fuse` 裝置）。您可以透過在執行中的容器中執行命令隨時手動掛載物件儲存：

```bash
# 建立憑證檔案
echo "ACCESS_KEY:SECRET_KEY" > /root/.s3fs-credentials
chmod 600 /root/.s3fs-credentials

# 建立掛載點
mkdir -p /mnt/oss

# 掛載 S3 儲存桶（對於非預設區域，需要同時指定 url 和 endpoint）
s3fs bucket-name:/path /mnt/oss \
  -o passwd_file=/root/.s3fs-credentials \
  -o url=https://s3.region.amazonaws.com \
  -o endpoint=region
```

<Callout type="info">
**安全提示：** 物件儲存憑證永遠不會持久化到資料庫中。只有 URI 和掛載點會被儲存並在 API 響應中返回。憑證僅在掛載操作期間使用。
</Callout>

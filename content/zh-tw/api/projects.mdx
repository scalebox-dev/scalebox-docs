## API 端點

以下是所有可用的專案 API 端點：

| 端點 | 方法 | 路徑 | 描述 |
|------|------|------|------|
| create-project | POST | `/v1/projects` | 建立新專案 |
| list-projects | GET | `/v1/projects` | 列出使用者的所有專案 |
| get-project | GET | `/v1/projects/{project_id}` | 獲取特定專案的詳細資訊 |
| update-project | PUT | `/v1/projects/{project_id}` | 更新專案資訊 |
| delete-project | DELETE | `/v1/projects/{project_id}` | 刪除專案 |
| get-project-sandboxes | GET | `/v1/projects/{project_id}/sandboxes` | 獲取專案中的所有沙盒 |
| add-sandbox-to-project | POST | `/v1/projects/{project_id}/sandboxes/{sandbox_id}` | 將沙盒新增到專案 |
| remove-sandbox-from-project | DELETE | `/v1/projects/{project_id}/sandboxes/{sandbox_id}` | 從專案中移除沙盒 |

## create-project

建立新專案

**路徑：** `POST /v1/projects`

### 請求引數

| 引數 | 型別 | 必需 | 預設值 | 描述 |
|------|------|------|--------|------|
| `name` | string | 是 | | 專案名稱（2-100個字元） |
| `description` | string | 否 | | 專案描述 |

### 請求示例

```bash
curl -X POST https://api.scalebox.dev/v1/projects \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-development-project",
    "description": "Project for developing new features"
  }'
```

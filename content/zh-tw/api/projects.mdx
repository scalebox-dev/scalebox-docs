## 專案概念

- **預設專案**：每位使用者的第一個專案會被強制設為 `is_default: true`。
- **可見範圍**：一般使用者只能看到自己的專案；帳戶 root 使用者可查看整個帳戶的專案。
- **移動規則**：加入或移出沙盒時，沙盒必須是執行中，且仍會檢查帳戶歸屬。

## 標準回應格式

專案 API 使用標準信封格式：

```json
{
  "success": true,
  "data": {},
  "timestamp": "2026-04-17T12:34:56Z"
}
```

只有訊息的操作會在頂層回傳 `message`，且可能省略 `data`。

## API 端點

### 建立專案

`POST /v1/projects`

建立新專案。

**請求主體**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| name | string | 是 | 專案名稱 |
| description | string | 否 | 專案描述 |
| is_default | boolean | 否 | 是否設為預設專案 |

**回應**

```json
{
  "success": true,
  "data": {
    "project_id": "prj-abc123def456789",
    "name": "frontend-development",
    "description": "Project for all frontend development sandboxes",
    "owner_user_id": "usr-xyz789abc123456",
    "status": "active",
    "is_default": false,
    "created_at": "2026-04-17T12:00:00Z"
  },
  "timestamp": "2026-04-17T12:00:00Z"
}
```

### 列出專案

`GET /v1/projects`

列出目前可見的所有專案。

**查詢參數**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| owner_user_id | string | 否 | 僅 root 使用者可用：依擁有者使用者 ID 篩選 |

**回應**

```json
{
  "success": true,
  "data": {
    "projects": [
      {
        "project_id": "prj-abc123def456789",
        "name": "frontend-development",
        "description": "Project for all frontend development sandboxes",
        "owner_user_id": "usr-xyz789abc123456",
        "status": "active",
        "is_default": false,
        "sandbox_count": 5,
        "total_spent": 0,
        "created_at": "2026-04-10T10:00:00Z",
        "updated_at": "2026-04-17T11:30:00Z",
        "owner": {
          "user_id": "usr-xyz789abc123456",
          "username": "developer",
          "display_name": "John Developer",
          "email": "john@example.com"
        }
      }
    ]
  },
  "timestamp": "2026-04-17T12:00:00Z"
}
```

`owner` 會在帳戶 root 使用者視角出現；某些管理員清單回應也可能包含 `account_owner`。

`GET /v1/projects/{project_id}`

取得單一專案。

**回應**

```json
{
  "success": true,
  "data": {
    "project_id": "prj-abc123def456789",
    "name": "frontend-development",
    "description": "Project for all frontend development sandboxes",
    "owner_user_id": "usr-xyz789abc123456",
    "status": "active",
    "is_default": false,
    "sandbox_count": 5,
    "total_spent": 0,
    "created_at": "2026-04-10T10:00:00Z",
    "updated_at": "2026-04-17T11:30:00Z"
  },
  "timestamp": "2026-04-17T12:00:00Z"
}
```

### 更新專案

`PUT /v1/projects/{project_id}`

更新可變更的專案欄位。

**請求主體**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| name | string | 否 | 新專案名稱 |
| description | string | 否 | 新專案描述 |
| status | string | 否 | 更新後的狀態值 |
| is_default | boolean | 否 | 設定或取消預設專案 |

**回應**

```json
{
  "success": true,
  "data": {
    "id": 42,
    "project_id": "prj-abc123def456789",
    "name": "full-stack-development",
    "description": "Updated project for full-stack development work",
    "owner_user_id": "usr-xyz789abc123456",
    "owner_account_id": "acc-123456789",
    "status": "active",
    "is_default": true,
    "created_at": "2026-04-10T10:00:00Z",
    "updated_at": "2026-04-17T12:05:00Z",
    "owner": {
      "user_id": "usr-xyz789abc123456",
      "username": "developer",
      "display_name": "John Developer",
      "email": "john@example.com"
    },
    "sandboxes": []
  },
  "message": "Project updated successfully",
  "timestamp": "2026-04-17T12:05:00Z"
}
```

這個回應會直接回傳專案模型，因此和 list/get 的投影不同，可能包含 `id`、`owner_account_id` 與巢狀 `sandboxes`。

### 刪除專案

`DELETE /v1/projects/{project_id}`

刪除一個空專案。

**回應**

```json
{
  "success": true,
  "message": "Project deleted successfully",
  "timestamp": "2026-04-17T12:10:00Z"
}
```

### 取得專案沙盒

`GET /v1/projects/{project_id}/sandboxes`

列出某個專案中的沙盒。

**查詢參數**

| 名稱 | 型別 | 必填 | 說明 |
|------|------|------|------|
| status | string | 否 | 依沙盒狀態篩選 |
| skip | integer | 否 | 位移，預設 `0` |
| limit | integer | 否 | 筆數上限，預設 `50` |

**回應**

```json
{
  "success": true,
  "data": [
    {
      "id": "sbx-abc123def456789",
      "name": "react-frontend-dev",
      "description": "Frontend sandbox",
      "template_id": "tpl-react-dev",
      "owner_user_id": "usr-xyz789abc123456",
      "project_id": "prj-abc123def456789",
      "cpu_count": 2,
      "memory_mb": 4096,
      "storage_gb": 20,
      "status": "running",
      "started_at": "2026-04-17T11:00:00Z",
      "stopped_at": null,
      "created_at": "2026-04-17T10:55:00Z",
      "updated_at": "2026-04-17T11:00:00Z"
    }
  ],
  "timestamp": "2026-04-17T12:12:00Z"
}
```

此端點的 `data` 是根層陣列，不會回傳 `data.sandboxes` 或分頁中繼資料。

### 將沙盒加入專案

`POST /v1/projects/{project_id}/sandboxes/{sandbox_id}/add`

把執行中的沙盒移入目標專案。

**回應**

```json
{
  "success": true,
  "message": "Sandbox added to project successfully",
  "timestamp": "2026-04-17T12:15:00Z"
}
```

### 將沙盒移出專案

`POST /v1/projects/{project_id}/sandboxes/{sandbox_id}/evict`

把執行中的沙盒移回呼叫者的預設專案。

**回應**

```json
{
  "success": true,
  "message": "Sandbox evicted from project successfully",
  "timestamp": "2026-04-17T12:16:00Z"
}
```

## 常見錯誤

```json
{
  "success": false,
  "error": "Project not found",
  "timestamp": "2026-04-17T12:20:00Z"
}
```

- `400`：專案名稱無效、名稱重複、刪除仍含沙盒的專案，或取消唯一預設專案
- `403`：帳戶範圍不足
- `404`：在目前範圍內找不到專案或沙盒
- `500`：資料庫或清理流程失敗

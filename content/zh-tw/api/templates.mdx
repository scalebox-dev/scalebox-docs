## API 端點

以下是所有可用的模板 API 端點：

| 端點 | 方法 | 路徑 | 描述 |
|------|------|------|------|
| create-template | POST | `/v1/templates` | 建立新模板 |
| list-templates | GET | `/v1/templates` | 列出所有可訪問的模板 |
| get-template | GET | `/v1/templates/{template_id}` | 獲取特定模板的詳細資訊 |
| update-template | PUT | `/v1/templates/{template_id}` | 更新模板配置 |
| delete-template | DELETE | `/v1/templates/{template_id}` | 刪除模板 |
| build-template | POST | `/v1/templates/{template_id}/build` | 構建模板映像 |
| list-import-jobs | GET | `/v1/import-jobs` | 列出當前使用者的模板匯入任務 |
| get-import-job | GET | `/v1/import-jobs/{job_id}` | 依任務 ID 取得單一匯入任務詳情 |
| share-template | POST | `/v1/templates/{template_id}/share` | 將私有模板與帳戶共享 |
| unshare-template | POST | `/v1/templates/{template_id}/unshare` | 將帳戶共享模板恢復為私有 |

## create-template

建立新模板

**路徑：** `POST /v1/templates`

### 請求引數

| 引數 | 型別 | 必需 | 預設值 | 描述 |
|------|------|------|--------|------|
| `name` | string | 是 | | 模板名稱（4-32個字元，支援小寫字母、數字、連字元和下劃線） |
| `description` | string | 否 | | 模板描述 |
| `image` | string | 是 | | 容器映象名稱 |
| `base_template_id` | string | 否 | | 基礎模板ID |
| `public` | boolean | 否 | false | 是否為公共模板 |
| `cpu_count` | integer | 否 | 2 | 預設CPU數量 |
| `memory_mb` | integer | 否 | 512 | 預設記憶體（MB） |
| `storage_gb` | integer | 否 | 1 | 預設儲存（GB） |
| `timeout` | integer | 否 | 300 | 預設超時時間（秒） |
| `ports` | array | 否 | [] | 埠配置 |

### 請求示例

```bash
curl -X POST https://api.scalebox.dev/v1/templates \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "python-dev-template",
    "description": "Template for Python development",
    "image": "python:3.9",
    "public": false,
    "cpu_count": 2,
    "memory_mb": 1024,
    "storage_gb": 10,
    "timeout": 3600,
    "ports": [8000, 8080]
  }'
```

## update-template

更新模板配置

**路徑：** `PUT /v1/templates/{template_id}`

### 請求引數

| 引數 | 型別 | 必需 | 預設值 | 描述 |
|------|------|------|--------|------|
| `name` | string | 否 | | 新模板名稱 |
| `description` | string | 否 | | 新模板描述 |
| `image` | string | 否 | | 新容器映象名稱 |
| `public` | boolean | 否 | | 是否為公共模板 |
| `cpu_count` | integer | 否 | | 新預設CPU數量 |
| `memory_mb` | integer | 否 | | 新預設記憶體（MB） |
| `storage_gb` | integer | 否 | | 新預設儲存（GB） |
| `timeout` | integer | 否 | | 新預設超時時間（秒） |
| `ports` | array | 否 | | 新埠配置 |
| `custom_command` | string | 否 | | 自訂啟動命令 |
| `ready_command` | string | 否 | | 就緒探針 JSON |

### 請求示例

```bash
curl -X PUT https://api.scalebox.dev/v1/templates/tpl-abc123def456789 \
  -H "X-API-Key: sk-1234567890abcdef1234567890abcdef12345678" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "更新的Python環境",
    "description": "更新的描述",
    "image": "python:3.10",
    "cpu_count": 4,
    "memory_mb": 2048
  }'
```

## list-import-jobs

列出當前使用者的模板匯入任務。預設僅回傳進行中（pending/running）任務。

**路徑：** `GET /v1/import-jobs`

### 請求引數

| 引數 | 型別 | 必需 | 預設值 | 描述 |
|------|------|------|--------|------|
| `status` | string | 否 | | 篩選：ongoing、pending、running、completed、failed、cancelled |
| `template_id` | string | 否 | | 僅回傳該模板 ID 的任務 |
| `limit` | integer | 否 | 20 | 回傳數量上限（1-100） |
| `offset` | integer | 否 | 0 | 分頁偏移 |

## get-import-job

依任務 ID 取得單一匯入任務詳情

**路徑：** `GET /v1/import-jobs/{job_id}`

## share-template

將私有模板與帳戶共享（可見性 → account_shared）。僅模板擁有者或管理員。

**路徑：** `POST /v1/templates/{template_id}/share`

### 請求引數

| 引數 | 型別 | 必需 | 預設值 | 描述 |
|------|------|------|--------|------|
| `new_name` | string | 否 | | 共享時使用的新名稱（與現有帳戶共享模板同名時必填） |

## unshare-template

將帳戶共享模板恢復為私有。僅模板擁有者或管理員。

**路徑：** `POST /v1/templates/{template_id}/unshare`

<Callout type="info">
**模板管理最佳實踐**

使用描述性的模板名稱，設定合理的預設資源限制。
公共模板可以被其他使用者使用，請確保不包含敏感資訊。
檢視 [沙盒 API](./sandboxes) 來了解如何從模板建立沙盒。
</Callout>
